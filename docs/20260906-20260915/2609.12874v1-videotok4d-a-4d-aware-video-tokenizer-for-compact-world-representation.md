## 摘要
视频标记器已成为现代视频建模的基石，通过将高维视觉信号映射到紧凑的潜在空间，支撑了压缩、重建和生成方面的进展。然而，尽管取得了这些进展，当前的标记化范式在很大程度上仍局限于 2D 视觉领域，将视频视为图像序列，而非对底层动态 3D 世界的观测。因此，学习到的标记继承了这种以观测为中心的偏差，限制了它们紧凑表示真实世界 4D 场景的能力。为缓解这一问题，我们提出 VideoTok4D，一种面向紧凑世界表示的新型 4D 感知视频标记器。具体而言，我们的方法包含三个关键设计：1）一种时空解耦策略，将视频分解为静态和动态标记，以实现整体世界建模；2）一种轨迹感知的动态注意力机制，聚合轨迹对齐的线索，以促进跨视角运动一致性；3）Co4DGen，一种在所得 VideoTok4D 标记空间上学习得到的扩散先验，用于高效 4D 场景生成。大量实验表明，我们提出的方法在达到最先进性能的同时，所需存储量最多可比密集 4D 表示少 4 个数量级。此外，紧凑的标记空间显著缩短了扩散序列，从而实现了高效生成。

## Abstract
Video tokenizers have emerged as a cornerstone of modern video modeling, underpinning progress in compression, reconstruction and generation by mapping high-dimensional visual signals into compact latent spaces. However, despite this progress, current tokenization paradigms largely remain within the 2D visual domain, treating videos as image sequences rather than observations of an underlying dynamic 3D world. Consequently, the learned tokens inherit this observation-centric bias, limiting their capacity to compactly represent real-world 4D scenes. To mitigate this issue, we propose VideoTok4D, a novel 4D-aware video tokenizer for compact world representation. Specifically, our approach comprises three key designs: 1) a spatiotemporal disentanglement strategy that factorizes videos into static and dynamic tokens for holistic world modeling; 2) a track-aware dynamic attention mechanism that aggregates trajectory-aligned cues to promote cross-view motion consistency; and 3) Co4DGen, a diffusion prior learned over the resulting VideoTok4D token space for efficient 4D scene generation. Extensive experiments have demonstrated that our proposed method achieves state-of-the-art performance while requiring up to 4 orders of magnitude less storage than dense 4D representations. Moreover, the compact token space substantially shortens diffusion sequences, enabling efficient generation.

## 二、方法论

### 2.1 整体框架

- 训练目标不是重建输入片段，而是**新视角合成**：给定源视频 $V^s=\{I^s_t\}$ 与其标定相机轨迹 $P^s$，编码器输出结构化静态/动态 token 组
  $(Z^s, Z^d) = E_\phi(V^s, P^s)$；
  渲染器在目标相机轨迹下解码 $\hat{V}^{tgt} = D_\theta(Z^s, Z^d, P^{tgt})$。
- 图像编码使用**冻结的 VA-VAE**；RGB 输出由**冻结的 VideoDCAE 解码器**完成；渲染器是一个 latent rectified-flow 解码器。
- 训练目标为 rectified flow matching：在线性路径 $Y_\tau=(1-\tau)Y_0+\tau Y_1$（$Y_1\sim\mathcal{N}(0,I)$）上预测速度场
  $\mathcal{L}_{tok}=\mathbb{E}\|(Y_1-Y_0)-v^\tau_\theta(Y_\tau,Z^s,Z^d,P^{tgt},\tau)\|_2^2$。

### 2.2 时空解耦策略（Spatiotemporal Disentanglement）

- **动机**：持久场景内容（几何、外观，跨大范围区域与帧）与瞬时物体运动（局部、且与相机位移纠缠）时空支撑不同，混在同一潜空间会被主导的静态证据淹没稀疏运动线索。
- **Spatial Branch**：对整段潜特征序列 $X_{1:T}$ 叠加相机射线嵌入（camera-ray embedding），经空间/时间注意力构建相机感知特征网格；再由 $N_s$ 个可学习静态 query 交叉注意力聚合全局上下文，得到 $Z^s\in\mathbb{R}^{N_s\times d}$。
- **Temporal Branch**：在动态聚焦特征 $X^{dyn}_{1:T}$ 上施加轨迹感知动态注意力，由 $N_d$ 个可学习动态 query 的最终状态形成 $Z^d\in\mathbb{R}^{N_d\times d}$。
- 最终编码：$Z^s=E_s(X_{1:T},P^s)$，$Z^d=E_d(X^{dyn}_{1:T},P^s,F_{1:T-1})$。

### 2.3 轨迹感知动态注意力（Track-Aware Dynamic Attention）

分两阶段解决"相机位移与物体运动混合"和"运动内容位置漂移导致固定网格聚合错位"两个难题：

- **位姿补偿运动隔离**：
  - 用 RAFT 估计光流 $F_{1:T-1}$、UniDepth 估计逐帧深度 $D_{1:T}$，结合相对相机变换 $T_{t\to t+1}$，在静态场景假设下计算相机诱导流：
    $F^{pose}_t(p)=\pi_{t+1}(T_{t\to t+1}\pi_t^{-1}(p,D_t(p)))-p$。
  - 残差 $r_t(p)=\|F_t(p)-F^{pose}_t(p)\|_2$ 隔离物体自身位移，二值运动掩码 $M_t(p)=\mathbf{1}\{r_t(p)>\tau_t\}$，得 $X^{dyn}_t=X_t\odot M_t$。
- **轨迹对齐特征聚合**：
  - 先在每个掩码动态区域内做空间自注意力：$\bar{X}^{dyn}_t=A_{sp}(X^{dyn}_t;M_t)$；
  - 在潜分辨率掩码上采样种子点，沿光流跨帧传播：$p^{t+1}_i=p^t_i+F_t(p^t_i)$，$g^t_i=\bar{X}^{dyn}_t(p^t_i)$，形成轨迹对齐序列 $G_i=\{g^t_i\}_{t\in V_i}$；
  - 每层 Temporal Branch 沿**每条轨迹独立**做自注意力 $\tilde{g}^{t,l}_i=\mathrm{MHA}_l(g^t_i,G_i,G_i)$，避免固定网格时间注意力混合无关特征；动态 query 经自注意力、对轨迹特征交叉注意力与 MLP 更新，$L$ 层后得到 $Z^d$。

### 2.4 Co4DGen：高效 4D 场景生成

- **核心思想**：不在每个视角上重新生成稠密视频潜变量，也不构建稠密显式 4D 状态，而是**只采样一次紧凑 4D token 状态**，随后复用冻结的 VideoTok4D 渲染器渲染多条同步相机轨迹。
- **联合 token 扩散**：训练时采样条件相机 $c$ 与锚点相机 $a$，令联合目标状态 $Z_a=[Z^s_a;Z^d_a]=E_\phi(V^a,P^a)$，学习 $p_\omega(Z_a\mid V^c,P^c,P^a)$；扩散扰动 $Z_a^\tau=\alpha_\tau Z_a+\sigma_\tau\epsilon$，条件特征 $h=E_{cond}(V^c,P^c,P^a)$ 注入双流。
- **静态–动态交叉 token 注意力（非对称路由）**：静态 query 只在静态流内注意力，动态 query 可同时关注两个流——既保护静态 token 不受瞬态运动污染，又让动态 token 锚定场景几何、外观与布局。损失为联合速度场回归
  $\mathcal{L}_{Co4DGen}=\mathbb{E}\|\hat{v}_\omega(Z_a^\tau,h,\tau)-v_\tau\|_2^2$。
- **推理**：从条件先验采样**一个**联合 token 状态，用冻结渲染器对全部查询轨迹 $P^q,\ q\in Q$ 渲染，无需重复运行 token 先验。
