## 摘要
大语言模型（LLM）智能体日益依赖外部记忆来支持长时程推理与决策。现有记忆系统通常将历史轨迹或摘要作为独立的上下文片段进行检索，忽视了多步执行背后固有的过程依赖。随着记忆规模扩大，这种扁平化检索会引入上下文碎片化和跨任务干扰，导致推理轨迹在结构上不一致。我们提出 ActiveMem，一种分层记忆框架，它以递归方式将智能体经验组织为依赖感知的潜在执行树。ActiveMem 将轨迹抽象为可复用的子任务节点，同时显式保留执行转移，从而能够以当前执行状态为条件检索连贯的推理路径。为支持持续适应，ActiveMem 进一步通过强化学习学习动态记忆扩展、检索和剪枝策略。在各种智能体基准上的实验表明，与现有基于记忆的智能体相比，ActiveMem 在任务完成、推理稳定性和记忆效率方面均有持续提升。此外，ActiveMem 使紧凑的开放权重模型能够取得与规模显著更大的专有系统相竞争的性能。

## Abstract
Large Language Model (LLM) agents increasingly rely on external memory to support long-horizon reasoning and decision making. Existing memory systems typically retrieve historical trajectories or summaries as independent context fragments, overlooking the procedural dependencies underlying multi-step execution. As memory scales, such flat retrieval introduces context fragmentation and cross-task interference, leading to structurally inconsistent reasoning trajectories. We propose ActiveMem, a hierarchical memory framework that recursively organizes agent experiences into dependency-aware latent execution trees. ActiveMem abstracts trajectories into reusable subtask nodes while explicitly preserving execution transitions, enabling coherent reasoning-path retrieval conditioned on the current execution state. To support continual adaptation, ActiveMem further learns dynamic memory expansion, retrieval, and pruning policies through reinforcement learning. Experiments across various agent benchmarks demonstrate that ActiveMem consistently improves task completion, reasoning stability, and memory efficiency over existing memory-based agents. Moreover, ActiveMem enables compact open-weight models to achieve competitive performance with substantially larger proprietary systems.

## 2. 方法论

### 2.1 核心思想与整体框架

- 将智能体交互建模为序贯决策：任务指令 $x$、冻结 LLM $\pi_\theta$、环境 $E$、$T$ 步轨迹 $\tau=(s_0,a_0,\dots,s_T)$。
- 历史前缀被压缩为动态**层次化潜在记忆树（HLMT）** $T_t$，通过离散更新函数演化：
  $$T_t=\text{TreeUpdate}(T_{t-1},\,a^{\text{tree}}_{t-1})$$
- 给定当前状态 $s_t$ 检索相关记忆路径 $P_t=f_{\text{retrieve}}(s_t,T_t)$；轻量控制器 $W_\phi$ 结合路径与当前隐状态 $h_t=f_{\text{enc}}(s_t;\pi_\theta)$ 得到共享表示 $u_t$，再分两路输出：
  - **潜在记忆前缀** $m_t$：条件化冻结 LLM；
  - **树动作** $a^{\text{tree}}_t$：管理记忆拓扑。
- **三点根本性区别**：(1) 用连续潜在记忆而非原始文本块；(2) 主动优化记忆拓扑而非被动追加历史；(3) 用 RL 联合优化推理适配与记忆结构。
- 潜在头虽不输出离散动作，但 $m_t(\phi)$ 改变冻结 LLM 隐激活，隐式定义了新的参数化策略：
  $$\pi_{\theta,\phi}(a_t\mid s_t)=\pi_\theta(a_t\mid s_t,m_t(\phi))$$
- 优化目标：$\max_\phi \mathbb{E}_{x\sim D,\tau\sim\pi_{\theta,\phi}}[R(\tau)]$。

### 2.2 关键技术细节

**（1）层次化潜在记忆树（HLMT）**

- 有向树拓扑，节点 $n_i=(e_i,pa(i),ch(i))$，$e_i\in\mathbb{R}^d$ 为控制器产生的压缩潜在摘要；上层节点编码粗粒度任务语义，下层保留细粒度执行细节。
- 初始化一个**虚拟根节点** $n_r$（不编码任务语义，回合边界重置）。
- 以 $h_t$ 为查询进行**递归贪心遍历**，每层选余弦相似度最大的子节点：
  $$n_{k+1}=\arg\max_{n\in ch(k)}\frac{h_t\cdot e_n}{\lVert h_t\rVert\lVert e_n\rVert}$$
- 当最大相似度低于阈值 $\tau_{\text{stop}}$ 时终止，得到激活路径 $P_t=(n_1,\dots,n_d)$，实现**由粗到细**的检索并天然抑制无关分支。

**（2）双头记忆控制器**

- 路径经均值池化 $\bar p_t=\frac{1}{|P_t|}\sum_{n_i\in P_t}e_i$（遍历深度已隐含编码路径顺序），再经 2 层 MLP 得 $u_t=\text{MLP}_{\text{shared}}([h_t;\bar p_t])$。
- **潜在注入头**：$m_t=W_{\text{latent}}u_t\in\mathbb{R}^{l_p\times d_{\text{model}}}$，作为**动态软提示**直接前置于当前观测的输入嵌入（或在选定注意力层前置到 KV 缓存），避免逐层改造的开销；RL 梯度虽不更新 $\theta$，但可穿过冻结 LLM 的计算图回传至控制器。
- **树动作头**：$\pi_{\text{tree}}(\cdot\mid u_t)=\text{Softmax}(W_{\text{tree}}u_t)$，采样离散拓扑操作，分为两类执行：
  - **即时执行（高频）**：`insert` 时以 $e_{\text{new}}=W_{\text{ins}}u_t$ 作为检索到的叶节点 $n_d$ 的子节点；`update` 时用门控 $\alpha=\sigma(W_{\text{gate}}u_t)$ 精炼叶节点 $e_d\leftarrow(1-\alpha)e_d+\alpha W_{\text{upd}}u_t$；新节点/更新节点均做 L2 归一化以防表示坍缩。
  - **延迟执行（低频，回合末）**：计算节点情节效用 $S(n_i)$（同回合多次激活取平均以防过度奖励高频循环），EMA 平滑后剪除低于 $\tau_{\text{del}}$ 的节点（子节点直接重挂到父节点以保拓扑连通），并对相似度 $>\tau_{\text{merge}}$ 的兄弟节点做平均池化融合。
- **在线/离线解耦**：解码时检索基于**时间冻结的树快照**，树动作先缓存、轨迹结束后异步提交，避免并发拓扑变更导致的检索不一致。

**（3）训练配方（GRPO）**

- 无需 critic；对同一提示采样一组轨迹 $G$。
- 引入可验证过程监督，节点效用含逐步奖励与最终回报：$S(n_i)=\sum_k\gamma^{k-t_i}r_k$。
- 层次化优势：$A_i=\lambda_g\frac{S(n_i)-\mu_G(S)}{\sigma_G(S)+\epsilon_0}+\lambda_l(S(n_i)-S(pa(i)))$——全局项鼓励任务级有用性，局部项保留相对父节点的专门化。
- 联合目标：$\mathcal{L}(\phi)=\mathcal{L}^{\text{latent}}_{\text{GRPO}}(\phi)+\lambda\mathcal{L}^{\text{tree}}_{\text{GRPO}}(\phi)$，两者均采用裁剪代理目标；潜在项含 KL 惩罚防策略崩溃；梯度共享累加，作者称未观察到训练不稳定。
- 深度感知折扣 $\tilde A_i=\gamma^{d_i}A_i$。
