## 摘要
大语言模型在静态推理中展现出卓越能力，但通过强化学习（RL）将其训练为面向长时程任务的自主智能体时，往往受到严重奖励稀疏的阻碍。尽管传统的通过监督微调（SFT）进行的智能体侧预热可以缓解这一问题，但其常常受限于数据稀缺和探索受限。为此，我们提出一种范式转变，转向环境侧自适应，即构建反馈增强环境（FEEs）。通过一项初步研究，我们建立了一种反馈设计策略，通过在回合内探索和回合间演化的后期阶段从动作指导转向观测丰富来重构环境。在 SciWorld 和 BFCL 基准上，使用不同规模的 Qwen3 模型以及 GRPO、GSPO 和 DAPO 等 RL 算法进行的大规模实验表明，FEEs 相比标准设置持续带来性能提升。此外，我们的分析揭示，使用 FEEs 训练能够 (1) 通过降低熵波动来稳定训练动态，(2) 促进困难任务中的主动状态空间探索，(3) 确保环境指导内化到策略权重中，而非仅作为推理时先验，(4) 将组内反馈一致性识别为稳定优化的关键边界。

## Abstract
Large Language Models demonstrate remarkable proficiency in static reasoning, yet training them as autonomous agents through Reinforcement Learning (RL) for long-horizon tasks is often hindered by severe reward sparsity. While conventional \textit{agent-side warming} up via supervised fine-tuning (SFT) can alleviate this, it is frequently limited by data scarcity and constrained exploration. To address this, we propose a paradigm shift to \textit{environment-side adaptation} by constructing \textbf{F}eedback-\textbf{E}nriched \textbf{E}nvironments (\textbf{FEEs}). Through a pilot study, we establish a feedback design strategy that reformulates environments by transitioning from action guidance to observation enrichment during the later stages of both intra-episode exploration and inter-episode evolution. Large-scale experiments on SciWorld and BFCL benchmarks using various Qwen3 model scales and RL algorithms such as GRPO, GSPO, and DAPO demonstrate that FEEs consistently yield performance improvements over standard settings. Furthermore, our analysis reveals that training with FEEs \textbf{(1)} stabilizes training dynamics by reducing entropy volatility, \textbf{(2)} facilitates proactive state-space exploration in difficult tasks, \textbf{(3) }ensures the internalization of environmental guidance into policy weights rather than acting as a mere inference-time prior, and \textbf{(4) }identifies intra-group feedback consistency as a critical boundary for stable optimization.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：LLM 在数学推理、代码生成等静态单轮任务上表现优异，研究重心正转向构建能在动态复杂环境中自主探索的**长时程智能体**（如网页导航、终端操作）。这类任务通常需要数十步交互才能完成，RL 成为主流训练范式。
- **核心痛点**：长时程任务中 RL 面临严重的**奖励稀疏**问题——智能体缺乏有效探索能力，容易陷入零奖励轨迹，导致梯度消失、无学习信号。
- **现有方案的局限**：传统的**智能体侧预热**（用专家轨迹做 SFT）虽能提高初始正奖励概率，但存在两大瓶颈：
  - 真实轨迹采集昂贵、难以规模化；
  - 过度优化 SFT 目标会约束智能体行为，反而削弱 RL 所需的探索潜力。
- **本文主张的范式转变**：不再寻求"更好初始化的智能体"，而是转向**环境侧适配**（environment-side adaptation），通过系统性地丰富环境反馈信号来构建**反馈增强环境（Feedback-Enriched Environments, FEEs）**，在 RL 训练中充当"脚手架"。

## 2. 方法论：核心思想与关键技术细节

### 2.1 问题形式化
- 环境建模为**目标条件 POMDP**：$e_\phi = (\mathcal{G}, \mathcal{S}, \mathcal{A}, O, \mathcal{T}, r)$。
- 智能体在部分观测 $o_t$ 和历史 $h_t$ 下生成文本动作 $a_t \sim \pi_\theta(a_t \mid g, o_t, h_t)$，轨迹级二值奖励 $r_\tau$。
- **反馈增强**定义为对观测空间的干预：$o^+_t = \mathcal{E}(o_t, h_t)$，形成增强环境 $e^+_\phi$，从而隐式重塑动作分布、调节任务难度并鼓励轨迹多样性。

### 2.2 反馈设计的两个维度
| 维度 | 分类 | 说明 |
|---|---|---|
| **提供什么信息** | 动作引导（AG） | 在反馈中嵌入程序性提示，缩小策略搜索空间（如"进入实验室"），剪除无关探索分支 |
| | 观测丰富（OE） | 为原始观测补充语义信息，缓解部分可观测性（如"阴极仍未通电"） |
| **何时提供** | 回合内探索（Intra-episode） | 单条轨迹的 $T$ 步交互过程中，早期 vs. 后期注入 |
| | 回合间演化（Inter-episode） | 整个训练生命周期中，能力有限的早期 vs. 熟练后的后期注入 |

### 2.3 核心策略（初步研究得出的设计结论）
- **动作引导（AG）整体优于观测丰富（OE）**：AG 通过规定有效下一步直接剪枝搜索空间，绕过探索瓶颈；OE 认知负荷更高，需要隐式学习特征到动作的因果映射，过程更慢。
- **"丰富什么"决定"何时丰富"**：AG-Early 早期更优，OE-Late 后期呈陡峭上升趋势——AG 适合早期剪枝组合搜索空间，OE 需要基础策略才能解读新增语义。
- **混合策略最优**：前 100 步用 AG-Early 引导探索，后 100 步切换到 OE-Late 精炼策略，取得最高成功率。
- **最终通用策略**：*在智能体-环境交互与智能体演化两个过程中，早期用动作引导启动探索，后期用观测丰富进行高级策略精炼。*

### 2.4 Agentic RL 训练流程
- 采样 $N$ 条候选轨迹，基于组内统计计算轨迹级优势 $A(\tau_k)$，并均匀分配给该轨迹所有智能体生成的 token；环境生成的 token 被掩码，梯度仅由智能体动作估计。
- 支持三种算法：**GRPO**（组相对优势，无 critic）、**DAPO**（clip-higher + 动态采样，过滤零方差组）、**GSPO**（序列级重要性比率）。

## 3. 实验设计

### 3.1 数据集 / 场景与 Benchmark
- **SciWorld**：交互式文本环境，评估智能体设计并执行基础科学实验的能力；动作引导 = 具体有效动作，观测丰富 = 实时任务进度追踪。
- **BFCL-v3 Multi-Turn**：评估多轮对话中通过预定义 API 处理动态真实用户交互的能力；动作引导 = 附加在用户查询后的建议动作，观测丰富 = 工具调用返回内容的扩展。覆盖 Vehicle Control、Trading Bots、Travel Booking、Gorilla File System 四个领域（Gorilla File System 和 Vehicle Control 用于训练，Trading Bots 和 Travel Booking 留作留出评估）。
- 每回合限制 15 步，训练 200 步，增强操作以 0.5 概率随机施加，评估任务与训练严格不重叠。

### 3.2 对比方法与基线
- **模型**：Qwen3-4B、Qwen3-8B（另含 Qwen3-4B-Thinking-2507 用于初步研究）。
- **RL 算法**：GRPO、DAPO、GSPO。
- **性能天花板基线**：GPT-5.4、Kimi-K2-Thinking、Qwen3-235B-Thinking。
- **核心对比**：FEEs 训练 vs. 标准环境训练（相同算法、相同模型）。

### 3.3 主要结果
- RL 训练显著缩小开源模型与顶级闭源模型的差距：Qwen3-4B 从 23.58% 提升到 47.81%，Qwen3-8B 从 27.18% 提升到 48.11%，超过 Qwen3-235B-Thinking，接近 GPT-5.4。
- FEEs 在所有模型规模、算法、基准上**一致优于标准环境**，平均提升 **2.82%**（如 Qwen3-8B + GSPO 在 SciWorld 上从 53.91% → 60.94%；Qwen3-4B + GRPO 在 BFCL-Base 上绝对提升 10.00%）。
- **反向发现**：FEEs 可能导致智能体过度依赖环境反馈，削弱对输入上下文的质疑能力——在 Miss Param（缺失参数）和 Miss Func（无可用工具）任务上出现性能回退（如 Qwen3-4B + DAPO 从 41% → 34%）。

## 6. 主要结论与发现

1. **性能提升**：FEEs 在多种模型规模（Qwen3-4B/8B）、多种 RL 算法（GRPO/DAPO/GSPO）、两个基准上一致优于标准环境，平均提升 2.82%。
2. **训练稳定性**：FEEs 显著延迟或阻止策略熵的过早崩溃——无熵正则化时，增强环境训练 300 步熵保持稳定，而标准环境约 250 步时骤降至零；有熵正则化时，增强环境维持近 200 步稳定，标准环境约 130 步即崩溃。
3. **状态空间探索**：FEEs 提升训练期探索效率（绿色高成功率方格密度更高），且该能力可迁移到标准环境——在 hard 难度环境中提升 4.3%，表明智能体发展出更主动的探索策略，能在无增强反馈时导航低概率状态。
4. **反馈内化**：FEE 训练的智能体在标准环境中对增强反馈选项赋予更高概率，说明环境引导被**内化进策略权重**，而非仅作为推理时先验。
5. **组内反馈一致性**：组内一致的反馈带来稳定上升的成功率，而组内随机多样化反馈导致剧烈震荡。原因在于组基 RL 的优势估计在采样组内进行，组内过度随机性会扭曲优势估计，产生噪声优化信号。
6. **边界与代价**：FEEs 可能让智能体过度倾向跟随交互线索、优先执行而非必要澄清，在需质疑输入充分性的场景（Miss Param、Miss Func）产生性能回退。

## 7. 优点（方法与实验设计亮点）

- **范式创新**：将解决奖励稀疏问题的焦点从"智能体侧预热"转向"环境侧适配"，提出了正交于现有智能体中心优化算法的补充框架，思路新颖且实用。
- **系统性的反馈设计策略**：不是简单堆砌提示，而是明确划分"提供什么（AG vs. OE）"与"何时提供（回合内 vs. 回合间）"两个维度，并通过初步研究得出可操作的阶段性切换策略（AG-Early → OE-Late）。
- **实验证据链完整**：除性能指标外，还从熵动力学、探索热力图、探针实验、组内一致性四个角度深入剖析机制，回答"为什么有效"而非仅"是否有效"。
- **公平性与严谨性**：评估任务与训练任务严格不重叠；使用多种 RL 算法交叉验证，排除算法特异性；引入顶级专有模型作为性能天花板参照。
- **坦诚报告负面结果**：明确指出 FEEs 在 Miss Param/Miss Func 任务上的性能回退，并给出机理解释。
- **开源代码**：提供 GitHub 仓库，便于复现与后续研究。

## 8. 不足与局限

- **环境特定设计，缺乏自动化**：构建 FEEs 需要针对每个环境进行人工设计（阶段划分、超参数设定）。early/late 阶段的定义、切换点、增强概率等均为人工指定，其敏感性与最优配置尚未探索。
- **基准覆盖有限**：仅在 SciWorld 和 BFCL 上验证，未在更广泛的智能体基准（如网页导航、终端操作、GUI 自动化等）上评估，策略的泛化能力论证不充分。

- **过度依赖风险**：FEEs 可能诱导智能体盲从交互线索，在需要澄清缺失信息或质疑工具可用性的场景下性能下降（Miss Param、Miss Func），存在应用限制。
- **算力信息缺失**：论文未报告 GPU 型号、数量与训练时长，难以评估计算成本与可复现门槛。
- **奖励信号单一**：所有实验均基于二值轨迹级奖励，未探讨在更细粒度或稠密奖励下 FEEs 的表现，也未讨论组内反馈一致性要求与多样化探索之间的权衡机制。
