## 摘要
长时间运行的LLM智能体需要能够在多次交互中维持连贯内部状态的记忆机制。我们研究一种生命周期标注的记忆设置，其中写入片段在训练期间提供生命周期元数据，而在评估期间使用相位感知读出。该设置反映了区分应跨未来交互持续产生影响的信息与仅应影响当前上下文的信息的需要。这些生命周期之间的不匹配可能导致临时信息覆写持久知识，从而在持久性智能体中引发行为漂移。在该设置下，我们提出LifeFuse-Mem，一种生命周期感知的神经记忆框架，它根据信息的时间承诺来分离信息。LifeFuse-Mem使用专用记忆组件和生命周期感知更新，使稳定知识与瞬态知识能够在局部演化，而不会将临时上下文转化为持久状态。在受控的抗覆写基准上，LifeFuse-Mem提高了采集受控的保持率并减少了临时覆写；在两个公开的长期记忆基准上，它保持广泛竞争力。这些结果表明，显式生命周期信号有助于诊断和缓解紧凑在线记忆中的覆写。

## Abstract
Long-running LLM agents require memory mechanisms that maintain coherent internal states across interactions. We study a lifecycle-labeled memory setting in which write episodes provide lifecycle metadata during training, and phase-aware readout is used during evaluation. This setting reflects the need to distinguish information that should remain influential across future interactions from information that should affect only the current context. A mismatch between these lifecycles can cause temporary information to overwrite durable knowledge, leading to behavioral drift in persistent agents. Within this setting, we introduce \textbf{LifeFuse-Mem}, a lifecycle-aware neural memory framework that separates information according to its temporal commitment. LifeFuse-Mem uses dedicated memory components and lifecycle-aware updates to allow stable and transient knowledge to evolve locally without converting temporary context into durable state. On the controlled anti-overwrite benchmark, LifeFuse-Mem improves acquisition-controlled retention and reduces temporary overwrite; on two public long-memory benchmarks, it remains broadly competitive. These results suggest that explicit lifecycle signals can help diagnose and mitigate overwrite in compact online memory.

# LifeFuse-Mem 论文总结

## 1. 核心问题与整体含义

- **研究背景**：基于 LLM 的智能体正从短时助手演变为持续交互的长期系统，需要记忆机制在上下文窗口之外维持用户偏好、行为策略与累积知识等连贯内部状态。
- **核心矛盾**：智能体记忆中的信息在"时间有效性"上本质不同——部分信息应跨未来交互持续生效（永久/持久知识），部分信息仅应影响当前情境（临时/瞬态假设）。现有记忆系统（如 δ-Mem、Titans 等）将二者压缩进同一共享潜状态并采用统一更新动态，忽视了这一"生命周期"维度。
- **失效模式定义**：论文将这种生命周期错配导致的问题命名为 **temporary overwrite（临时覆写）**——临时信息被写入后覆盖或重排了持久知识的证据，使后续永久性查询返回临时值，造成持久智能体行为漂移、一致性下降与用户信任受损。
- **典型案例**：智能体长期策略为"外部操作前需用户确认"，但在某次调试会话中用户临时指令"本次全部在沙箱内，跳过确认"。生命周期无关的记忆会把该临时指令当作持久更新写入，导致后续任务中智能体持续跳过确认。
- **整体含义**：防止临时覆写不能仅靠增大记忆容量或改进检索，而需要一种**显式按信息生命周期分离**的记忆架构，将稳定知识与瞬态知识在写入、训练与读出三个层面隔离。

## 2. 方法论

### 2.1 核心思想
LifeFuse-Mem 在现有紧凑在线记忆（基于 δ-Mem 的低秩关联状态）之上加入"生命周期边界"，由三部分组成：
1. 学习**可塑/稳定子空间划分**；
2. 用**监督式永久路由器**控制写 token 对稳定行的更新强度；
3. 在受控覆写归因协议下使用**阶段感知的受保护状态融合与生命周期读出**。

### 2.2 关键技术细节

- **生命周期感知子空间划分**
  - 不采用固定的原始秩维度切分，而是为每个注入的记忆模块学习一个方阵 $R_l$，并在前向传播中通过 QR 分解正交化得到基 $Q_l = \mathrm{orth}(R_l)$，满足 $Q_l^\top Q_l = I$。
  - 将读向量、键、值旋转到该基：$\tilde q_t = Q_l^\top q_t^m$，$\tilde k_t = Q_l^\top k_t^m$，$\tilde v_t = Q_l^\top v_t^m$。
  - 前 $r_A$ 个坐标定义为**可塑子空间 A**，剩余 $r_B = r - r_A$ 个为**稳定子空间 B**；实验取 $r=8$、$r_A=r_B=4$。
  - 用正交正则项 $L_{orth} = \frac{1}{L r^2}\sum_l \|R_l^\top R_l - I\|_F^2$ 保持子空间可分离性。

- **记忆状态读写（基于 δ-Mem 的仿射更新）**
  - 读取：$z_t = S_{t-1}\tilde q_t$。
  - 更新：$S_t = \kappa_t \odot_{row} S_{t-1} - \epsilon_t \odot_{row}[(S_{t-1}\tilde k_t)\tilde k_t^\top] + \omega_t \odot_{row}[\tilde v_t \tilde k_t^\top]$，其中 $\kappa_t, \epsilon_t, \omega_t \in \mathbb{R}^r$ 为逐行保留/擦除/写入系数。

- **永久路由与子空间写入**
  - 对每个写 token 预测永久路由权重 $\rho_t = \sigma(w_r^\top h_t + b_r)$。
  - 路由监督来自 episode 元数据：永久示例的合法写 token 标 $y_i=1$，临时示例标 $y_i=0$，无生命周期标签的示例被掩码；损失为 $L_{route} = -\frac{1}{|\Omega|}\sum_{(i,t)\in\Omega}[y_i\log\rho_{i,t} + (1-y_i)\log(1-\rho_{i,t})]$。
  - 行缩放 $a_{t,j}$：可塑行恒为 1；稳定行取 $a_{t,j} = a_{tmp} + \rho_t(a_{perm} - a_{tmp})$，主实验用 $a_{tmp}=0$、$a_{perm}=1$。
  - 由此系数变为 $\kappa_{t,j} = 1 - a_{t,j} + a_{t,j}\lambda_{t,j}$，$\epsilon_{t,j} = \omega_{t,j} = a_{t,j}\beta_{t,j}$，即高 $\rho_t$ 的 token 可同时更新两类行，低 $\rho_t$ 的 token 主要更新可塑行。
  - 另加**子空间键隔离**：普通在线写入时稳定键坐标衰减至 0.5。

- **情节式写后读训练目标**
  - 模型先消费写消息更新记忆至 $S_{write}$，然后在**禁用进一步写入**的条件下回答最终目标，迫使答案依赖已存储状态。
  - 总损失：$L = L_{CE} + \lambda_{route}L_{route} + \lambda_{orth}L_{orth} + \lambda_{hc}(u)L_{hc} + \lambda_{ret}L_{ret} + \lambda_{sp}L_{sp}$。
  - $L_{hc}$ 为硬候选损失，要求错误候选的交叉熵比正确候选至少大 $m_{hc}$；$L_{ret}$ 为永久示例的保留排序损失；$L_{sp}$ 为稀疏惩罚，将平均写门控拉向 $\beta_0=0.05$。

- **受保护状态融合与生命周期读出（仅用于受控协议）**
  - 对 Phase A 后的状态 $S_A$ 与覆写后的状态 $S_{AB}$，构造稳定行受保护状态 $S_{stable}$：可塑行取自 $S_{AB}$，稳定行取自 $S_A$。
  - 永久查询：分别用 $S_A$ 与 $S_{stable}$ 打分，融合分数 $s_{fuse}(y) = \alpha s_A(y) + (1-\alpha)s_{stable}(y)$，取 $\hat y = \arg\max s_{fuse}(y)$，主实验 $\alpha=0.70$。
  - 临时查询：不做保护或融合，直接用覆写后的 $S_{AB}$ 打分。
  - 强调该组件**并非自主生命周期发现**，而是利用已知相位边界与查询生命周期的诊断性读出。

- **评价指标（采集受控）**
  - 仅在被正确采集（$A_i=1$）的永久事实上计算：$Ret_{acq} = \frac{\sum_i \mathbf{1}[A_i=1 \wedge R_i=1]}{\sum_i \mathbf{1}[A_i=1]}$；覆写率 $Ovr$ 统计同一子集中返回冲突临时值的比例。
