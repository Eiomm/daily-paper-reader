## 摘要
自动驾驶中的安全运动规划需要预判不断演变的交通风险，并决定何时修订当前规划的轨迹。我们提出 RiskWorld，一个风险感知的世界建模框架，用于共享占据预测与选择性轨迹替换。空间风险场与时间维度上的交通参与者上下文，与视觉鸟瞰图特征相融合。流引导的演化传输占据与场景特征，而带符号残差在传输后对占据进行校正。每个规划步骤生成一次预测，并在各候选轨迹间复用。每个候选轨迹与当前状态持久性参考进行比较，得到非负的碰撞分数校正。由当前世界评估选出的轨迹作为规划锚点，仅当额外的预测风险触发干预，并且某个替代轨迹满足对预测风险和轨迹误差的逐分量约束时，才会被替换。候选轨迹的几何形状保持不变。我们在 nuScenes 上使用相机特征、由标注导出的当前与历史交通参与者状态以及数据集提供的地图上下文，对 RiskWorld 进行开环规划评估。RiskWorld 在 3 秒的较长评估时域下取得最低碰撞率，并在多种最先进基线中取得第二优的平均 L2 误差，同时在单块 NVIDIA RTX 4090 上以 11.5 FPS 运行，参数量为 90.81 M。同设置下的消融实验表明，RiskWorld 比当前状态重评分基线取得更低的碰撞率，同时预测复用使得能够以较低的边际计算成本评估更多候选轨迹。

## Abstract
Safe motion planning in automated driving requires anticipating evolving traffic risks and deciding when to revise the current planned trajectory. We introduce RiskWorld, a risk-aware world modeling framework for shared occupancy forecasting and selective trajectory replacement. Spatial risk fields and temporal actor context are fused with visual bird's-eye-view features. Flow-guided evolution transports occupancy and scene features, while signed residuals correct occupancy after transport. One forecast is generated per planning step and reused across candidates. Each candidate is compared with a current-state persistence reference, yielding a nonnegative collision-score correction. The trajectory selected by current-world evaluation serves as the planning anchor and is replaced only when additional predicted risk triggers intervention and an alternative satisfies component-wise constraints on predicted risk and trajectory error. Candidate geometries remain unchanged. We evaluate RiskWorld for open-loop planning on nuScenes using camera features, annotation-derived current and historical actor states, and dataset-provided map context. RiskWorld achieves the lowest collision rate at a long evaluation horizon of 3 s, and the second-best average L2 error among various state-of-the-art baselines, while running at 11.5 FPS on a single NVIDIA RTX 4090 with 90.81 M parameters. Within-setting ablations show that RiskWorld achieves lower collision rates than the current-state rescoring baseline, while forecast reuse enables additional candidates to be evaluated at low marginal computational cost.

## 1. 核心问题与研究背景

- **核心痛点**：自动驾驶安全规划必须预判交通场景的时序演化。仅基于当前观测判断无碰撞的轨迹，仍可能与周围交通参与者的未来路径相交（如邻车道车辆切入自车预定路径）。
- **现有工作的缺口**：占据预测（FIERY、OccWorld 等）和世界模型（Drive-WM、ResWorld 等）能给出未来场景状态，但"预测出合理的未来"本身并不构成改变已选轨迹的理由——未来风险分数可能只是重复了当前场景评估已捕获的风险。
- **关键科学问题**：如何区分「场景演化带来的**额外**预测暴露」与「当前评估已包含的风险」，并据此判断是否值得干预、以及干预时如何保证替代方案在风险与轨迹误差上都不劣化。
- **整体含义**：论文将"世界建模"与"轨迹选择"解耦为**共享预测 + 选择性替换**两件事，主张在固定候选集内、以当前状态持续性为参照，谨慎地做最小干预，从而在长时域（3 s）安全性与推理效率之间取得平衡。

## 2. 方法论

### 2.1 核心思想
- 构建**风险感知世界表示**：把空间驾驶风险场（DRF）、时序参与者上下文与视觉 BEV 特征对齐融合，得到当前世界表示 `W0`。
- 用**流引导的占据演化**从 `W0` 推演未来占据与场景特征 `{(Ot, St)}`，每个规划步只算一次并**被所有候选共享**。
- 用**持久性参照干预（PRI）**比较候选在未来场与"当前状态重复参照"上的查询差异，产生**非负**碰撞分数校正。
- 由当前世界评估选出**锚点轨迹**，仅当额外预测风险触发干预且存在满足逐分量约束的替代候选时才替换，**候选几何不变**。

### 2.2 关键细节与流程

**（a）风险场构造**
- 在 BEV 域上定义非负标量势 `rt: Ω → R≥0`，栅格化为多通道风险张量 `Rτ`：静态地图风险（不可行驶区惩罚、道路/车道线、人行横道、路缘邻近势）、参与者占据（按车辆/行人/骑行者分组栅格化并求和）、运动诱导风险、成对交互与 TTC 启发式风险、聚合场。
- 单个参与者的运动风险势采用**朝向框架下的各向异性高斯**：`φi(x) = Ai·ωi(x)·exp[−(ui²/(si,x²+ε)) − (vi²/(si,y²+ε))]`，其中 `Ai` 为类别幅值、`ωi` 为速度相关方向权重、`si,x/si,y` 为受尺寸/运动状态/类别决定的长横向尺度，`εker` 保证数值稳定；经空间截断与可行驶区加权后按类别累加归一化。
- 复合场用对数压缩 + 5%–95% 空间分位缩放并裁剪到 [0,1]；分位退化时回退到最大值缩放。

**（b）时空编码与视觉融合**
- 共享卷积编码器 → 空间 token 网格；时序自注意力聚合历史，残差 MLP 注入地图 token；GRU 编码 actor/ego 历史，以风险 token 为 query 做交叉注意力；空间残差混合器融合邻域。
- 视觉特征来自 GeoBEV（ResNet-50 主干），风险特征重采样到视觉网格并做通道对齐。
- 融合残差：`Δ = fΔ([V, R, |V−R|, V⊙R, M])`，最终 `W0 = R + G⊙Δ`，`G = gM + (1−M)`，即在风险覆盖区用系数 `g∈(0,1)` 缩放残差，覆盖外施加完整残差。

**（c）候选集构造**
- 用训练集真值 ego 轨迹相对"保持当前速度的直线参考"聚类残差，学习轨迹码本；推理时按 ego 速度与导航命令选组，取 10 个残差原型加 2 个确定性低速运动学候选，共 **K = 12** 条候选，每条含 3 s 时域内 6 个 0.5 s 间隔位姿。

**（d）流引导占据演化**
- 初始化：`S0 = fscene(W0)`，`O0 = σ(fO(S0))`，运动状态 `m0 = C = S0 + fC(W0)`，`C` 在整个 rollout 中固定作为当前场景上下文。
- 每步由流头预测位移场 `Ft = sF·tanh(fF(mt−1))`；**同一位移**对占据、运动状态、场景特征做双线性反向 warp：`Õt = Πϵ(W(Ot−1,Ft))`、`m̃t = W(mt−1,Ft)`、`S̃t = W(St−1,Ft)`，保证后续轨迹查询采样自同一空间对应。
- 运动更新 `mt = U(C + et + ffb(Õt − O0), m̃t)`，`U` 为 ConvGRU，占据差分反馈让循环更新纳入占据演化。
- **带符号残差校正**：源/汇头预测 `Bt = fsrc(mt)`、`Dt = fsnk(mt)`，`ΔOt = α[tanh(Bt) − tanh(Dt)]`，最终 `Ot = Πϵ(Õt + ΔOt)`——允许占据在传输后增减，但不修改已传输的场景特征 `S̃t`。

**（e）持久性参照干预（PRI）**
- 每个候选在未来场 `(Ot, St)` 与"重复当前状态 `(O0, S0)`"的参照上于**相同位置**查询，查询块与足印掩码保持与当前 ego 帧对齐。
- 共享证据编码器输出特征对比 `δEk,t = EFk,t − ECk,t` 与最大足印占据对比 `δρk,t = ρFk,t − ρCk,t`；incoming-risk bridge 经时间编码得 `zk,t`，非负增益 `γk,t = [softplus(zk,t) − log2]+`。
- 碰撞分数更新：`bk,t = β·γk,t·tanh(‖δEk,t‖2/√d)·[δρk,t]+`，`pFk,t = σ(cCk,t + bk,t)`。构造上保证 `pFk,t ≥ pCk,t`；**正校正同时要求特征对比非零且最大足印占据增加**，而非局部占据变化即可。

**（f）约束式替换**
- 风险汇总：前缀 `h ∈ {1,2,3} s` 的平均 `rk,h`，加尾部项 `rk,tail = 1 − (1−pk,T−1)(1−pk,T)`（仅作决策分数，非标定联合概率）。
- 触发条件：锚点校正为正，且某分量满足 `rFkC,j > rCkC,j + η` 或 `rCkC,j ≤ τj < rFkC,j`。
- 有效替代需逐分量满足：`rFk ≤ rFkC`、存在 `j` 使 `rFk,j + η < rFkC,j`、归一化加权平均预测误差 `ℓ̄k ≤ ℓ̄kC + δmean`、前缀误差 `ℓk ≤ ℓkC + δprefix`。
- 排序目标：`Jk = wmax·max_j rFk,j + wavg·r̄Fk + ℓ̄k`，取最小者；未触发或无合格替代则保留锚点。

**（g）训练与优化**
- 分阶段：RiskExpert 预训练（未来风险场重建）→ 风险-视觉融合与当前世界打分 → 占据演化（占据监督 + 掩码 smooth-L1 位移损失 + 源/汇事件平衡 BCE）。
- 最终校准冻结表示、演化、证据编码器与当前世界打分器，**只优化 incoming-risk bridge**，特征与占据对比被 detach，预测与轨迹误差不变；损失为 BCE + Brier + 焦点损失 + 难例项 + 辅助项 + 对 `bk,t` 的二次惩罚（式 13）。

## 6. 主要结果与发现

- **主对比（表 I）**：RiskWorld 在 1 s/2 s/3 s 的碰撞率上整体优于所比较的开环规划基线，且在 3 s 长时域上的优势更明显，说明预测暴露的引入主要收益在于长时域风险规避；轨迹 L2 误差保持在同类方法可比区间，未因安全干预而显著劣化——这与"替换需满足逐分量误差约束"的设计目标一致。代价是 11.5 FPS 与 90.81 M 参数，处于中等水平，逊于若干轻量单阶段方法，但优于依赖重型占据预测的世界模型类方法。
- **RiskExpert 特征扰动（表 II）**：将风险特征零化或跨样本打乱后，碰撞率明显上升，而 L2 基本不变。这一"只动安全、不动轨迹精度"的解耦现象，直接支持了"风险表示承载的是选择性干预信号，而非轨迹生成信号"的论断。
- **PRI 与流传输消融（表 III）**：Full > No-Transport > CSR 的排序表明——（i）仅用当前状态选锚点（CSR）会遗漏动态演化风险，碰撞率最差；（ii）把预测流置零会破坏时空对应，说明收益来自"同一空间位置上的未来查询"而非仅多算了一步；（iii）二者结合（Full）才能同时降低风险与保持误差。这验证了"持续性参照"与"流引导传输"是互补而非冗余的。
- **时序顺序实验**：在固定当前帧、打乱更早帧的条件下，3 s incoming-cell 的 AUPRC 下降，证明模型确实利用了历史的时间顺序信息，而非仅靠单帧风险场。
- **候选数可扩展性**：K 从 1 增至 24 时，共享世界预测耗时几乎不变（13.76→13.87 ms），总运行时间仅小幅增长（44.16→45.20 ms），验证了"预测一次、候选共享"的设计使推理开销近似与候选数无关，为扩大候选集留出了空间。
- **定性结果**：三例场景显示，RiskWorld 相较 CSR 能提前绕开静止货车（持续性风险）并对对向/后方车辆（动态演化风险）做出更早的规避动作，且未来占据可视化中源/汇残差能合理增删区域，说明占据演化并非单纯刚性平移。

## 7. 局限与不足

- **评估范式**：全部为 nuScenes 开环评估，无法反映闭环中自车动作改变他车行为的交互效应；CR 亦非闭环碰撞率的直接代理。
- **候选集依赖**：轨迹码本从训练集残差聚类得到，推理时按速度与导航命令选组，候选集一旦不覆盖真实可行机动，替换机制便无解；K=12 的固定规模与"几何不变"约束在复杂博弈场景下可能过于保守。
- **概率语义**：尾部项 `rk,tail` 明确为决策分数而非标定联合概率，风险汇总（前缀均值 + 尾部项）缺乏概率解释，阈值的物理含义较弱。
- **训练算力不透明**：论文未披露训练 GPU 型号/数量、总时长与各阶段轮数，复现成本难以估计；视觉前端（GeoBEV/ResNet-50）的预训练开销亦未计入。
- **风险场手工设计**：各向异性高斯势的幅值、尺度、方向权重等超参数依赖先验设定，跨数据集/地区的迁移性未经检验。
- **实时性**：11.5 FPS 且不含视觉前端的计时，离车规级实时部署仍有差距。

## 8. 结论与启示

- **核心贡献**：论文提出"风险感知世界表示 + 流引导占据演化 + 持久性参照干预 + 约束式替换"的规划框架，将世界建模与轨迹选择解耦，把预测的作用严格限定为"相对当前状态提供**额外**风险证据"，并用非负校正与逐分量约束保证干预只会更安全、不会更差。
- **方法论启示**：其"共享预测 + 选择性替换"的范式可迁移到其他需要长时域预判的决策任务（如机器人导航、交互式预测规划）；"以当前状态重复为参照"的对比思想，为判别预测信息是否冗余提供了一种可操作的技术手段。
- **工程启示**：候选共享预测使推理开销与候选数近似解耦，为在算力受限平台上扩大搜索空间提供了思路；分阶段训练 + 冻结校准的策略也降低了引入新安全模块对既有轨迹质量的风险。
- **待验证方向**：闭环评估、候选集自适应扩展、风险场超参数迁移、概率标定，以及训练侧算力与复现细节的公开，是后续工作最值得补齐的几项。
