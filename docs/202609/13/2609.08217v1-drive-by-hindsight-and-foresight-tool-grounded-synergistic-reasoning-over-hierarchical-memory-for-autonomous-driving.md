## 摘要
视觉语言模型（VLMs）在自动驾驶中展现出前景，但仍存在幻觉、时空感知能力弱以及泛化能力有限等问题。近期方法通过思维链（CoT）解释、检索增强生成或静态注入工具输出来改进推理与决策。尽管这些机制丰富了上下文，模型既不能主动感知场景信息，也不会在回答后积累经验。为克服这些局限，据我们所知，我们提出了首个在闭环推理中将分层记忆与主动工具调用紧密耦合的协同框架。我们的贡献有三方面。(i) 分层驾驶记忆：场景级短期记忆维护动态场景状态，而不断演化的长期记忆检索可复用的经验与工具策略。(ii) 记忆-工具协同推理框架：在场景状态和检索经验的引导下，模型在推理时自适应调用工具以精化其推理，并在离线状态下将可复用经验整合到长期记忆池中。(iii) 数据生成与两阶段训练流程：由多步教师 rollout 构建的、经验证的记忆-工具轨迹被用于通过 SFT 和 GRPO 进行训练。我们的 7B 模型在 DriveLMM-o1 上达到 80.03 的总体推理得分和 79.09% 的 MCQ 准确率，超过最强基线 7.74 个 MCQ 百分点，并在多个基准上展现出强泛化能力。值得注意的是，消融与分析研究验证了每个组件的有效性，并进一步揭示了分层记忆的互补作用。短期记忆增强了时空理解，使 STSBench 准确率提高 24.2 个百分点；而在所有参数冻结的情况下，离线长期记忆整合额外带来 3.57 个百分点的 MCQ 增益，展示了通过积累驾驶经验实现的持续自我进化。

## Abstract
VLMs have shown promise for autonomous driving, yet still suffer from hallucination, weak spatio-temporal perception, and limited generalization. Recent methods improve reasoning and decision-making through CoT explanations, retrieval-augmented generation or the static injection of tool outputs. Although these mechanisms enrich the context, the model neither proactively perceives scene information nor accumulates experience after answering. To overcome these limitations, we present, to our knowledge, the first synergistic framework that tightly couples hierarchical memory with proactive tool invocation in a closed reasoning loop. Our contributions are threefold. (i) Hierarchical Driving Memory: a scene-level short-term memory maintains the dynamic scene state, and an evolving long-term memory retrieves reusable experience and tool strategies. (ii) Memory-Tool Synergistic Reasoning Framework: guided by the scene state and retrieved experience, the model adaptively invokes tools to refine its reasoning at inference time and consolidates reusable experience into a long-term memory pool offline. (iii) Data Generation and Two-stage Training Pipeline: verified memory-tool trajectories built by multi-step teacher rollout are used to train with SFT and GRPO. Our 7B model reaches an overall reasoning score of 80.03 and MCQ accuracy of 79.09% on DriveLMM-o1, surpassing the strongest baseline by 7.74 MCQ points and generalizes strongly across benchmarks. Notably, ablation and analysis studies validate the effectiveness of each component and further reveal the complementary roles of hierarchical memory. Short-term memory strengthens spatio-temporal understanding, improving STSBench accuracy by 24.2 points, while offline long-term memory consolidation yields an additional 3.57-point MCQ gain with all parameters frozen, demonstrating continual self-evolution through accumulated driving experience.

  - 思维链（CoT）：让模型生成更详细的解释，但只是模板化展开；
  - 检索增强生成（RAG）：被动注入外部知识；
  - 静态工具输出注入（如 AgentThink）：一次性将预计算工具结果拼入上下文。
  - 三者本质都是"单向、被动接收信息"，模型的理解**不会随证据增长而演化**，也不会在回答后积累经验。
- **人类驾驶的参照**：驾驶决策不是对静态帧的一次性识别，而是**主动感知 + 时空理解 + 经验积累**的统一过程——依赖"前瞻"（foresight）跟踪自车与关键对象的运动趋势，依赖"后见"（hindsight）调用长期积累的可迁移经验。
- **核心研究问题**：能否构建一个统一的闭环推理框架，将时空感知、主动感知与经验积累整合起来，从而同时捕捉人类驾驶的"前瞻"与"后见"特征？
- **整体含义**：论文主张自动驾驶 VLM 研究应从"扩展静态感知与孤立推理"转向"持久的、可交互、能随证据与经验演化的驾驶智能"。

## 2. 方法论

### 2.1 核心思想
提出**分层记忆上基于工具的协同推理框架**：场景级短期记忆（STM）维护当前时空状态，跨场景长期记忆（LTM）检索可复用经验；模型以分层记忆为条件，在推理时**主动调用工具**获取证据，并通过 Think–Action–Observation–Update 循环迭代，直至证据充分后作答；离线再将验证过的经验固化进 LTM。

### 2.2 关键技术细节

**(1) 分层驾驶记忆**

- **场景级短期记忆 $M_s$**：
  - 输入相邻两个时刻的六视角观测 $I_{t-1}, I_t$；
  - 用预训练 BEV 感知模型（HERMES 风格）编码为自车中心 BEV 表示，输出结构化语义描述 $d_\tau$ 与场景属性 $n_\tau$（位置、定性关系、运动趋势）；
  - 组织为场景图：$M_s = \Phi_{graph}(d_{t-1}, d_t, n_{t-1}, n_t) = (V, R)$，节点含自车、交通参与者、道路元素，边含空间/时间/交互关系；
  - 仅在输入场景推进时刷新，单条轨迹内为**只读场景先验**。
- **跨场景长期记忆 $M_l$**：
  - 每条目 $e_i = (c_i, r_i, p^+_i, \pi^{tool}_i, w_i)$，分别表示适用场景/任务条件、风险因素摘要、可复用成功推理模式、有效工具使用策略、检索效用；
  - 检索评分：$S(e_i \mid q, M_s) = \text{sim}(E_m([q; M_s]), E_m(e_i)) + \lambda \bar{w}_i$，取 TopK 条目 $E_K$；
  - 检索时排除同场景条目（防止检索到自身场景约 40 个时间相邻帧），并剥离教师决策与数据集身份字段，保证推理安全。
- **离线整合**：从通过验证的轨迹中抽取经验，$B^+_n = \{\text{Ext}(C) \mid \text{Vrf}(C)=1\}$，$M_l^{(n+1)} = \Phi_{con}(M_l^{(n)}, B^+_n)$；对已有条目按效用信用 $g_i(C) \in \{0,1\}$ 更新 $w_i \leftarrow w_i + \eta g_i(C)$。

**(2) 记忆-工具协同推理（MTSR）**

- 轨迹定义为 $C = (x_0, s_1, \dots, s_T, y)$，其中 $s_t = (h_t, a_t, o_t, u_t)$ 分别为推理状态、动作、工具观察、修正后的场景信念；
- 初始 $x_0 = (q, I, M_s, E_K)$，$u_0 = (M_s, E_K)$；
- 每步：$(h_t, a_t) \sim \pi_\theta(\cdot \mid x_0, H_{<t})$，$a_t \in \mathcal{T} \cup \{\text{finish}\}$；
- 证据充分后输出 finish 并生成最终答案 $y \sim \pi_\theta(\cdot \mid x_0, H_{\le T})$；
- 关键：**无预定义工具序列**，记忆在单条查询内固定，仅瞬态场景信念随观察演化。

**(3) 数据生成与两阶段后训练**

- **多步教师 rollout 与验证**：教师策略 $\pi_\phi$ 从 $x_0$ 出发，检索 $M_l^{(0)}$，经 MTSR 循环生成多步轨迹；验证最终答案正确性、工具调用有效性、推理-观察一致性；验证通过的构成训练集 $D_{MTSR}$，同时整合为学生的初始 LTM。
- **阶段式 SFT 热身**：
  - Phase 1：移除执行器返回的观察，训练工具选择与参数生成；
  - Phase 2：从 Phase-1 检查点继续，使用完整记忆与工具反馈，学习基于观察的推理；
  - 统一目标 $\mathcal{L}^{(p)}_{SFT}(\theta) = -\mathbb{E}_{C \sim D^{(p)}}[\sum_{j \in Y^{(p)}(C)} \log \pi_\theta(z^{(p)}_j \mid z^{(p)}_{<j})]$，其中 $Y^{(1)}$ 含工具调用 token，$Y^{(2)}$ 含推理、动作、信念更新与最终答案；执行器返回的观察作为上下文但不计入损失。
- **轨迹级 GRPO**：
  - 从 Phase-2 检查点出发，每输入采样 $G$ 条轨迹；
  - 正确性门控奖励：联合评估最终答案正确性、相关记忆使用、有效工具交互、输出格式；辅助奖励仅在答案正确时激活；
  - 优化目标含轨迹级组相对优势与 KL 正则项（$\beta=0.001$），$\pi_{ref}$ 初始化为 Phase-2 策略。

### 2.3 工具库
- 完整工具库含 **27 个可调用函数**，论文报告实验使用其中 **20 个核心工具**，覆盖：开放词汇视觉定位、3D 几何度量、物体感知、自车状态估计、轨迹预测、占据栅格推理、地图查询。
