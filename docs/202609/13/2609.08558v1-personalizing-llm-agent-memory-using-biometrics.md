## 摘要
个性化记忆通过跨交互存储和复用用户特定数据，帮助 LLM 智能体提供稳定且定制化的辅助。然而，在多用户场景中，检索不仅需要考虑语义相似度，还需要考虑当前请求者是否与所存储记忆关联的身份匹配。我们提出 Bio-Memory，一种生物特征感知的记忆架构，其记忆检索同时取决于语义相似度和生物特征匹配。Bio-Memory 构建于 A-Mem 之上，为每条原子记忆笔记增加生物特征嵌入，并在语义排序之前利用生物特征匹配构建检索候选池。我们在 10 用户共享智能体设置下，基于 7 个人脸基准和 10 个掌纹协议，在 LoCoMo 上评估 Bio-Memory。在不同数据集上，Bio-Memory 始终能区分所有者查询和非所有者查询。在基于人脸的个人化设置下，在 CALFW 上 F1 / BLEU-1 的最大平均差距达到 27.29% / 21.15%；在基于掌纹的个人化设置下，在 MS_Blue 上相应的差距为 25.75% / 19.22%。这些结果表明，生物特征可作为共享环境中个性化记忆检索的实用控制信号。

## Abstract
Personalized memory helps LLM agents deliver stable, tailored assistance by storing and reusing user-specific data across interactions. In multi-user scenarios, however, retrieval must consider not only semantic similarity but also whether the current requester matches the identity associated with the stored memory. We propose Bio-Memory, a biometric-aware memory architecture that conditions memory retrieval on both semantic similarity and biometric matching. Built on top of A-Mem, Bio-Memory augments each atomic memory note with a biometric embedding and uses biometric matching to form the retrieval candidate pool before semantic ranking. We evaluate Bio-Memory on LoCoMo in a 10-user shared-agent setting over 7 face benchmarks and 10 palmprint protocols. Across datasets, Bio-Memory consistently separates owner and non-owner queries. Under face-based personalization, the largest average gap reaches 27.29% / 21.15% in F1 / BLEU-1 on CALFW; under palmprint-based personalization, the corresponding gap is 25.75% / 19.22% on MS_Blue. These results support biometrics as a practical control signal for personalized memory retrieval in shared environments.

# 论文总结：Personalizing LLM Agent Memory Using Biometrics（Bio-Memory）

## 1. 核心问题与研究动机

- **背景**：LLM 智能体正从一次性问答转向长期个性化助手，MemoryBank、Mem0、PersonaMem-v2、A-Mem 等记忆架构通过跨会话存储用户偏好、日程、历史交互来提升交互连续性。
- **核心痛点**：现有个性化记忆系统默认"身份"由外部提供（账号、User ID、会话边界）。但在共享环境中（智能家居、公共终端、企业助手），账号/会话状态可能被共享、复用或长期挂起，**"当前激活的 profile"并不等于"当前物理请求者"**。
- **后果**：同一句查询（如"What is my next appointment?"）应由不同用户触发时检索出完全不同的记忆。而 A-Mem 等系统仅按语义相似度排序，在多用户共享记忆池中，语义相同但属于他人的记忆会直接进入候选集，造成跨用户隐私泄露与身份错配。
- **研究问题**：能否把"物理身份证据"从事后认证前移到检索阶段，用生物特征决定哪些记忆有资格进入语义排序？
- **整体含义**：论文主张个性化记忆不仅是**相关性（relevance）问题**，更是**用户对齐（user-alignment）问题**——系统必须同时判断"什么是相关记忆"和"应该检索谁的记忆"。

## 2. 方法论：Bio-Memory

### 2.1 核心思想

- 在 A-Mem 的图结构原子笔记架构上做**轻量检索层扩展**，不改动其笔记创建、图链接与记忆演化模块。
- 为每条记忆笔记附加一个**生物特征嵌入**，把个性化从"纯语义检索"改为"语义相关性 + 生物身份匹配"的联合条件检索。
- 关键顺序：**先生物匹配构建候选池，再语义排序**。若顺序颠倒，不同用户的笔记会在同一候选集中竞争，身份一致性无法保证。

### 2.2 记忆构造

- 统一笔记表示：`mi = {ci, ti, Ki, Gi, Xi, ei, Li, bi}`，分别为交互内容、时间戳、LLM 生成的关键词、标签、上下文描述、语义嵌入、语义链接集合、存储的生物特征嵌入。
- 关键词/标签/上下文由 LLM 通过模板 `Ps1` 生成：`Ki, Gi, Xi ← LLM(ci ∥ ti ∥ Ps1)`。
- 语义嵌入：`ei = fenc(concat(ci, Ki, Gi, Xi))`，使用文本编码器。
- 生物特征嵌入 `bi` 由预训练编码器提取（人脸用 **ArcFace**，掌纹用 **CCNet**），全部 L2 归一化，用余弦相似度匹配。
- 同一对话样本的所有记忆共享同一存储模板 `bi = bgal_u`。

### 2.3 检索流程

1. **生物匹配门控**：`Mbio(bt, bi) = I[sim_bio(bt, bi) ≥ τD]`，`bt` 为查询时的实时探针生物特征嵌入，`τD` 为各生物基准上预先优化的验证阈值（取 owner / non-owner 相似度分布主峰之间的交点，并固定用于后续所有试验）。
2. **构建匹配池**：`Mt_match = {mi ∈ M : Mbio(bt, bi) = 1}`。
3. **时间排序**：`Mt_time = SortTime(Mt_match)`，保持时序连贯。
4. **语义排序**：在时间排序池内按查询嵌入与记忆嵌入的余弦相似度 `sim_sem(qt, mi)` 排序。
5. **Top-K 选取**（K 固定为 10）：`Rt = TopK(...)`；若 `Mt_match = ∅`，则 `Rt = ∅`。
6. **响应生成**：`Ct = Format(Rt)`，`ŷt = LLM(qt, Ct)`；当检索集为空时，模型退回仅依赖参数化知识作答，不注入任何个人记忆。

### 2.4 角色设定

- **Owner 条件**：探针生物特征与目标记忆的存储模板匹配，记忆参与检索。
- **Non-owner 条件**：探针不匹配，相关记忆在语义排序前即被排除。

## 3. 实验设计

### 3.1 数据与场景

- **记忆/QA 基准**：LoCoMo（长程对话记忆评测），取测试集 **10% 子集**（采样比 0.1），关注 **Multi-Hop、Temporal、Single-Hop** 三类问题。
- **生物特征基准**：
  - 人脸 7 个：AgeDB-30、CALFW、CFP-FF、CFP-FP、CPLFW、LFW、VGG2-FP（覆盖年龄、姿态、正脸等变化）。
  - 掌纹 10 个协议：CasiaM_460/700/850、IITD、MS_Blue/Green/NIR/Red、PolyU、Tongji（覆盖不同波长、接触/非接触）。
- **多用户共享场景构造**：将 10 个 LoCoMo 对话合并为单一记忆空间，形成 10 个与生物身份绑定的用户分区；每个对话绑定一个生物身份，其全部记忆共享同一 gallery 模板。Owner 查询使用同身份探针，Non-owner 使用同一共享设置内其他用户的探针。

### 3.2 评测指标与实现

- 指标：token 级 **F1** 与 **BLEU-1**（均为百分比）；Average 为三类问题的宏平均；**Avg. Gap = Owner Average − Non-owner Average**。
- 语义检索器：基于 **all-MiniLM-L6-v2** 的 sentence-transformer。
- 公平性控制：Owner 与 Non-owner 共用同一记忆库、同一检索配置、同一问题子集，**唯一变量是查询探针生物特征嵌入**。

## 6. 主要结论与发现

- **Owner 优势普遍存在**：在所有数据集、所有问题类型、两个指标上，Owner 均显著高于 Non-owner。
  - 掌纹：平均差距 F1 为 **20.13–25.75**，BLEU-1 为 **14.97–19.53**；最强为 **MS_Blue**（Owner 30.68 / 23.56 vs Non-owner 4.93 / 4.34，差距 25.75 / 19.22）。
  - 人脸：平均差距 F1 为 **23.58–27.29**，BLEU-1 为 **18.34–21.15**；最强为 **CALFW**（Owner 30.89 / 24.31 vs Non-owner 3.60 / 3.16，差距 27.29 / 21.15）。
- **过滤是选择性的而非破坏性的**：Owner 分数稳定在健康区间（掌纹 26.27/21.25–31.32/24.00，人脸 28.59/22.57–31.41/23.07），说明门控抑制了身份错配证据，同时保留了足够的用户对齐笔记。
- **Temporal 问题最敏感**：Non-owner 的 Temporal F1 在人脸仅 1.08–3.12、掌纹仅 0.36–4.23，因为一旦正确用户的事件链被移除，模型无法重建时间线。
- **跨模态一致**：人脸与掌纹在感知条件、特征变化、验证难度上差异很大，但方向性结论一致；验证质量越好，记忆边界越锐利。
- **核心机制判断**：分离发生在**答案生成之前的候选池构建阶段**，Bio-Memory 实质是记忆证据的**检索期访问控制**，而非生成结果的后期修正。

## 7. 优点

- **切入角度新颖且务实**：明确区分"会话认证"与"检索条件化"，指出一次性登录在共享/持久会话下不足，把生物特征从事前凭证扩展为检索约束。
- **架构轻量、易集成**：仅扩展 A-Mem 的原子笔记字段并在检索层插入门控，不改动底层 LLM、图链接与记忆演化逻辑，工程可迁移性好。
- **顺序设计合理**：生物匹配先于语义排序，从机制上避免跨用户笔记在候选集中竞争；空匹配池时回退到参数化知识，而非强行返回可疑记忆。

- **应用限制**：
  - 依赖稳定可获取的生物信号（人脸/掌纹采集条件），在遮挡、低光照、非配合场景下的实际可用性存疑。

  - 对"拒识"（Non-owner 落入空池）的处理是退回通用知识，可能带来用户体验与安全性的权衡，论文未深入分析。
