## 摘要
现实世界驾驶本质上是多智能体的，然而现有大多数驾驶世界模型仅从单个自车生成观测。将它们独立扩展到多辆车，并不能确保不同智能体观测到一致的共享世界。我们提出 CoDrive，一种跨车辆、多视角的驾驶视频生成框架，能够在精确的相机轨迹控制下，联合生成共享同一动态场景的多个车辆的观测。CoDrive 将局部自注意力与全局自注意力交错结合：前者建模每辆车各视角之间的时空依赖，后者实现跨车辆的信息交换与一致性建模。为显式编码其空间关系，所有相机轨迹都在共享世界坐标系中表示，并通过投影相对位置编码注入注意力层。我们进一步采用渐进式混合任务训练策略，将大规模真实世界单智能体数据与合成的跨智能体交互数据相结合，使模型既能受益于真实世界的外观分布，又能从仿真中学习跨智能体一致性。为进行系统评估，我们提出 CoDrive-Bench，一个涵盖真实与合成多车辆场景的基准，用于评估轨迹可控性、场景几何一致性和实例级一致性。实验表明，CoDrive 在保持有竞争力的视觉质量的同时，提升了轨迹可控性以及跨智能体的几何一致性和实例级一致性。

## Abstract
Real-world driving is inherently multi-agent, yet most existing driving world models generate observations from a single ego vehicle. Independently extending them to multiple vehicles does not ensure that different agents observe a consistent shared world. We present CoDrive, a cross-vehicle, multi-view driving video generation framework that jointly generates observations of vehicles sharing the same dynamic scene with precise camera-trajectory control. CoDrive interleaves local self-attention, which models spatiotemporal dependencies among the views of each vehicle, with global self-attention, which enables information exchange and consistency modeling across vehicles. To explicitly encode their spatial relationships, all camera trajectories are represented in a shared world coordinate system and injected into the attention layers through projective relative positional encoding. We further adopt a progressive mixed-task training strategy that combines large-scale real-world single-agent data with synthetic cross-agent interaction data, allowing the model to benefit from real-world appearance distributions while learning cross-agent consistency from simulation. For systematic evaluation, we introduce CoDrive-Bench, a benchmark covering real and synthetic multi-vehicle scenarios and evaluating trajectory controllability, scene geometry consistency, and instance-level consistency. Experiments show that CoDrive improves trajectory controllability and cross-agent geometric and instance consistency while maintaining competitive visual quality.

## 1. 核心问题与整体含义

- **研究背景**：视频生成模型的发展使其能够作为“世界模型”从大规模视觉数据中学习动态环境演化，自动驾驶是其中最重要的应用之一，可支撑数据生成、闭环评测、罕见事件模拟及感知/规划系统开发。
- **核心痛点**：现有驾驶世界模型几乎都只从**单个自车视角**建模驾驶世界，而真实交通环境本质上是**多智能体**的——多辆车同时从不同位置、朝向和视野观察并交互同一动态场景。
- **关键矛盾**：将单智能体模型独立扩展到多车，并不能保证不同智能体观测到的是**同一个共享世界**。独立生成会引发一系列矛盾：同一物体可能只出现在一个视角、在不同智能体间轨迹不兼容、几何位置不一致。这限制了其在协同感知、多车规划与交互式交通仿真中的应用。
- **核心目标**：提出 CoDrive，在精确相机轨迹控制下，联合生成共享同一动态场景的多车多视角观测，确保**智能体内多视角连贯**与**智能体间世界一致**两个层次的一致性。
- **整体含义**：将驾驶世界模型从“单车独立生成”推进到“多车共享世界联合生成”，并配套提出首个面向跨智能体、多视角驾驶世界模型的系统评测基准 CoDrive-Bench。

## 2. 方法论

### 2.1 核心思想
- 基于预训练隐空间视频扩散 Transformer（HunyuanVideo-1.5），通过两种互补机制将其扩展为多车联合生成：**跨智能体信息交换**与**显式共享相机几何**。
- 将共享场景建模为 N 辆车、每车 M 个前向相机，共 V = N·M 个视角；每个视角用冻结的 3D VAE 独立编码，并沿宽度轴拼接成宽隐变量 z，Transformer 在该宽 latent 的 token 序列上运行。

### 2.2 关键技术细节

- **交错全局-局部自注意力（IGLA）**：
  - *局部自注意力*：对同一辆车（智能体）的所有视角 token 做时空依赖建模，保持单车多视角结构。
  - *全局自注意力*：对跨所有智能体的宽 latent 做注意力，使一辆车的 token 能关注其他车辆的观测，协调共享场景内容。
  - 在 Transformer 各层**交错**排布：局部块保留智能体内多视角结构，全局块逐步跨车传播信息，避免用全全局注意力替换各智能体表示。

- **全局相机几何注入（GCGI，基于 PRoPE）**：
  - 所有相机不各自归一化，而是相对**同一参考相机 a₀** 表达，置于共享几何规范中：定义相对变换 Ẽₐ = EₐEₐ₀⁻¹ = CₐᵀCₐ₀。
  - 归一化焦距、去除主点后构造可逆齐次内参变换 K̂ₐ，进而得到可逆齐次特征变换 Pₐ = K̂ₐẼₐ。
  - PRoPE 将每个注意力头的 Q/K/V 特征按 4 维通道分组，对每组施加块对角变换：q′ = Pᵀq，k′ = P⁻¹k，v′ = P⁻¹v。
  - 注意力 logit 为 ⟨q′ᵢ, k′ⱼ⟩ = qᵢᵀ(PᵢPⱼ⁻¹)kⱼ，其中 PᵢPⱼ⁻¹ = K̂ᵢEᵢEⱼ⁻¹K̂ⱼ⁻¹。共享参考相机在成对算子中**精确抵消**，交互仅取决于相机 i、j 之间经内参标定的相对几何，并对世界坐标规范的选择**不变**。
  - 变换后的特征经额外注意力分支处理后，由 Pₐ 映射回，并通过零初始化投影加到预训练注意力输出上。

- **训练目标**：沿用基模型的 flow matching。给定干净宽 latent z 与高斯噪声 ϵ，构造线性插值 z_τ = (1−τ)z + τϵ，速度恒为 ϵ−z；Transformer v_θ 在文本、参考帧条件 c 与各视角相机 {Pᵥ} 下回归该速度，损失为 v_θ(z_τ, τ, c, {Pᵥ}) 与 (ϵ−z) 的 L2 距离期望。

### 2.3 训练配方（五阶段渐进式）
1. **骨干域适应**：在大规模驾驶视频上做 TI2V 训练，仅需文本标注。
2. **单车单视角相机可控训练**：在带自车相机位姿的数据上，为注意力层增加零初始化 PRoPE 分支，学习基础轨迹控制。
3. **单车多视角扩展训练**：将单视角可控模型扩展到单车三视角联合生成。
4. **多车多视角一致性训练**：仅用 CARLA 合成的 15K 双车交互样本，启用 IGLA 与 GCGI 学习跨车空间一致性。
5. **混合任务微调**：以 50%/50% 概率在真实单车多视角数据与合成多车数据间随机交替，兼顾真实外观分布与仿真学到的跨车一致性。

### 2.4 数据构建
- 真实数据来自多个开源驾驶数据集（nuScenes、Waymo、PandaSet、OpenDV-2K、CoVLA 等），用经 RL 训练的 VLM 生成文本标注。
- 合成数据基于 CARLA 构建：8 种地图场景、11 种天气、6 种车辆交互模式（路口交叉、同向跟车、对向会车、转向交互、汇入/切入、并行车道），加入随机运动扰动与背景干扰车辆，最终筛选 15K 双车交互高质量片段（含相机位姿）。仿真采用运动学轨迹回放、碰撞检测、可见性筛选（最小距离 8–34 m、至少 24 帧互相可见等）保证质量。

## 3. 实验设计

- **基准（CoDrive-Bench）**：
  - 包含 **200 个双车交互场景**（100 真实 + 100 合成），每车 3 个相机视角，共 **1200 段 RGB 视频、400 条轨迹**。
  - 真实数据取自 OpenMars 多智能体多视角数据集；合成数据用上述 CARLA 流水线采集。
  - 数据过滤：剔除两车距离过远或共视视野过小的片段，保证天气、场景类型与交互模式多样性。

- **评测维度与指标**：
  1. **轨迹可控性**：用单目深度估计 + 视觉 SLAM 恢复相机轨迹，指标为 ADE（平均位移误差）与 DTW（动态时间规整）。

  - 另报告 FVD 衡量视觉质量。

- **对比方法**：
  - 通用视频生成模型：HunyuanVideo-1.5、Wan2.2-I2V-A14B。
  - 驾驶专用世界模型：MagicDrive-V2、Cosmos3-Nano。
  - 面向合成驾驶场景的多车生成模型：ShareVerse。
  - 对每个基线提供其支持格式下的首帧与相机控制条件。

## 6. 主要结论与发现

- CoDrive 在**轨迹可控性**上取得最低 ADE（3.05）与 DTW（116）；在**场景一致性**上取得最低 CD（1.64）与 RE（0.52）；在**实例一致性**上取得最高 Hit（0.482）与最低 LE（5.81）。
- FVD 为 108.8，与最佳基线（Cosmos3 的 103.2）相当，说明跨智能体一致性提升**不以显著牺牲感知质量为代价**。
- 消融表明：移除 IGLA 会使 FVD 从 108.8 恶化至 161.2、CD 从 1.64 升至 1.77、Hit 从 0.482 降至 0.409；移除 GCGI 会使 ADE 从 3.05 剧增至 13.40、DTW 从 116 升至 688。两者互补，分别侧重跨车一致性与轨迹/空间对齐。
- 混合任务微调在真实场景上全面改善：FVD 282.9→104.3、ADE 6.86→1.53、DTW 343→61、Hit 0.560→0.646、LE 7.69→5.99。
- 在真实与合成两个 split 上 CoDrive 均领先，说明其泛化能力。

## 7. 优点

- **问题定位新颖且重要**：首次系统性地将驾驶世界模型从单车视角扩展到多车共享世界联合生成，明确了跨智能体一致性的两个层次。
- **几何注入设计优雅**：基于 PRoPE 的全局相机几何注入将跨车注意力建立在**标定后的相对相机几何**上，且对世界坐标规范选择严格不变（参考相机在成对算子中精确抵消），比仅依赖外观对应更物理合理。
- **注意力架构合理**：局部/全局注意力交错而非简单全全局替换，兼顾单车多视角结构与跨车一致性。
- **训练策略务实**：利用仿真提供稀缺的跨车监督、真实数据提供外观分布，通过渐进式五阶段 + 混合任务微调缓解仿真到真实的鸿沟。
- **基准与指标设计严谨**：CoDrive-Bench 同时覆盖真实与合成场景，三项一致性指标配套敏感性分析与评测器鲁棒性验证，观测集构造透明且与生成像素无关，保证公平配对比较。

## 8. 不足与局限

- **跨智能体监督依赖仿真**：因真实同步多车数据稀缺且采集成本高，跨车监督全部来自仿真，虽经混合微调改善真实表现，但仿真到真实的差距仍需真实跨车监督来进一步缩小。
- **计算开销增加**：PRoPE 引入了额外的注意力分支用于几何条件注入，增加了每个应用该模块的 Transformer 块的计算成本。
- **规模仅验证双车**：公式虽面向 N 辆车，但当前实现与评测仅限两车交互，扩展到更多交互车辆（以及全局注意力的可扩展性）仍是未来工作。
