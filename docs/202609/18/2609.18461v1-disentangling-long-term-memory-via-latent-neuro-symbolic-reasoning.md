## 摘要
个性化智能体需要基于长期历史交互进行推理，以推断显式偏好和隐式行为证据。早期扁平检索方法独立地对记忆片段打分，忽略了分布式信息，而当前结构化记忆框架依赖与查询无关的静态图，无法捕捉依赖上下文的关系。关键在于，原始文本记忆本质上相互纠缠且含有噪声，使得细粒度个性化和跨会话推理的计算代价过高。为此，我们提出 LGM，一种新颖的神经符号框架，将长期记忆解耦转移到连续潜在空间。具体而言，(i) 我们不再持久化固定图，而是设计了一种基于稀疏自编码器的定制潜在图构建方法。针对每个查询，它将历史交互映射为潜在记忆节点，并将记忆痕迹解耦为稀疏概念激活，动态合成查询感知的关系边权重。(ii) 随后，图编码器将查询嵌入视为条件偏好，以指导在任务特定的潜在子图上的非线性消息传递。这产生了高度表达性的记忆表示，以实现有效的激活。在长期个性化基准上的大量实验表明，LGM 在捕捉显式和隐式偏好方面显著优于最先进的基线，同时能够实现个性化响应。

## Abstract
Personalized agents are required to reason over long-term history interactions to infer both explicit preferences and implicit behavioral evidence. While early flat retrieval methods score memory fragments independently and neglect the distributed information, current structured memory frameworks rely on query-agnostic static graphs that fail to capture the context-dependent relations. Crucially, raw textual memories are inherently entangled and noisy, making fine-grained personalization and cross-session reasoning computationally prohibitive. To this end, we present LGM, a novel neuro-symbolic framework that shifts long-term memory disentanglement into a continuous latent space. Specifically, (i) instead of persisting fixed graphs, we design a tailored latent graph construction with a sparse autoencoder. Subject to each query, it maps historical interactions into latent memory nodes and disentangles the memory traces into sparse concept activations, dynamically synthesizing query-aware relational edge weights. (ii) A graph encoder then treats the query embedding as a conditioning preference to direct non-linear message passing across the task-specific latent subgraph. This yields a highly expressive memory representation for effective activations. Extensive experiments on long-term personalization benchmarks demonstrate that LGM significantly outperforms state-of-the-art baselines in capturing both explicit and implicit preferences while enabling personalized responses.

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想
- 将长期记忆的解耦与关系推理从**文本空间**迁移到**连续潜在空间**：不再持久化固定图，而是让每个查询**动态诱导**自己的潜在拓扑；记忆不再作为原始文本重放，而是压缩为紧凑的潜在前缀 token 条件化生成。

### 2.2 三大核心模块

**(i) 潜在记忆解耦（Latent Memory Disentanglement）**
- 将每个历史交互单元 $x \in H \cup \{q\}$ 映射为潜在节点 $z_x \in \mathbb{R}^d$（查询节点 $z_q$ + 记忆节点 $\{z_i\}$）。
- **多层隐藏状态聚合**：从骨干 LLM 的多个中间层（默认 $\{8,16,24,32\}$）读取隐藏状态，取均值后经掩码池化、投影、层归一化得到潜在节点。低层携带词汇线索、高层携带语义与行为抽象，隐式偏好通常存在于**混合**中。
- **稀疏自编码器（SAE）**：将稠密 $z_x$ 分解为稀疏概念编码 $c_x = S(\text{ReLU}(W_{enc} z_x))$，重建 $\hat{z}_x = W_{dec} c_x$。稀疏非负编码 $c_x$ 是显式陈述与隐式行为因素对齐的**可解释单元**，实现"记忆是关于什么"与"如何被表述"的分离。
- SAE 损失：$L_{sae} = \|\hat{z}_x - z_x\|_2^2 + \lambda \Omega(c_x)$。

**(ii) 查询条件潜在图构建（Query-Conditioned Latent Graph Construction）**
- 图 $G(q) = (V, E, \omega)$，节点集含查询与全部记忆；**边权由查询决定**：$\omega_{q \to i} = \phi(c_q, c_i) \in [0,1]$，即概念重叠的归一化值。
- 同一记忆池在不同查询下形成不同连接：某查询下无关的记忆，在另一查询下可能强连接。
- 添加自环与类型化双向查询↔记忆关系 $r_{ij}$，查询既能门控记忆也能反向接收证据。
- **关系图网络**执行 $T$ 步消息传递（默认 $T=4$）：
  - $m_i^{(t)} = \sum_{j \in N(i)} \omega_{j \to i} \psi(z_i^{(t)}, z_j^{(t)}, r_{ij})$
  - $z_i^{(t+1)} = \text{Upd}(z_i^{(t)}, m_i^{(t)})$
- 置换不变 readout 得到紧凑记忆状态 $g$，打分头产生节点级相关性 $s_i = \langle z_i^{(T)}, g \rangle$。该传播正是把多个**单独微弱的线索**沿查询激活边组合成一个推断出的隐式偏好的关键。

**(iii) 图条件推理（Graph-Conditioned Reasoning）**
- 投影器将 $g$ 映射为 $p$ 个（默认 16）软潜在前缀 token $\tilde{P}$，每个重缩放至普通 token 嵌入的范数，避免前缀主导注意力。
- 前缀拼接于查询嵌入前：$y \sim f_\theta([\tilde{P}; E(q)])$，长历史通过紧凑潜在通道影响生成，而非作为原始上下文重放。

### 2.3 训练目标
- **生成监督**（生成参考回复文本，而非选项分类）：$L_{gen} = -\sum_t \log f_\theta(y_t^\star | y_{<t}^\star, [\tilde{P}; E(q)])$。
- **证据重建**（防止潜在前缀坍缩为无信息信号）：复用 $f_\theta$ 为解码器，在固定解码指令 $\rho$ 下要求同一前缀重建支撑证据 $e^\star$：$L_{recon} = -\sum_t \log f_\theta(e_t^\star | e_{<t}^\star, [\tilde{P}; E(\rho)])$。
- **总目标**：$L = L_{gen} + L_{recon} + L_{sae}$，端到端训练。

### 2.4 算法流程（单次前向）
1. 对 $H \cup \{q\}$ 中每个单元编码为潜在节点，经 SAE 解耦为稀疏概念。
2. 计算查询与各记忆的概念重叠作为边权，构建查询特定图，执行 $T$ 步消息传递，readout 得到紧凑记忆状态 $g$。
3. 将 $g$ 投影为潜在前缀 token，拼于查询前，生成答案。训练时额外要求同一前缀重建支撑证据。

## 6. 主要结论与发现

- **性能领先**：LGM 在 Qwen2.5-7B（平均 72.28）与 Gemma3-4B（平均 66.16）上均取得最佳平均准确率，较最强基线 MemCoE 分别提升 **+11.20** 与 **+11.70**。
- **隐式偏好与长上下文增益最大**：在 PrefEval 隐式划分与 128K 长上下文设置下提升最显著，说明潜在图能组合分散的行为线索而非复制单条陈述事实。
- **低成本前沿**：由于历史被压缩为紧凑潜在状态而非重读原始上下文，LGM 在 LLM 调用数、token 消耗、TTFT 三个效率维度上均处于最低成本角落，且随上下文增至 128K 延迟保持稳定。
- **消融结论**：移除任一组件均导致性能下降；**−Reconstruct 降幅最大**（尤其隐式偏好），说明证据重建目标是保持聚合记忆可用的最关键项；−SAE 与 −GNN 也明显退化，证明稀疏概念解耦与图传播均不可少。
- **超越强专有模型**：在 PersonaMem-v2 隐式设置下，仅用 4B 开源骨干即达 62.9（32K）/ 51.9（128K），超越 GPT-5-Chat（45.6/41.4）等专有模型及同骨干的 Base/SFT/GRPO 变体与智能体记忆（55.2）。
- **潜在 token 数**：1→16 快速上升，16 处达峰值后饱和或略降，说明紧凑潜在通道已足够。
- **图状态可视化**：t-SNE 显示图状态按场景形成清晰聚类，语义相关场景更接近，表明记忆保留了用户与主题级语义结构。

- **跨论文数字可比性风险**：部分基线（标 ∗）取自 MemCoE 论文，PersonaMem-v2 使用官方报告数字，未在同一环境下统一复现

，因此跨论文数字的可比性存在风险，可能高估或低估方法间差距。
- **统计显著性缺失**：论文未报告多次随机种子运行的均值/方差，也未进行显著性检验，单次实验结果可能受初始化、数据划分与解码随机性影响。
- **超参数敏感性分析不足**：虽测试了潜在 token 数量，但对中间层选择、图消息传递步数 $T$、潜在维度 $d$、SAE 稀疏度 top-k、概念维度等关键超参缺乏系统敏感性分析，默认配置是否跨骨干、跨数据集稳健仍不明确。
- **隐式偏好推断仍有信息损失**：PersonaMem-v2 从 32K 到 128K 时性能明显下降（62.9 → 51.9），说明当历史进一步增长时，紧凑潜在状态仍可能丢失部分细粒度或长尾证据。
- **真实场景验证不足**：三个基准主要是模拟用户、人工策划偏好或合成画像，尚未覆盖真实长期交互中的噪声、冲突偏好、偏好反转、时间衰减、隐私敏感信息等复杂情况。
- **隐私与遗忘机制未讨论**：长期记忆被压缩到潜在空间后，仍可能编码敏感属性；论文未讨论如何支持用户删除、选择性遗忘、审计与合规，也未分析潜在表示的可逆泄露风险。
- **图构建依赖概念重叠**：查询-记忆边权由稀疏概念重叠决定，可能弱化否定、条件、时序、因果等关系；概念重叠高不一定等于任务相关性高，存在误连边或漏连边风险。
- **证据重建依赖标注**：$L_{recon}$ 需要支撑证据 $e^\star$，若真实部署中缺少高质量证据标注，如何以自监督或弱监督方式保持潜在前缀不坍缩仍需探索。
- **可扩展性未充分评估**：当记忆池达到数万乃至更大规模时，对全部节点编码、构图与消息传递的复杂度、检索剪枝策略、增量更新成本等未给出充分实验。
- **与专有模型对比不完全对等**：PersonaMem-v2 中与 GPT-5/GPT-4.1 等比较使用官方报告数字，且专有模型未必针对该任务微调，因此“4B 开源超越专有模型”的结论需谨慎解读。

## 9. 总体评价与启示

- **核心贡献明确**：论文将长期个性化记忆从“文本重放/静态图检索”推进到“查询感知的潜在记忆解耦 + 动态关系推理”，把记忆的选择、关联、聚合与利用统一为端到端可微过程，问题形式化具有新意。
- **方法设计有针对性**：SAE 稀疏概念编码解决显式陈述与隐式行为线索的共享空间对齐；查询条件潜在图解决静态图无法表达查询相关拓扑的问题；证据重建则针对潜在前缀坍缩这一关键失效模式。
- **实证结果有说服力**：在多个基准、多个骨干和多种强基线下取得领先，尤其在隐式偏好与长上下文场景提升显著；同时处于 LLM 调用数、token 消耗与 TTFT 的低成本前沿，显示精度与效率兼具。
- **主要风险在于可复现与落地**：训练依赖骨干微调、证据标注与较大算力；算力报告不完整、跨论文数字混用、统计显著性缺失，削弱了结论的严格可比性。
- **未来方向**：可探索更轻量的适配器/LoRA 训练、无证据标注的自监督重建、动态记忆剪枝与增量图更新、真实场景隐私保护与遗忘机制，以及将潜在图推理与外部工具/RL 策略结合。
- **总体判断**：LGM 为长期个性化智能体提供了一条有前景的技术路线，若能在真实数据、统计严谨性、隐私合规和部署成本上进一步补强，具备较强的研究与应用价值。
