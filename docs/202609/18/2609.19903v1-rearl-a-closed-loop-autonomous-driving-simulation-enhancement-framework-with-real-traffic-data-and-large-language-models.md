## 摘要
准确的仿真是自动驾驶开发的关键，但捕捉真实世界交通的复杂性仍然具有挑战性。现有依赖预定义规则或静态数据回放的仿真器难以应对动态交通。CRITICAL 使用真实交通数据和大语言模型（LLM）来调整初始仿真配置，但随着推演展开，仿真分布仍会偏离真实交通。我们提出 REARL，一种将真实交通数据与大语言模型集成的闭环仿真增强框架。对真实交通数据进行聚类，并将每个聚类中心用作代表性场景，为 LLM 提供典型的真实世界交通模式。随后，一个定时滑动窗口检测器监测车辆速度分布和车辆对之间平均间距的差异。若某项指标超过阈值，LLM 会调整车辆决策；否则保留现有控制器。LLM 还会从交通快照中选择匹配的真实车辆，并参考该真实动作来调节仿真车辆。在受控的 HighD 高速公路设置中，与 CRITICAL 基线以及基于 PPO 的学习基线相比，REARL 将速度分布的 Hellinger 距离降至 0.3067，将平均间距的 MAPE 降至 0.8371，同时实现 22.8575 的时间车头时距（THW）和 0.0708 的换道率。

## Abstract
Accurate simulation is crucial for autonomous driving development, yet capturing real-world traffic complexity remains challenging. Existing simulators that rely on predefined rules or static data playback struggle with dynamic traffic. CRITICAL uses real traffic data and a large language model (LLM) to adjust the initial simulation configuration, but the simulated distribution still diverges from real traffic as the rollout evolves. We propose REARL, a closed-loop simulation enhancement framework that integrates real traffic data with LLMs. Real traffic data are clustered, and each cluster center is used as a representative scenario that provides typical real-world traffic patterns for the LLM. A timed sliding-window detector then monitors discrepancies in vehicle speed distribution and mean spacing between pairs of vehicles. If a metric exceeds a threshold, the LLM adjusts vehicle decision-making; otherwise the existing controller is kept. The LLM also selects a matching real vehicle from a traffic snapshot and modulates the simulated vehicle with reference to that real action. In a controlled HighD highway setting, compared with the CRITICAL baseline and a PPO-based learning baseline, REARL reduces the Hellinger distance for speed distributions to 0.3067 and the MAPE for mean spacing to 0.8371, while achieving a time headway (THW) of 22.8575 and a lane change rate of 0.0708.

- **背景**：仿真是自动驾驶算法测试与验证的核心平台，但真实世界交通具有时变、非线性、高密度交互等复杂特性。
- **现有方法的两大缺陷**：
  - **传统规则型仿真器**（SUMO、VISSIM、AIMSUN、highway-env 等）：依赖预定义跟驰/换道模型与手工规则，参数化过于简化，难以刻画动态交通流与复杂交互。
  - **数据驱动方法**：可提升真实感，但存在数据偏差、过拟合、可解释性差、噪声敏感，且多为短时仿真（如仅几秒），难以支撑完整行程训练。
- **LLM 增强路线的局限**：CRITICAL 等工作仅用 LLM 优化**初始仿真配置**，仿真开始后不监控、不校正中间过程，导致随推演推进，仿真分布逐渐偏离真实交通数据。
- **核心问题**：如何在仿真推演过程中（rollout）实现**仿真车辆行为与真实交通分布的动态对齐**。
- **整体含义**：论文提出 REARL——一个结合真实交通数据与大语言模型的**闭环仿真增强框架**，通过“定时偏差检测 + LLM 决策干预”形成检测-调整反馈回路，提升仿真真实性。

## 2. 方法论

### 2.1 核心思想
将真实交通数据聚类为**代表性场景**，作为 LLM 学习真实交通分布特征的参考；用**定时滑动窗口**持续监测仿真与最相似代表场景在速度分布、车辆平均间距上的偏差；一旦超阈值，LLM 介入调整背景车辆决策，并参考匹配的真实车辆动作调制仿真车行为；否则沿用原控制策略。

### 2.2 三大模块

**（1）真实数据预处理与聚类**
- 基于 HighD 数据集（25 帧/秒高频轨迹），对齐时间尺度并做 min-max 归一化（速度归一化至 [5, 32]）。
- 每个仿真周期 Ts = 60 秒，每秒决策一次，截取为 60 秒交通场景，共得到 **741 个交通场景**；约束为任意时刻车辆数 Nv(t) ≥ 10，每帧取记录时长最长的 10 辆车作为代表快照。
- 过滤长度 L(Pi) < 100 时间步的轨迹；用 **kicluster**（基于中心的轨迹聚类算法）对轨迹聚类，相似度采用近似 Fréchet 距离。
- 每个场景用车辆类型比例构成 3 维特征向量 vk，再用 **k-means** 对场景特征聚类（目标为最小化簇内平方距离，见 Eq. 3），最终得到 **15 个代表性场景中心 M = {su1, ..., su15}**。
- 轨迹聚类参数用**贝叶斯优化**（高斯先验 + gp hedge 自适应采集，500 次迭代，随机采样 5% 轨迹）调优，最优为聚成 3 组、3 次迭代。

**（2）速度分布与平均间距偏差检测**
- 在每个检测点，先做**前缀比较**：计算仿真中所有背景车辆对的平均间距与每个候选场景的逐帧 MAPE，取前缀窗口内平均 MAPE 最小的场景作为参考场景。
- 计算两项指标：
  - **Hellinger 距离**（Eq. 4）：衡量仿真与真实数据速度分布的相似性；速度分箱区间为 [5.0, 8.375, 11.75, 15.125, 18.5, 21.875, 25.25, 28.625, 32.0]，取过去 5 秒窗口。
  - **MAPE**（Eq. 5）：衡量仿真与真实数据车辆对平均间距的相对误差，取当前帧。
- 选择 Hellinger 距离而非 KL 散度，因其对称性更好、更稳定；选择 MAPE 而非 RMSE/MAE，因其尺度无关、适合跨场景帧比较。
- 任一指标超过预设阈值即触发 LLM 干预。

**（3）代表性场景引导的 LLM 决策**
- 对当前仿真时刻 t，用前缀比较选出差异最小的代表场景，提取该时刻驾驶时间最长的 10 辆车的速度与间距作为特征向量 Fuk(t)（Eq. 6）。
- **Prompt 设计包含四部分**：道路结构描述、局部观测（周边车辆状态文本化）、动作空间描述（IDLE、Turn-left、Acceleration、Deceleration 等离散动作 ID）、决策建议模块（安全约束 + 效率约束 + 模仿匹配真实车辆行为）。
- LLM 输出解析为离散动作 ID；**无效或越界动作回退到规则控制策略**；换道动作还需检查目标车道可用性。
- 该机制定位为**动作级有效性过滤**，而非形式化安全验证。
- 最终使仿真的速度与间距分布 Psim 逐步逼近真实分布 Preal，形成闭环。

## 6. 主要结论与发现

- **宏观分布对齐**：
  - 所有 REARL 变体的 Hellinger 距离均低于三个基线；REARL(DeepSeek-R1 32B) 最低为 **0.2562**，默认 REARL 为 **0.3067**。
  - 默认 REARL 取得最低 MAPE **0.8371**；REARL(DeepSeek-R1 32B) 为 0.8600。
  - CRITICAL 虽略降 Hellinger（0.3277），但间距 MAPE 恶化至 **2.0523**，说明仅调初始配置存在权衡。
  - PPO 在速度分布上改善（0.3258），但间距 MAPE 达 1.3940，未实现两项宏观指标均衡。
- **微观行为**：
  - 默认 REARL 的 THW 达 **22.8575**，远高于 Base（7.6679）、PPO（10.6617）、CRITICAL（7.2094），体现更保守的跟驰行为。
  - 换道率：Base 极低（0.0081）、PPO 极低（0.0138）、CRITICAL 过高（0.5630），REARL 变体为 0.0616~0.0708，更接近自然水平。
- **总体判断**：REARL 在速度分布对齐上跨骨干一致改善，间距性能依赖骨干；默认 Qwen3 32B 配置最均衡。结果是**方法-指标依赖的权衡**，而非四项指标全面占优。
- **阈值结论**：速度分布 30% 阈值 + 间距 5% 阈值组合整体表现最佳。
- **推理成本**：REARL 计算开销远高于规则与 PPO，论文定位其为“仿真环境增强器”而非轻量级车端控制策略。

## 7. 优点

- **闭环在线校准思路新颖**：不同于 CRITICAL 只调初始配置，REARL 在 rollout 中持续检测并纠正分布漂移，形成检测-调整反馈回路。
- **真实数据与 LLM 有机结合**：用聚类中心作为代表性场景，为 LLM 提供可解释、结构化的真实交通先验，而非直接喂原始数据。
- **指标选择有依据**：明确论证 Hellinger 距离优于 KL 散度、MAPE 优于 RMSE/MAE 的原因。
- **工程细节严谨**：无效动作回退规则控制、换道可用性检查、温度 0 确定性解码、阈值估计集与评估集分离，提升了可复现性与公平性。
- **实验设计较为全面**：同时覆盖宏观分布与微观行为，考察 3 种 LLM 骨干，并做了阈值消融与聚类参数优化。
- **表述客观克制**：明确承认结果是“指标依赖的权衡”而非全面优越，并主动列出四条关键假设与适用边界。

## 8. 不足与局限

- **推理成本极高**：REARL 平均 86241.309 ms/10 步，约为 PPO 的 5400 倍、规则方法的 18 万倍，难以用于实时或大规模仿真。
- **场景覆盖有限**：仅验证 HighD 高速、四车道、10 车、60 步的受控设置，未证明对城市道路、混合交通、3D 驾驶、更大规模场景的泛化能力。
- **未评估安全性**：THW 与 LCR 只是行为代理指标，不能直接证明驾驶安全性；动作过滤仅为有效性检查，非形式化安全验证。
- **依赖强假设**：仅用速度分布与平均间距两项宏观指标代理仿真保真度；假设 LLM 能从静态快照合理模仿驾驶行为；假设微观调整可贡献宏观真实性。
- **未报告算力资源**：缺少 GPU 型号、数量、训练/推理时长等信息，不利于复现与成本评估。
- **阈值与聚类存在过拟合风险**：阈值仅基于 15 个场景选择，聚类参数基于 5% 轨迹采样，可能对当前数据集偏置。
- **长尾安全关键场景未系统评估**：虽保留离群场景，但明确列为未来工作。
- **评估指标有限**：缺少碰撞率、jerk 舒适度、长尾事件覆盖率等更细粒度指标。
- **LLM 骨干差异导致性能波动**：间距 MAPE 在不同骨干间差异较大（0.8371~1.2099），说明方法稳定性依赖模型选择。
