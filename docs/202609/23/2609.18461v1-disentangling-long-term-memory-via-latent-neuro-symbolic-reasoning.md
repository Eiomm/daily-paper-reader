## 摘要
个性化智能体需要基于长期历史交互进行推理，以推断显式偏好和隐式行为证据。早期的扁平检索方法独立地对记忆片段打分，忽略了分布式信息；而当前的结构化记忆框架依赖与查询无关的静态图，无法捕捉依赖上下文的关系。至关重要的是，原始文本记忆本质上是纠缠且嘈杂的，使得细粒度个性化和跨会话推理在计算上代价过高。为此，我们提出 LGM，一种新颖的神经符号框架，将长期记忆解耦转移到连续潜在空间。具体而言，(i) 我们不持久化固定图，而是设计了一种基于稀疏自编码器的定制潜在图构建方法。针对每个查询，它将历史交互映射为潜在记忆节点，并将记忆轨迹解耦为稀疏概念激活，动态合成查询感知的关系边权重。(ii) 随后，图编码器将查询嵌入视为条件偏好，以指导在任务特定的潜在子图上进行非线性消息传递。这产生了具有高度表达力的记忆表示，以实现有效的激活。在长期个性化基准上的大量实验表明，LGM 在捕捉显式和隐式偏好方面显著优于最先进的基线，同时能够实现个性化响应。

## Abstract
Personalized agents are required to reason over long-term history interactions to infer both explicit preferences and implicit behavioral evidence. While early flat retrieval methods score memory fragments independently and neglect the distributed information, current structured memory frameworks rely on query-agnostic static graphs that fail to capture the context-dependent relations. Crucially, raw textual memories are inherently entangled and noisy, making fine-grained personalization and cross-session reasoning computationally prohibitive. To this end, we present LGM, a novel neuro-symbolic framework that shifts long-term memory disentanglement into a continuous latent space. Specifically, (i) instead of persisting fixed graphs, we design a tailored latent graph construction with a sparse autoencoder. Subject to each query, it maps historical interactions into latent memory nodes and disentangles the memory traces into sparse concept activations, dynamically synthesizing query-aware relational edge weights. (ii) A graph encoder then treats the query embedding as a conditioning preference to direct non-linear message passing across the task-specific latent subgraph. This yields a highly expressive memory representation for effective activations. Extensive experiments on long-term personalization benchmarks demonstrate that LGM significantly outperforms state-of-the-art baselines in capturing both explicit and implicit preferences while enabling personalized responses.

- **三大张力**：
  1. 原始文本与隐藏状态将显式偏好与细微习惯纠缠，解耦时难以保留长尾证据。
  2. 历史事件相关性随查询变化，刚性文本级图重建过慢，拓扑需在潜在空间动态适应。
  3. 潜在空间推理虽避免上下文饱和，但多步传播有信息坍缩风险，状态需紧凑且忠实于历史证据。
- **整体含义**：论文将长期个性化重新表述为**潜在空间中的查询感知记忆解耦与关系推理**，提出神经符号框架 LGM，把记忆生命周期（选择、关联、聚合、利用）统一为端到端可微分优化过程。

## 2. 方法论

### 核心思想
- 将长期记忆解耦与关系推理从显式文本空间迁移到**连续潜在空间**，用稀疏概念作为可解释单元，用查询动态诱导潜在图拓扑，最终以紧凑的潜在前缀 token 条件化生成，避免重放原始历史。

### 关键技术细节

- **（1）潜在记忆解耦**
  - 对每个历史交互与当前查询 $x \in H \cup \{q\}$，读取骨干 LLM 多层隐藏状态（默认均匀选取 $\{8,16,24,32\}$ 四层），取平均后做 masked mean pooling，再投影到共享低维空间，得到潜在节点 $z_x$（$d=32$）。
  - 使用**稀疏自编码器（SAE）**将稠密表示分解为稀疏概念激活：
    - $c_x = S(\mathrm{ReLU}(W_{enc} z_x))$
    - $\hat{z}_x = W_{dec} c_x$
  - 其中 $S(\cdot)$ 抑制弱激活，$c_x$ 为非负稀疏码，用于在共享概念空间中对齐显式陈述与隐式行为线索。
  - SAE 损失：$L_{sae} = \|\hat{z}_x - z_x\|_2^2 + \lambda \Omega(c_x)$，在重建潜在表示的同时保持概念稀疏。

- **（2）查询条件潜在图构建**
  - 图 $G(q) = (V, E, \omega)$，节点集 $V = \{z_q\} \cup \{z_i\}$，边权是**查询的函数**：
    - $\omega_{q \to i} = \phi(c_q, c_i) \in [0,1]$，即查询与记忆的归一化概念重叠。
  - 同一记忆池在不同查询下形成不同拓扑；加入自环与类型化双向查询↔记忆关系 $r_{ij}$。
  - **关系图网络**进行 $T$ 步消息传递：
    - $m_i^{(t)} = \sum_{j \in N(i)} \omega_{j \to i} \psi(z_i^{(t)}, z_j^{(t)}, r_{ij})$
    - $z_i^{(t+1)} = \mathrm{Upd}(z_i^{(t)}, m_i^{(t)})$
  - 置换不变读出得到紧凑记忆状态 $g = \mathrm{Readout}(\{z_i^{(T)}\})$，评分头产生节点级相关性 $s_i = \langle z_i^{(T)}, g \rangle$。
  - 该传播将多个单独弱线索沿查询激活边组合为一个推断出的隐式偏好。

- **（3）图条件推理**
  - 投影器将 $g$ 映射为少量软潜在前缀 token $\tilde{P} = \{\tilde{P}_k\}_{k=1}^p \in \mathbb{R}^{p \times d_{lm}}$（默认 $p=16$），每个 token 重缩放到普通 token 嵌入的范数，避免前缀主导注意力。
  - 前缀前置到查询嵌入：$y \sim f_\theta([\tilde{P}; E(q)])$，长历史通过紧凑潜在通道影响生成。

- **训练目标**
  - 生成监督：$L_{gen} = -\sum_t \log f_\theta(y^*_t \mid y^*_{<t}, [\tilde{P}; E(q)])$
  - **证据重建**：复用 $f_\theta$ 作为解码器，要求同一前缀在固定解码指令 $\rho$ 下重建支持证据 $e^*$：
    - $L_{recon} = -\sum_t \log f_\theta(e^*_t \mid e^*_{<t}, [\tilde{P}; E(\rho)])$
  - 总目标：$L = L_{gen} + L_{recon} + L_{sae}$，端到端训练。

- **算法流程（三阶段）**
  1. 编码：将历史与查询编码为潜在节点，SAE 解耦为稀疏概念。
  2. 构图与传播：计算概念重叠边权，构建查询特定图，$T$ 步消息传递，读出紧凑状态 $g$。
  3. 生成：将 $g$ 投影为潜在前缀 token，前置到查询，自回归生成答案；训练时额外要求前缀重建支持证据。

## 3. 实验设计

### 数据集 / 场景
- **PersonaMem**：大规模动态用户画像基准，超过 180 个模拟用户–LLM 交互历史，最多 60 个多轮会话，约 1M token，覆盖 15 类个性化任务；评估 32K 与 128K 两种上下文规模，强调偏好的持久性与更新。
- **PrefEval**：长对话偏好跟随基准，包含 3000 条人工策划偏好、20 个日常主题；同一偏好以**显式**（直接陈述，与查询有词汇重叠）和**隐式**（间接行为线索，无表面词汇重叠）两种模式提供。
- **PersonaMem-v2 隐式偏好 split**：围绕隐式用户画像构建，1000 个用户画像、20000+ 偏好、300+ 场景；目标偏好从不明说，必须从分散的行为证据中重建，评估 32K 与 128K。

### Benchmark 与对比方法
- 所有方法生成**自由形式自然语言响应**，而非从预定义选项中选择，避免退化为选项分类。
- 四类基线：
  1. **Context / retrieval basics**：Long Context、Naive RAG。
  2. **Structured RAG**：GraphRAG、LightRAG、HippoRAG、Youtu-GraphRAG。
  3. **Agentic memory management**：MemoryBank、Mem0、A-Mem、MemoryOS、LightMem。
  4. **RL-based memory**：Mem-α、MemAgent、Memory-R1、MemCoE。
- 骨干模型：Qwen2.5-7B-Instruct、Gemma3-4B-it、Qwen3-4B-Instruct。
- 基线均按其公开代码库推荐设置运行，使用相同骨干与数据划分。
