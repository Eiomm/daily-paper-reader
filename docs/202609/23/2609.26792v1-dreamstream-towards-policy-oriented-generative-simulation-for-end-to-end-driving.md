## 摘要
在仿真中忠实评估端到端驾驶策略，需要观测不仅照片级真实，还要保留策略做出决策所依赖的场景特征。然而，现有平台存在仿真到真实的视觉差距，这会破坏策略感知，削弱其评估策略闭环决策的能力。为此，我们提出 DreamStream，一种生成式闭环仿真器，利用基于仿真器的自回归视频模型实现面向策略的保真度。我们的视频模型通过交通布局引导，从大型预训练视频模型蒸馏而来，在改变视觉外观的同时保留策略相关特征，例如场景布局和动态对象的时间一致性。我们进一步观察到，像 FID 这样的感知指标会错误地排序这些特征的保留程度。为解决这一问题，我们引入 FD$π$，一种新的多表示度量，将仿真到真实的差距度量公共 E2E 策略的场景上下文特征上的 Fréchet 距离。在 FD$π$ 下，DreamStream 在 nuScenes 上比最强的先前闭环仿真器提升 1.6 倍，在 NAVSIM 上提升 4.7 倍，并且对策略感知可观测性造成最小扰动。基于 DreamStream，我们构建 Navhard-CL 基准，将非反应式真实世界基准 NAVSIM 转变为具有对抗性驾驶行为和天气变化的交互式测试环境。该基准揭示了许多先前闭环基准忽视的驾驶策略失效模式，例如评分器偏差和缺乏恢复行为。代码和数据见 https://github.com/VAIL-UCLA/DreamStream。

## Abstract
Faithfully evaluating end-to-end driving policies in simulation requires observations that are not merely photo-realistic, but preserve the scene features a policy relies on to make decisions. Existing platforms, however, exhibit a sim-to-real visual gap that corrupts policy perception, undermining their ability to assess a policy's closed-loop decision-making. To this end, we propose DreamStream, a generative, closed-loop simulator that achieves policy-oriented fidelity using a simulator-grounded autoregressive video model. Our video model is distilled from a large pretrained video model via traffic layout guidance, varying visual appearance while preserving policy-relevant features such as scenario layout and the temporal consistency of dynamic objects. We further observe that perceptual metrics like FID misrank how well these features are preserved. To tackle this, we introduce FD$π$, a new multi-representation metric that measures the sim-to-real gap as the Fréchet distance over scene-context features from public E2E policies. Under FD$π$, DreamStream improves over the strongest prior closed-loop simulator by $1.6\times$ on nuScenes and $4.7\times$ on NAVSIM, and induces the least perturbation to policy's perceptual observability. Based on DreamStream, we construct Navhard-CL benchmark, which turns non-reactive real-world benchmark NAVSIM into interactive testing environments with adversarial driving behaviors and weather variations. This benchmark exposes many failure modes of driving policies, such as scorer bias and lack of recovery behaviors, that prior closed-loop benchmarks overlook. Code and data are available at https://github.com/VAIL-UCLA/DreamStream.

## 1. 核心问题与整体含义

- **背景**：近期研究表明端到端（E2E）驾驶策略存在显著的「开环—闭环（OL–CL）评估鸿沟」，因此可靠的策略评估必须依赖闭环仿真。由于 E2E 策略直接由传感器观测映射到动作，闭环仿真器必须同时满足两点：提供**可控的交通场景**（物理上合理的布局与智能体行为），以及渲染**既真实又保留策略决策所依赖场景特征**的观测。
- **核心矛盾**：
  - 物理/游戏引擎仿真器（MetaDrive、CARLA、BridgeSim 等）可控性强、支持反应式与对抗行为，但使用手工 3D 资产渲染，存在明显 **sim-to-real 视觉差距**，会破坏视觉策略的感知。
  - 生成式与重建式仿真器（DriveArena、DreamForge、HUGSIM 等）提升了真实感，但视觉域狭窄、可控性受限（重建法只能回放已采集场景，且离轨视角/动态插入有伪影）。
  - **没有任何现有平台同时具备两者**，导致闭环评估无法真实反映策略性能。
- **关键洞察**：评估所需的不是「照片级真实」，而是**面向策略的保真度（policy-oriented fidelity）**——即保留策略所依赖的布局、几何、时序一致性等场景特征。
- **指标问题**：FID/FVD 等感知指标在小规模域内驾驶数据集上有偏，且与驾驶表现相关性弱；3D 检测/地图分割等可控性指标只是模块化视角、维度有限，未必与策略决策相关。
- **整体含义**：论文提出 DreamStream，把「物理仿真器的可控性」与「大规模预训练视频模型的真实感与视觉多样性」结合，并配套提出面向策略的视觉对齐指标 FDπ 与闭环基准 Navhard-CL，目标是让 E2E 策略的闭环评估变得**忠实、可诊断**。

## 2. 方法论

### 2.1 DreamStream 总体框架

由三个组件构成闭环：物理仿真器 **S**、自回归（AR）视频模型 **G_φ**、待评估 E2E 策略 **π**。仿真器维护底层场景状态（自车位姿、周围智能体、HD 地图），视频模型负责把符号状态「翻译」为策略真正消费的相机画面——这种解耦让系统既继承仿真器的物理落地性，又具备高视觉保真度。

- **场景初始化**：世界状态 s₀ + 初始帧 o₀。两类来源：(i) 真实驾驶日志（经 ScenarioNet 转换，o₀ 为日志帧）；(ii) 生成式安全关键场景（o₀ 由图像生成模型合成）。
- **闭环迭代（第 i 轮，起点 tᵢ）**：
  1. **Plan**：策略 π 基于最近 K 帧观测输出长度 H 的规划轨迹 τ = (a_{i+1},…,a_{i+H})。
  2. **Simulator rollout**：只执行前 Δr ≤ H 步（Δr 为可配置重规划周期），逐步更新状态 s_{t+k} = S(s_{t+k−1}, a_{t+k})，并为每个新状态渲染交通布局条件 c（HD 地图的透视投影：车道几何、交通元素 + 车辆/行人 3D 边界框）。
  3. **Observation generation**：视频模型以布局与文本提示 p 为条件，自回归生成接下来 Δr 帧；用早期时间步隐状态作为 **KV cache** 保证整个场景的一致性，K₀ 由初始帧 o₀ 播种。
- **闭环评分**：周围智能体可由日志回放、IDM 或对抗模式驱动；场景结束后对完整执行轨迹打分（DS = 路线完成率 RC × 逐帧 EPDMS 均值）。

### 2.2 自回归视频扩散模型的三阶段蒸馏

从大规模预训练视频模型出发（Wan 2.1 / Wan 2.2），输入定义为 c = (c, o₀)：

- **Stage-1 双向教师模型**：基于 flow matching，训练可控条件视频生成器，损失为 `L_flow = E[||G_T(x_t, c, t) − (ε − x₀)||²]`，条件包含场景布局 c 与初始帧的 CLIP 嵌入。先学可控性，再做因果蒸馏。
- **Stage-2 因果 ODE 初始化**：把双向教师蒸馏为少步因果学生 G_θ（块内双向注意力、块间因果注意力），使用带真值上下文的 ODE 回归目标 `L_ode = E[||G_θ(x_t^T, c, t) − x₀||²]`，为学生提供强初始化。
- **Stage-3 Self Forcing**：解决「训练用真值历史、推理用自生成历史」的 train–test 失配，在自回归 rollout 的自生成上下文上训练，采用 DMD 式分布匹配目标 `L_sf`（冻结的真实 score 网络 s_real + 可训练 critic s_fake）。**关键细节**：若用完全去噪的隐状态作 KV cache，高频误差会累积导致快速漂移，因此改为**只用早期时间步隐状态**作为 cache。

### 2.3 两个提升策略保真度的关键设计

- **交通引导蒸馏（TGD）**：闭环中策略依据生成画面决策，车道/智能体错位会改变决策。采用无分类器引导（CFG），训练时以 p=0.1 概率把布局替换为 c∅（去掉布局、保留 CLIP(o₀)），生成时按 `Ĝ_T = G_T(x_t,c∅,t) + w·(G_T(x_t,c,t) − G_T(x_t,c∅,t))` 组合，引导尺度 w=7.5。无需额外数据即可提升布局对齐。
- **多样场景蒸馏（DSD）**：预训练模型本具备多样天气/光照能力，但蒸馏数据来自覆盖有限的驾驶日志，因果学生会在蒸馏中逐渐丢失这些能力。做法是从 nuPlan 训练集均匀采样 500 个场景，**保持布局 c 不变**，仅用图像编辑模型（Nano-Banana / Gemini 2.5 Flash Image）按光照、天气、路面三条轴重渲染首帧 o₀，再由 Stage-1 教师按原布局 rollout 出完整视频，人工筛选保留 500 个合成场景加入 Stage-2/3 训练集。

### 2.4 FDπ：面向策略的视觉对齐指标

- **动机**：FID 衡量视觉质量而非下游决策所需信息，且在域内小数据集上有偏；可控性指标是模块化视角。
