## 摘要
执行长时程任务的具身智能体需要一种记忆表示，使得动态对象的状态转换在数小时到数天的观测时程内仍能以自然语言进行查询。现有系统要么丢弃细粒度运动（片段级视频-语言嵌入），要么仅将其保留为原始坐标（几何SLAM），要么围绕即时任务上下文进行组织（智能体工作记忆）。这些系统均未为智能体提供逐对象时间线，且其状态转换本身可用语言查询。我们的核心贡献是语言轨迹编码（Linguistic Trajectory Encoding, LTE），它通过结合自然语言描述、稀疏空间锚点和视觉锚点的混合表示来压缩动态对象的运动历史。LTE 根据运动复杂度自适应地压缩：将缺乏可靠观测的时段锚定到最近一次观测到的位置，同时用几何路点和语言描述来表示运动，以保持准确性。为了在扩展时间范围内评估这些能力，我们基于 EgoLife 多日录制构建了空间记忆基准（Spatial Memory Benchmark, SMB），针对现有基准中缺失的能力：语义轨迹检索和长时程对象检索。在 SMB 上，基于 LTE 的系统在语义轨迹检索中达到 45.3% 的成功率，在长时程对象检索中达到 48.7%，优于结构化记忆和 VLM 基线（此前最佳：31.9% 和 34.4%）。LTE 在 24 小时视频上实现了 8.7× 到 26.1× 的轨迹压缩，查询延迟低于一秒。在 Ego4D 自然语言查询上，该系统达到 28.75% / 55.10% 的 R@1/R@5，较 EgoVLPv2 提升 +15.80 / +31.30 个百分点。

## Abstract
Embodied agents performing long-horizon tasks require a memory representation in which the state transitions of dynamic objects remain queryable in natural language across hours-to-days observation horizons. Existing systems either drop fine-grained motion (clip-level video-language embeddings), keep it only as raw coordinates (geometric SLAM), or organise it around immediate task context (agent working memories). None of them gives the agent a per-object timeline whose state transitions are themselves queryable in language. Our key contribution is \textbf{Linguistic Trajectory Encoding} (LTE), which compresses dynamic object motion histories via a hybrid representation combining natural language descriptions, sparse spatial anchors, and visual anchors. LTE adapts compression to motion complexity by anchoring periods without reliable observations to the last seen location, while representing motion with geometric waypoints and linguistic descriptions to preserve accuracy. To evaluate these capabilities across extended time horizons, we construct the \textbf{Spatial Memory Benchmark} (SMB) from EgoLife multi-day recordings, targeting capabilities absent in existing benchmarks: semantic trajectory retrieval and long-horizon object retrieval. On SMB, the LTE-based system achieves $45.3\%$ success in semantic trajectory retrieval and $48.7\%$ in long-horizon object retrieval, outperforming structured-memory and VLM baselines (best prior: $31.9\%$ and $34.4\%$). LTE achieves trajectory compression by factors of $8.7\times$ to $26.1\times$ with sub-second query latency on $24$\,h video. On Ego4D natural-language queries, the system reaches $28.75\%$ / $55.10\%$ R@1/R@5, $+15.80$ / $+31.30$ pts over EgoVLPv2.

## 1. 核心问题与整体含义

- **研究动机**：执行长时程（数小时至数天）任务的具身智能体，需要一个能够回答诸如“我把洗好的苹果最后放在哪了？”这类问题的记忆系统。该查询同时要求三种检索能力：语言命名的物体（“苹果”）、语义描述的状态变化（“洗过”）、以及特定时刻的空间位置（“最后放在哪”）。
- **现有方法的共同缺陷**：
  - **几何 SLAM**（如 Kimera、Khronos）：维护持久 3D 状态，但无法暴露“洗过”这类自然语言谓词接口——知道位置，不知道状态。
  - **视频-语言模型**（如 EgoVLPv2）：在片段级特征上做文本匹配，但缺少 3D 索引，“最后放在哪”退化为无空间剪枝的全时序扫描。
  - **记忆增强视频智能体**（如 VideoAgent、AMEGO）：以时间事件为单位组织观测，物体个体轨迹被折叠进更大的事件中而丢失。
  - **任务导向的智能体记忆**（如 KARMA）：围绕当前任务组织记录，与任务无关的物体（如苹果）根本没有可查询记录。
- **核心缺口**：没有任何系统为智能体提供**逐对象的时间线，且其状态转换本身可用语言查询**。作者将这一“运动相位级别的语言”定位为几何 SLAM 与视频-语言模型之间被低估的中间层。
- **整体含义**：论文提出 **LTE（Linguistic Trajectory Encoding）** 表示 + **SMB（Spatial Memory Benchmark）** 基准 + 完整记忆架构，试图填补上述空白，并在效率（压缩 8.7×–26.1×、亚秒查询）与检索精度上同时取得优势。

## 2. 方法论

### 2.1 核心思想
- 对每个被跟踪物体，将其运动历史压缩为**三通道混合表示**：语言描述、稀疏空间锚点、视觉锚点。三通道各覆盖其他通道无法覆盖的查询类型：
  - **语言字幕 C**：匹配“洗过”等状态谓词；
  - **空间锚点 A_spatial**：回答 3D “在哪”；
  - **视觉锚点 A_visual**：跨运动相位验证“是哪个苹果”。

### 2.2 形式化定义
- 对物体 $o_i$ 的轨迹 $\tau_i=\{(p_t,t)\}_{t=1}^{T_i}$，LTE 输出：
  $$\mathrm{LTE}(o_i) = (C,\ A_{spatial},\ A_{visual})$$
  - $C=\{(c_j,[t^{start}_j,t^{end}_j])\}$：带时间跨度的区间字幕；
  - $A_{spatial}=\{p_k\}_{k\in K}$：3D 空间锚点位置；
  - $A_{visual}=\{(I_{t_k}, b_{t_k})\}_{k\in K}$：帧裁剪 + 边界框。

### 2.3 构造流程（关键技术细节）
- **跟踪间隙判定**：设 $m_t\in\{0,1\}$ 表示是否检测到目标，$t^-(t)=\max\{t'\le t \mid m_{t'}=1\}$。若 $m_t=0$ 且 $t-t^-(t)\ge\theta_{static}$（默认 2 s），该跨度定义为**跟踪间隙**，物体被锚定到最后观测位置；其余为**运动区间**。
- **字幕生成**：每个运动区间由 VLM（Qwen3-VL）结合视觉标记生成一句自然语言描述（如“苹果从水槽移到台面”）。
- **空间锚点自适应采样**：
  - 跟踪间隙 → 仅存 1 个 3D 位置；
  - 运动区间 → 用 **Douglas–Peucker 简化**（垂直距离容差 0.15 m），保留显著偏离线性插值的路点；
  - 参数：最小锚点间距 0.25 s，最大锚点间距 10 s。
- **视觉锚点采样**：跟踪间隙仅在可观测边界（间隙前最后一帧、间隙后首个重检测帧）放置；运动区间在路点处加密采样，并在状态转换边界必采。
- **压缩效果**：相对逐帧稠密存储，压缩比 8.7×–26.1×。

### 2.4 系统架构（三部分）
- **感知层**：SAM3 做实例分割与跟踪；ViPE 做单目深度 + 视觉里程计，反投影得到世界坐标；Qwen3-VL-8B 提供房间级语义标签与物体运动描述；Whisper-large-v3 转写语音，Qwen3-8B 解析为时间事件。
- **记忆层（五视图）**：
  - **Scene**：八叉树空间索引（最大深度 8，最小节点 0.1 m³，根节点 20 m×20 m×5 m），节点关联 VLM 推断的房间标签；
  - **Object**：实体中心记录（类别、身份、状态），链接到 LTE；
  - **Text**：聚合 LTE 字幕、房间标签、语音转写，建向量索引（FAISS）；
  - **Event**：时间区间索引 + 活动摘要；
  - **Image**：物体视觉锚点 + 光流自适应关键帧；
  - 视图间双向链接，支持级联过滤。增量更新复用已重建的 3D 坐标系，避免重跑深度估计。
- **查询层**：统一模式 **parse → route → filter → aggregate**。
  - NLQ：Object 视图取实体与 LTE，Event 约束触发事件查找并与 Text 字幕交叉校验；
  - VQ2D：DINOv2 ViT-L/14 嵌入与视觉锚点做余弦匹配（阈值 0.7），再按时间过滤取最近一次出现；
  - STR：状态描述用 Qwen3-Embedding-8B 嵌入，与 LTE 字幕匹配（余弦 > 0.8），经八叉树按空间/时间剪枝；
  - LOR：按活动时间窗与空间区域过滤 Object 实体，返回 $t^*\le T$ 的最近锚点及其边界框。
  - 查询复杂度取决于**约束类型的选择性**而非视频时长，避免逐帧扫描。

### 2.5 辅助机制
- **自适应场景语义索引**：以 3 s 窗口、3 FPS 采样，VLM 同时推断房间标签与显著关键帧；当标签稳定 $k$ 个窗口后，步长按指数退避 $s_{k+1}=\min(2^{\lfloor k/2\rfloor}\cdot s_0, s_{max})$（$s_0$=3 s，$s_{max}$=15 s）增长；标签变化时重置步长并在 $[t-s,t]$ 内回溯精确定位转换边界。
- **不确定性量化**：每次响应附带 **HIGH / MEDIUM / LOW** 置信标签，区分“窗口内直接观测”“窗口前最后观测 + 位置外推”“仅历史数据”，显式暴露离镜不确定性。

## 3. 实验设计

### 3.1 数据集与基准
- **Ego4D NLQ**：5,462 条查询、303 个验证视频（平均 8.2 分钟），指标为 IoU=0.3/0.5 下的 R@1/R@5。
- **Ego4D VQ2D**：4,500 条查询、1,200 个验证片段，指标为 stAP、tAP、Success（IoU≥0.5）、Recovery rate。
- **SMB（本文新建）**：基于 EgoLife 的 7 天、300 小时、6 名参与者连续第一人称录制（单次会话最长 50 h），共 **600 条查询**：
  - **STR（语义轨迹检索）**：300 条，覆盖 232 个物体实例，需按运动状态 + 时空约束定位；
  - **LOR（长时程物体检索）**：300 条，回溯窗口 2/6/12/24 h 各 75 条，需检索最后一次出现。
  - 评判标准：检索帧落在真值时间跨度内且边界框 IoU ≥ 0.3（另有 IoU ≥ 0.5 的严格结果）。
  - 标注由 3 名标注员完成（STR 约 60 人时，LOR 约 45 人时）；标注者间一致性 Fleiss' κ：物体识别 0.71、时间边界 0.65、最后出现时刻 0.78、边界框 0.72；11.3% 候选物体因跟踪失败被跳过。

### 3.2 对比方法
- **NLQ**：监督方法 EgoVLPv2、GroundNLQ、EgoVideo、OSGNet；零样本 VideoAgent。
- **VQ2D**：监督 VQLoC、PRVQL；零样本 RELOCATE。
- **SMB**：两类基线——
  - VLM 裁剪扫描类：Qwen3-VL-8B / 235B-A22B + Grounding-DINO（2 s 滑窗）；
  - 结构化记忆类：KFMem（3D-Mem 式快照 + DINOv2 多样性关键帧，约 600 帧/24 h）、VideoAgent（事件分段记忆）。

### 3.3 主要结果
- **NLQ**：IoU=0.3 下 28.75%/55.10% R@1/R@5（EgoVLPv2 为 12.95%/23.80%），逼近监督 OSGNet（32.56%/59.82%）；IoU=0.5 下 20.31%/42.63%。
- **VQ2D**：stAP 0.36、tAP 0.43、Success 59.5%、Recovery 51.2%，为最强零样本结果（RELOCATE：0.33/0.41/58.0/50.5）。
- **SMB**：STR 45.3%、LOR 48.7%，优于最佳 VLM 基线（31.9%/34.4%）与结构化记忆基线（KFMem 19.8%/33.8%；VideoAgent 24.7%/30.5%）。
- **效率**：24 h 视频记忆占用 134 MB（稠密存储为 856 MB），单查询 0.43 s，而 Q3VL-235B+GD 为 98.3 s；300 条 SMB 查询总耗时 2.2 分钟 vs. 8.2 小时。
- **逐时程**：LOR 从 2 h 的 51.2% 缓降至 24 h 的 46.8%（−4.4），而 Q3VL-235B 从 39.1% 降至 29.3%（−9.8）。

### 3.4 消融实验
- 去掉全部 LTE：STR −16.5；去掉文本字幕：STR −11.8（主导贡献）；去掉视觉锚点：VQ2D −6.1；去掉八叉树：STR −3.2 / LOR −3.5；LOR 对 LTE 近似不变（−0.0），验证模块化设计。
- 仅保留单一通道的增益分别为 +7.4（文本）、+2.7（空间）、+1.3（视觉），合计 +11.4，而完整系统增益 +16.5，存在 **+5.1 的超加性交互效应**。

  - **较充分**：覆盖两个公开基准 + 两个自建任务，既有精度也有效率维度；消融与 keep-only-one 变体清晰隔离了各通道贡献；双 IoU 阈值排除了宽松阈值的伪优势。
  - **客观性**：所有基线均在相同数据与查询上运行，VLM 基线共享 EgoLife 官方视频片段，VideoAgent 使用公开实现与相同底层 VLM（Qwen3-VL-8B），KFMem 使用与本系统相同的 ViPE 重建，比较相对公平。
  - **潜在偏弱处**：SMB 为作者自建、自标注、自评测，存在一定自证风险（虽有标注一致性报告与 11.3% 难例剔除）；SMB 的评测仅限 EgoLife 家庭场景，无跨环境验证；未与部分最新长视频记忆方法（如 3D-M

续）等）进行直接比较，也缺少人工评估记忆质量（如用户主观可用性）的维度；跨场景、跨数据集泛化性尚未验证。

## 6. 创新点与主要贡献

- **提出 LTE 表示**：将物体运动历史压缩为“语言字幕 + 稀疏空间锚点 + 视觉锚点”的三通道混合表示。这是论文最核心的贡献——它把几何 SLAM 的持久 3D 状态与视频-语言模型的语义匹配能力，通过一个**可被自然语言查询的逐对象时间线**连接起来，填补了两者之间的中间层空白。
- **提出 SMB 基准**：基于 EgoLife 的 7 天、300 小时连续第一人称录制，构造了 STR（语义轨迹检索）与 LOR（长时程物体检索）两个任务、共 600 条查询，并给出标注一致性报告。该基准专门针对“长时程 + 状态谓词 + 空间定位”的复合检索，是现有 Ego4D NLQ/VQ2D 无法覆盖的能力维度。
- **完整记忆架构**：五视图（Scene / Object / Text / Event / Image）双向链接的记忆层 + `parse → route → filter → aggregate` 的统一查询层，实现了约束选择性驱动的查询复杂度（与视频时长解耦），而非逐帧扫描。
- **效率与精度的双赢实证**：在 NLQ、VQ2D 两个公开基准上达到或接近最强零样本/监督水平，同时实现 8.7×–26.1× 压缩、亚秒级查询（0.43 s @ 24 h），并在 SMB 上以 45.3%/48.7% 显著超越 VLM 扫描类与结构化记忆类基线。
- **可解释的不确定性接口**：HIGH / MEDIUM / LOW 三级置信标签显式区分“直接观测”“外推”“历史数据”，为具身智能体的下游决策提供了可依赖的元信息。

## 7. 局限性与可讨论之处

- **自建基准的自证风险**：SMB 由作者自建、自标注、自评测，虽有 Fleiss' κ 一致性报告与 11.3% 难例剔除，但缺少第三方复现或独立评测，结论的客观性仍需外部验证。
- **环境单一**：SMB 仅覆盖 EgoLife 的家庭室内场景，未在工业、户外、多楼层等环境验证；对遮挡严重、物体高度重复（如多个相同杯子）的场景鲁棒性未知。
- **感知层误差传播**：系统依赖 SAM3 跟踪 + ViPE 单目深度，跟踪失败或深度漂移会直接污染 LTE 锚点与字幕，论文未系统量化端到端误差传播。
- **离线构建成本高**：24 h 视频顺序 68.4 h / 并行约 42 h 的构建开销，以及约 1,545 次查询的盈亏平衡点，意味着该系统更适合长期部署、反复查询的场景，而非一次性短会话。
- **语言覆盖**：字幕与查询解析均以英语为主，未验证多语言或口语化、模糊指代（“那个东西”）查询下的表现。
- **零样本组合的边界**：方法整体为免训练组合，性能上限受底层 VLM（Qwen3-VL-8B）、嵌入模型（DINOv2、Qwen3-Embedding-8B）能力约束；未探索微调或任务适配带来的提升空间。
- **缺少与部分最新长视频记忆方法的直接对比**（如 3D-Mem 等），也未做记忆质量的人工主观评估。

## 8. 总体评价

论文定位清晰，问题动机扎实：它准确识别出“逐对象时间线 + 语言可查询状态转换”这一被几何 SLAM 与视频-语言模型共同忽视的中间层，并以 LTE 给出了一个工程上可落地、实验上有效果的答案。方法设计中的几处细节（跟踪间隙与运动区间的区分、Douglas–Peucker 自适应锚点采样、查询复杂度由约束选择性决定、置信度分级）体现出对长时程具身记忆实际痛点的深入理解。实验覆盖公开基准与自建基准、精度与效率、主结果与细粒度消融，其中“单通道增益之和 +11.4 vs 完整系统 +16.5”的**超加性交互效应**是较有说服力的设计验证。

主要保留意见集中在 SMB 的自证性、环境单一性、感知误差传播与构建成本上。若能在独立环境与第三方评测下复现，并补充多语言、模糊指代与高重复物体场景的鲁棒性分析，该工作有望成为长时程具身空间记忆方向的一个有影响力的基线。
