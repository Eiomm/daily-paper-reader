## 摘要
智能体推荐系统使用大语言模型维护语义记忆，并支持证据感知推荐。然而，现有记忆机制通常将用户和物品信息压缩为粗粒度摘要，并通过标量协同链接将其连接起来，这使得在用户兴趣演变时难以保留细粒度的偏好阶段或检索可解释的证据。我们提出 AtomRec，一种具有演化原子协同记忆的智能体推荐器。AtomRec 将用户和物品记忆表示为结构化原子单元，在相关记忆之间构建语义链接，并在新交互到来时演化相关历史字段。在推荐过程中，它检索链接记忆作为多跳证据路径，而不是孤立的邻居摘要，从而使协同信号能够支持有依据的排序。在四个公开基准上的实验表明，AtomRec 持续优于最先进的智能体和记忆增强基线，在各指标上平均相对提升约 8.5%。

## Abstract
Agentic recommender systems use large language models to maintain semantic memory and support evidence-aware recommendation. However, existing memory mechanisms often compress user and item information into coarse summaries and connect them with scalar collaborative links, making it difficult to preserve fine-grained preference stages or retrieve interpretable evidence as user interests evolve. We propose \textsc{AtomRec}, an agentic recommender with evolving atomic collaborative memory. \textsc{AtomRec} represents user and item memories as structured atomic units, builds semantic links across related memories, and evolves related historical fields when new interactions arrive. During recommendation, it retrieves linked memories as multi-hop evidence paths rather than isolated neighbor summaries, allowing collaborative signals to support grounded ranking. Experiments on four public benchmarks show that \textsc{AtomRec} consistently outperforms state-of-the-art agentic and memory-augmented baselines, with around 8.5\% average relative improvement across metrics.

- **背景**：推荐系统正从基于表示预测（评分矩阵、协同嵌入、序列隐状态）转向**智能体推荐**（agentic recommendation）。LLM 驱动的推荐智能体需要理解用户意图、维护长期记忆、整合协同证据并支持证据感知排序，**记忆成为历史交互、协同信号与语言推理之间的关键接口**。
- **核心问题**：长期推荐中用户偏好并非单一稳定画像，而是由多条**细小且演化速度不同**的轨迹构成（如反复出现的题材、近期意图、物品属性、来自相关用户/物品的协同信号）。
- **现有记忆机制的两大局限**：
  - **粗粒度**：摘要级记忆把多条偏好轨迹压缩成一个画像，难以选择性修改。
  - **语义可操作性有限**：标量交互权重、相似度或传播权重只表达关系强弱，**不解释记忆为何相关**。
- **后果**：粗粒度更新会反复重写宽泛画像，使早期细粒度证据（如"太空探索""硬科幻生存"）被后续兴趣削弱；检索只返回孤立邻居摘要，而非能解释偏好如何演进的证据路径，导致智能体虽有协同上下文却缺乏细粒度、可解释的排序依据。
- **整体含义**：论文主张让推荐记忆"**可重组**"而非仅"更详细"，用原子化、可链接、可演化的记忆单元替代粗摘要与标量边。

## 2. 方法论

### 2.1 核心思想
将用户与物品记忆建模为**结构化原子笔记**，在笔记间构建**语义协同链接**，新交互到来时对相关历史笔记做**字段级演化**，推荐时沿链接做**多跳证据路径检索**并综合为协同证据参与排序。

### 2.2 原子协同记忆构建
- 用户原子笔记定义为：  
  `m_u^t = {c_u^t, t_u, K_u^t, G_u^t, X_u^t, e_u^t, L_u^t}`  
  其中 `c` 为文本内容、`t` 为时间戳、`K` 为关键词集、`G` 为语义标签集、`X` 为简短上下文描述、`e` 为稠密嵌入、`L` 为链接记忆 ID 集合。物品记忆同构。
- 嵌入由语义字段拼接编码：  
  `e_u^t = f_enc(concat(c_u^t, K_u^t, G_u^t, X_u^t))`，`f_enc` 为文本编码器。
- 设计意图：内容字段保留原始偏好证据，关键词/标签暴露显式语义侧面，上下文概括当前意图，链接字段使笔记可参与记忆图。作者强调这些字段**不假设完全解耦**，而作为互补语义视图使检索、链接、演化更可控。

### 2.3 语义协同链接构建
- 新笔记 `m_n` 插入时，先用嵌入相似度检索语义邻近记忆：  
  `s_{n,j} = (e_n^T e_j) / (‖e_n‖‖e_j‖)`
- 取 Top-K 形成候选集 `M_n^near = TopK(s_{n,j})`。
- 由记忆智能体生成语义链接：  
  `L_n ← LM_Mem(m_n ‖ M_n^near ‖ P_link)`  
  链接关系类型包括：共享主题、互补偏好、意图递进、偏好转移、跨域迁移。
- 输出为带可选关系描述的链接 ID 集合，使协同关系**语义化、可解释**，而非纯数值边权。

### 2.4 动态记忆演化
- 演化触发条件（对每个邻近历史笔记 `m_j`）：  
  `Evolve(m_j) = I[m_j ∈ L_n ∨ s_{n,j} > τ_evo]`
- 触发后字段级更新：  
  `m_j* ← LM_Mem(m_n ‖ m_j ‖ M_n^near ‖ P_evolve)`  
  更新形式：`m_j* = {c_j*, t_j, K_j*, G_j*, X_j*, e_j*, L_j*}`，可强化关键词、细化标签、重构上下文描述、更新链接，但**时间戳 `t_j` 保持不变**以保留原始时间位置；嵌入由修订后字段重算。
- 设计意图：新证据可**改写历史记忆的解释**，使记忆图随时间自组织，而非被动累积摘要。

### 2.5 上下文感知协同检索与推荐
- 初始检索：`M_t^0 = TopK_{m_i∈M} cos(q_u^t, e_i)`，`q_u^t` 由当前指令、近期交互与 pre-t 原子字段经同一编码器得到。
- 沿语义链接扩展子图（可多跳）：`G_t^sub = M_t^0 ∪ ⋃_{m_i∈M_t^0} L_i`
- 记忆智能体综合子图为协同证据：`M_t^collab ← LM_Mem(G_t^sub ‖ P_synth)`
- 最终打分：`r_{u,i}^t = LM_Rec(M_u^t ‖ M_t^collab ‖ M_i^t ‖ P_rank)`，按 `r` 排序。
- **时间协议**：记忆构建、链接、演化、检索均只用时刻 `t` 之前的交互；目标物品仅作为候选项参与最终重排，**绝不写回同一测试实例的记忆**。

## 6. 主要结论与发现

- AtomRec 在 Books、Goodreads、MovieTV、Yelp 的**所有指标上均最优**，相对最强基线平均提升约 **8.5%**（Books/MovieTV 增益更大，说明对稀疏、内容驱动场景尤其有效）。
- 智能体与记忆增强基线普遍优于传统与纯 LM 方法，印证显式语义记忆与协同证据对指令感知排序的价值。
- 消融显示各组件均有效，其中**去掉原子记忆（退化为粗摘要）损失最大（Books 平均 -5.45%，Goodreads -5.24%）**；语义链接、记忆演化、链接感知检索均有独立贡献。
- **偏好漂移越大，AtomRec 相对 MemRec 的增益越大**（低 +5.2%、中 +9.1%、高 +13.9%），说明字段级演化与语义证据路径有助于在兴趣迁移下保留新兴兴趣。

**成本匹配下仍**保持优势，说明增益并非来自更长的上下文，而来自原子记忆的组织方式与证据路径检索。演化审计与语义链接质量评估显示，记忆智能体能生成合理的关系类型与字段级修订；记忆增长统计表明笔记数量随交互增长但可通过演化抑制无序膨胀。

- **分析子集限制**：多数分析基于 1,000 用户随机子集，可能无法完全代表完整测试集分布。
- **基线覆盖不足**：未与近期 agentic 推荐工作（如 RecNet、ChainRec、RecThinker 等）做实验对比，最接近基线仅为 MemRec。
- **潜在方向**：降低 LLM 调用次数（如批量链接生成、缓存复用）、引入轻量本地模型替代部分环节、补充在线延迟与吞吐评测、开展人工评估验证演化与链接质量、扩展到更多领域与更长历史场景。

## 8. 对领域与研究的启示

- **记忆的粒度设计是可操作性问题**：论文将"记忆该多细"转化为"记忆单元是否可选择性修改、可链接、可解释"，为长期推荐记忆研究提供了新的设计维度，而非单纯追求更详细的摘要。
- **关系边应具备语义**：用自然语言关系类型（共享主题、意图递进、偏好转移等）替代标量权重，使协同信号从"强弱"升级为"为何相关"，为可解释推荐与证据溯源提供路径。
- **演化需保留时间锚点**：允许新证据改写历史记忆的解释，同时固定原始时间戳，兼顾"记忆可更新"与"历史可追溯"，这一设计对处理偏好漂移具有借鉴意义。
- **证据路径优于孤立邻居**：多跳链接检索把分散的历史笔记组织成协同证据链，提示检索增强推荐可从"相似度近邻"转向"关系子图综合"。
- **评测协议的可信度**：严格的时序快照协议与成本匹配对照，为 agentic 推荐的可复现与防泄漏评测提供了参考范式。

## 9. 总体评价

- **贡献**：提出原子化、可链接、可演化的协同记忆框架，用字段级演化与语义链接路径解决长期推荐中偏好轨迹细粒度、可解释、可更新三难问题；实验覆盖全面，主结果一致领先，偏好漂移分析提供了机制层面的解释。
- **方法严谨性**：形式化定义清晰，时间协议严格，消融与诊断分析设计较完善，成本匹配对照增强了结论可信度。
- **不足**：效率与延迟缺失、自动评判偏差、消融范围有限、基线覆盖不足，构成主要可信度边界。
- **定位**：AtomRec 更接近"记忆组织范式"的提出，而非工程效率优化方案；其价值在于为 agentic 推荐提供可解释、可演化的记忆接口设计思路，而非直接可部署的工业级系统。
