## 摘要
近年来，大语言模型（LLM）的进展使智能体能够在多样环境中处理长时程任务。为了进一步提升智能体性能，现有的语言世界模型通常预测环境观测，但当真实反馈可用时，重构高熵且依赖执行的工具响应价值有限。与此同时，智能体会遭受任务状态污染：无依据的假设和过时的计划滞留在历史中，并扭曲后续决策。我们提出 Agent-Editing World Model (AEWM)，它建模推理和动作如何塑造未来任务进展，而不是模拟工具响应。AEWM 将 Action Judge 与 State Revision 相结合：前者区分 Critical、Exploratory 和 Noisy 决策，后者编辑来自同一观测历史的含噪推理-动作延续。EditAct 将这些能力与真实执行集成，直接改变后续决策所依据的状态，而不仅仅是提供批评。我们通过中期训练和监督微调在 Search、Terminal 和 Software Engineering 上训练 AEWM。AEWM 在我们的 Action Judge 基准上达到 70.5% macro-F1，超过最强前沿基线 10.6 分。在六个基准和三个智能体主干上，EditAct 相比最强基线将平均分数提升 3.2–6.7 分。此外，在验证过的 EditAct 轨迹上进行拒绝采样微调，称为 AEWM-RFT，在无需在线 AEWM 指导的情况下，在三个领域上比 Self-RFT 提升 2.2–2.6 分。

## Abstract
Recent advances in large language models (LLMs) have enabled agents to tackle long-horizon tasks across diverse environments. To further improve agent performance, existing language world models typically predict environment observations, yet reconstructing high-entropy, execution-dependent tool responses offers limited value when real feedback is available. Meanwhile, agents suffer from \emph{task-state contamination}, where unsupported assumptions and outdated plans persist in history and distort subsequent decisions. We propose the \textbf{Agent-Editing World Model (AEWM)}, which models how reasoning and actions shape future task progress rather than simulating tool responses. AEWM combines \textbf{Action Judge} to distinguish \textsc{Critical}, \textsc{Exploratory}, and \textsc{Noisy} decisions with \textbf{State Revision} to edit noisy reasoning--action continuations from the same observed history. \textbf{EditAct} integrates these capabilities with real execution, directly changing the state underlying subsequent decisions rather than merely providing critiques. We train AEWM across Search, Terminal, and Software Engineering through mid-training and supervised fine-tuning. AEWM achieves 70.5\% macro-F1 on our Action Judge benchmark, exceeding the strongest frontier baseline by 10.6 points. Across six benchmarks and three agent backbones, EditAct improves average scores by 3.2--6.7 points over the strongest baseline. Furthermore, rejection sampling fine-tuning on verified EditAct trajectories, termed \textbf{AEWM-RFT}, improves over Self-RFT by 2.2--2.6 points across three domains without online AEWM guidance.

## 2. 方法论：核心思想、关键技术细节与流程

- **核心思想**：AEWM 建模当前证据、当前推理–动作延续与未来任务进展之间的关系；当延续被判断为噪声时，直接生成更好的推理–动作对，替换原延续后再与真实环境交互。
- **形式化设定**：
  - 任务 \(x\)，历史 \(h_t=(x,(r_i,a_i,o_i)_{i=0}^{t-1})\)，其中 \(r_i\) 为推理，\(a_i\) 为动作，\(o_i\) 为真实观测。
  - 智能体提议 \((\hat r_t,\hat a_t)\sim\pi_\theta(\cdot\mid h_t)\)，形成预执行状态 \(s_t=h_t\oplus(\hat r_t,\hat a_t)\)。
  - 传统世界模型：\(M_{obs}(o_t\mid s_t)\)，预测观测 \(\hat o_t\)。
  - AEWM：\(M_{SR}(\cdot\mid s_t)\) 直接编辑状态，得到 \(\tilde s_t=h_t\oplus(\tilde r_t,\tilde a_t)\)，后续观测仍由真实环境执行获得。
- **Action Judge（动作判别）**：
  - 输入：预执行状态 \(s_t\)；输出：决策效果标签 \(\hat y_t\in\{\textsc{Critical},\textsc{Exploratory},\textsc{Noisy}\}\)。
  - **Critical**：关闭关键缺口、获取必要证据或执行必需状态变化，属于紧凑解路径。
  - **Exploratory**：有意义地降低不确定性或测试合理分支，保留有用探索。
  - **Noisy**：预期进展很小，或导致重复、无关、违反约束、错误方向。
- **State Revision（状态修订）**：
  - 仅当 Action Judge 判为 **Noisy** 时触发。
  - 从同一历史 \(h_t\) 生成新的推理与动作 \((\tilde r_t,\tilde a_t)\sim M_{SR}(\cdot\mid s_t)\)。
  - 修订后的推理可调和冲突信息、修正无依据假设、更新计划；修订后的动作将修正转化为下一次真实交互。
- **EditAct（编辑 + 执行）**：
  - 每个非最终步，智能体先提议 \((\hat r_t,\hat a_t)\)。
  - Action Judge 判断 \(\hat y_t\)。
  - 若为 Critical/Exploratory，提交原对；若为 Noisy，提交 State Revision 生成的 \((\tilde r_t,\tilde a_t)\)。
  - 提交动作在真实环境 \(E\) 中执行，得到 \(o_t\sim E(\cdot\mid h_t,a_t)\)，并更新历史 \(h_{t+1}=h_t\oplus(r_t,a_t,o_t)\)。
  - 关键区别：不是给智能体“批评/提示”让其重生成，而是直接替换后续决策所依据的状态。
