## 摘要
个性化智能体需要基于长期历史交互进行推理，以推断显式偏好和隐式行为证据。虽然早期扁平检索方法独立地对记忆片段打分，忽略了分布式信息，但当前结构化记忆框架依赖与查询无关的静态图，无法捕捉依赖上下文的关系。关键在于，原始文本记忆本质上是纠缠且嘈杂的，使得细粒度个性化和跨会话推理在计算上难以承受。为此，我们提出 LGM，一种新颖的神经符号框架，将长期记忆解耦转移到连续潜在空间。具体而言，(i) 不同于持久化固定图，我们设计了一种结合稀疏自编码器的定制化潜在图构建方法。针对每个查询，它将历史交互映射为潜在记忆节点，并将记忆轨迹解耦为稀疏概念激活，动态合成查询感知的关系边权重。(ii) 然后，图编码器将查询嵌入视为条件偏好，以指导跨任务特定潜在子图的非线性消息传递。这产生了高度表达性的记忆表示，以实现有效激活。在长期个性化基准上的大量实验表明，LGM 在捕捉显式和隐式偏好方面显著优于最先进的基线，同时能够实现个性化响应。

## Abstract
Personalized agents are required to reason over long-term history interactions to infer both explicit preferences and implicit behavioral evidence. While early flat retrieval methods score memory fragments independently and neglect the distributed information, current structured memory frameworks rely on query-agnostic static graphs that fail to capture the context-dependent relations. Crucially, raw textual memories are inherently entangled and noisy, making fine-grained personalization and cross-session reasoning computationally prohibitive. To this end, we present LGM, a novel neuro-symbolic framework that shifts long-term memory disentanglement into a continuous latent space. Specifically, (i) instead of persisting fixed graphs, we design a tailored latent graph construction with a sparse autoencoder. Subject to each query, it maps historical interactions into latent memory nodes and disentangles the memory traces into sparse concept activations, dynamically synthesizing query-aware relational edge weights. (ii) A graph encoder then treats the query embedding as a conditioning preference to direct non-linear message passing across the task-specific latent subgraph. This yields a highly expressive memory representation for effective activations. Extensive experiments on long-term personalization benchmarks demonstrate that LGM significantly outperforms state-of-the-art baselines in capturing both explicit and implicit preferences while enabling personalized responses.

- **现有两条路线的缺陷**：
  - **扁平检索（flat retrieval）**：历史轮次或摘要片段被独立嵌入、按向量相似度检索打分，**孤立打分**导致跨远距离会话的分布式、多跳证据被漏掉。
  - **结构化记忆框架（如 GraphRAG）**：依赖**与查询无关的静态图**，邻接结构一旦建好就固定，无法推断"只在特定查询触发下才浮现"的上下文相关关系。
- **根本困难**：原始文本记忆本质上是**纠缠且嘈杂**的——单次交互同时编码主题、意图、情感、情境，只有一小部分与当前请求相关。在 token/prompt 空间做细粒度偏好解耦与跨会话推理会带来 KV cache 膨胀、重复 LLM 调用、无关文本干扰等**不可承受的计算开销**。
- **核心研究问题**：能否在**不重复回放完整文本历史**的前提下，按需解耦并组织用户长期记忆？
- **三大张力**：(i) 原始文本与隐状态把显式偏好与细微习惯纠缠在一起，解耦时容易丢失长尾证据；(ii) 历史事件与查询的相关性随查询变化，刚性文本图重建太慢，拓扑需在隐空间中动态适配；(iii) 隐空间推理避免上下文饱和，但多步传播有信息坍缩风险，状态需同时保持紧凑与忠实。
- **整体含义**：论文将长期个性化重新表述为"**查询感知的记忆解耦 + 隐空间关系推理**"，把记忆管理从外部控制转变为内在可学习表示。

## 2. 方法论：LGM 框架

### 2.1 核心思想
将长期记忆的解耦、关联、聚合与利用全部搬到**连续潜在空间**，端到端可微；用**查询条件动态图**取代持久化的静态图；用**稀疏概念**对齐词汇上互不重叠的显式陈述与隐式线索。

### 2.2 关键技术细节（三阶段）

**阶段一：潜在记忆解耦（Latent Memory Disentanglement）**
- 每个历史交互与当前查询 `x ∈ H ∪ {q}` 输入 backbone，取 4 个等间距中间层 `{8,16,24,32}` 的隐藏状态**求平均**（低层携带词汇线索，高层携带语义/行为抽象，隐式偏好存在于混合中），再做 masked mean pooling、投影与 LayerNorm，得到共享潜在空间的隐节点 `z_x ∈ R^d`（d=32）。
- 查询与记忆由同一模型编码，因此位于同一空间，后续可作**控制信号**而非单纯检索键。
- 挂接**稀疏自编码器（SAE）**：`c_x = S(ReLU(W_enc z_x))`，`ẑ_x = W_dec c_x`，其中 `S(·)` 抑制弱激活。稀疏非负概念码 `c_x` 是可解释单元，用于把直接偏好陈述与间接行为线索对齐到共同概念空间。
- SAE 损失：`L_sae = ‖ẑ_x − z_x‖² + λΩ(c_x)`，即"区分一段记忆**关于什么**"与"它**如何被说出**"。

**阶段二：查询条件潜在图构建（Query-Conditioned Latent Graph）**
- 图 `G(q) = (V, E, ω)`，节点集为查询节点与全部记忆节点；**边权是查询的函数**：`ω_{q→i} = φ(c_q, c_i) ∈ [0,1]`（归一化概念重叠）。同一记忆池在不同查询下诱导出不同拓扑。
- 加入自环与双向、typed 的 query↔memory 关系 `r_ij`，使查询既能门控记忆又能回收证据。
- 关系图网络执行 `T=4` 步消息传递：
  - `m_i^(t) = Σ_{j∈N(i)} ω_{j→i} ψ(z_i^(t), z_j^(t), r_ij)`
  - `z_i^(t+1) = Upd(z_i^(t), m_i^(t))`
- 置换不变 readout 得到紧凑记忆状态 `g = Readout({z_i^(T)})`，评分头给出节点级相关性 `s_i = ⟨z_i^(T), g⟩`。这一步把若干**单独很弱的线索沿查询激活的边组合成一条推断出的隐式偏好**，而非按记录排序。

**阶段三：图条件推理（Graph-Conditioned Reasoning）**
- 投影器把 `g` 映射为 `p=16` 个软潜在前缀 token `P̃`，每个重缩放到普通 token embedding 的范数，使其"提供信息但不主导注意力"。
- 前缀前置到查询嵌入：`y ∼ f_θ([P̃; E(q)])`，长历史通过紧凑潜在通道影响生成，而非作为原始上下文回放。

**训练目标**
- 生成监督（监督参考回复文本而非选项分类，避免退化为分类并损害流畅性）：`L_gen = −Σ_t log f_θ(y*_t | y*_{<t}, [P̃; E(q)])`
- **证据重构**（针对潜在记忆的已知失效模式：前缀坍缩成模型直接忽略的无信息信号）：`L_recon = −Σ_t log f_θ(e*_t | e*_{<t}, [P̃; E(ρ)])`，用同一前缀在固定解码指令 ρ 下重构支撑证据文本。
- 总目标：`L = L_gen + L_recon + L_sae`，端到端训练。

**算法流程（文字版）**：编码历史+查询 → 每个单元生成隐节点并经 SAE 解耦为稀疏概念 → 计算查询-记忆概念重叠得到边权并建查询专属图 → T 步加权消息传递 → readout 得单一记忆状态 g → 投影为少量前缀 token → 前置查询后生成回答；训练时额外要求同一前缀重构支撑证据。
