## 摘要
长期对话中的问答智能体必须对海量且时间上分散的对话历史进行推理。然而，现有记忆机制主要将过去信息视为被动存储的事实，导致语义鸿沟和不可靠推理。为了解决这一局限，我们提出 RuleMem，一种基于规则的记忆框架，它从历史交互中归纳出可复用的逻辑规则，以主动指导证据检索和推理。具体而言，RuleMem 从对话中构建自然语言 Horn 子句，并通过规则困惑度一致性（Rule Perplexity Consistency, RPC）机制对其进行验证。这些归纳出的规则能够检索语义上相距较远的证据，同时为答案生成提供显式的逻辑结构。我们在两个长期对话基准 LoCoMo 和 LongMemEval_s* 上对 RuleMem 进行了全面评估。在 LoCoMo 上与 14 个基线进行严格比较时，RuleMem 取得了最高准确率，超出基线平均值 27.47 个百分点（相对提升 54.3%）。

## Abstract
Question answering agents in long-term conversations must reason over massive, temporally dispersed dialogue histories. However, existing memory mechanisms primarily treat past information as \textit{passively} stored facts, leading to semantic gaps and unreliable reasoning. To address this limitation, we propose RuleMem, a rule-based memory framework that induces reusable logical rules from historical interactions to \textit{actively} guide both evidence retrieval and reasoning. Specifically, RuleMem constructs natural-language Horn clauses from conversations and validates them via a Rule Perplexity Consistency (RPC) mechanism. These induced rules enable the retrieval of semantically distant evidence while providing an explicit logical structure for answer generation. We conducted a comprehensive evaluation of RuleMem on two long-term conversational benchmarks, LoCoMo and LongMemEval_s*. In a rigorous comparison against 14 baselines on LoCoMo, RuleMem achieved the highest accuracy, exceeding the baseline average by 27.47 points (a 54.3% relative improvement).

## 1. 核心问题与整体含义（研究动机与背景）

- **研究场景**：长期对话中的问答（QA）智能体需要在海量、非结构化、时间上高度分散的对话历史上进行推理。受限于 LLM 有限的上下文窗口与参数化记忆更新困难，外部记忆模块已成为智能体的标准组件。
- **两大核心挑战**：
  - **语义鸿沟导致的召回失败（recall failure）**：问题与证据之间往往没有字面或浅层语义重叠。例如问"Alice 为什么缺席会议"，历史记录里只写了"Alice 预订了假期"，不含"缺席"一词。
  - **长上下文中的推理失败（reasoning failure）**：即使证据被正确召回，LLM 在冗长、松散组织的上下文中仍容易断裂逻辑链或产生幻觉。
- **现有范式的不足**：作者将已有智能体记忆划分为两个抽象层级——
  - **事实记忆（fact memorization）**：直接存储对话片段或实例级事实，依赖词法/浅层语义相似度检索（MemGPT、Mem0、LangMem 等），易因语义鸿沟召回失败。
  - **事实组织（fact organization）**：用时间知识图谱、Zettelkasten 语义网络、层次化摘要等建立结构连接（Zep、Mem0g、A-MEM、MemInsight 等），但仍停留在实例级；记忆规模扩大后密集的实例连接引入大量与查询无关的噪声，LLM 需自行判断哪些事实是有效前提，仍会导致推理失败。
- **核心主张**：提出更高抽象层级的 **规则归纳（rule induction）**——记忆不应只是"被回忆的对象"，而应主动指导检索与推理。受人类认知（从具体观察中归纳可复用规则）启发，RuleMem 从历史交互中归纳可复用逻辑规则，作为演绎推理中的**显式大前提**（major premise），弥合语义鸿沟并约束推理过程。

## 2. 方法论

### 2.1 核心思想
- 以"**自底向上归纳 → RPC 验证 → 自顶向下演绎**"构成闭环，维护两个记忆空间：
  - **事实记忆库 $M_F$**：存储从对话抽取的时间事实；
  - **规则记忆库 $M_R$**：存储从具体推理轨迹归纳出的自然语言规则。
- 规则采用**自然语言 Horn 子句**形式，兼顾形式逻辑的结构严谨性与自然语言的语义灵活性。

### 2.2 自底向上的规则记忆构建
- **事实记忆（Fact Memorization）**：解析长对话，抽取主体实体、关系、客体实体与时间戳，形成时间四元组 $F=\{(e_s, r, e_o, t)\}$，构成 $M_F$。
- **推理路径挖掘（Reasoning Path Mining）**：将 $F$ 组织为图结构，通过**受限随机游走**采样候选路径；由 LLM 过滤不合逻辑的路径，并结合原始对话片段重建有效路径，得到连贯推理路径 $P_c$，作为规则归纳的"未泛化前驱"。
- **规则归纳（Rule Induction）**：将关系模式相同/相似的路径分组，由 LLM 归纳共享规则；归纳时抽象掉具体实体名（如 Alice、Bob、Marathon），替换为类型占位符（`[Person]`、`[Event]`、`[Location]`）。每条规则 $r \in M_R$ 表示为 Horn 子句：

$$r:\; B_1 \wedge \cdots \wedge B_n \;\Rightarrow\; H,\quad n\ge 1$$

其中 body $T(r)_A$ 为非空合取体，head $T(r)_C$ 为单个原子结论，各原子为可含类型占位符的自然语言关系短语。

### 2.3 RPC（Rule Perplexity Consistency）规则验证
- **动机**：归纳只从有限样例总结模式，不保证正确性，LLM 直接归纳易产生过度泛化或幻觉规则。RPC 用**困惑度下降量**近似规则在连续语义空间中的支持度。
- 记 $\ell_M(T|C)$ 为自回归模型 $M$ 在上下文 $C$ 下对目标文本 $T$ 的平均负对数似然：
  - **内部一致性信号**：$\Delta_{self}(r)=\ell_M(T(r)_C\mid\varnothing)-\ell_M(T(r)_C\mid T(r)_A)$，衡量规则体对结论的支撑。
  - **外部事实一致性信号**：从 $M_F$ 检索相关证据 $T(r)_E$，$\Delta_{fact}(r)=\ell_M(T(r)_C\mid T(r)_A)-\ell_M(T(r)_C\mid T(r)_A\oplus T(r)_E)$。
  - **综合置信度**：$\mathrm{RPC}(r)=\alpha\cdot\sigma(\Delta_{self}(r))+(1-\alpha)\cdot\sigma(\Delta_{fact}(r))$，$\sigma$ 为 Sigmoid 归一化，$\alpha\in[0,1]$ 平衡两项权重。
  - 仅当 $\mathrm{RPC}(r)>\tau$ 时规则才被写入 $M_R$。

### 2.4 自顶向下的规则引导问答
- **规则检索（Retrieval Rules）**：不直接从问题跳到事实检索，而是先将问题与规则头 $T(r)_C$ 做余弦相似度匹配，激活 Top-N 规则 $R_{active}$，把问题映射到抽象结论空间。
- **引导召回（Guided Recall）**：以激活规则的规则体 $T(r)_A$ 作为检索线索，从 $M_F$ 取 Top-K 候选事实 $E(r)_{cand}$；由于类型变量缺乏形式化绑定与合一，引入 **LLM 作为语义合一算子**，结合问题中的具体实体与规则体中的类型约束过滤错误绑定的事实，保留 $E(r)_{guided}$。
- **显式推理（Explicit Reasoning）**：将问题、激活规则、召回证据组织为结构化提示；规则充当演绎逻辑中的大前提/推理脚手架，证据充当情节性小前提，缓解推理失败。
