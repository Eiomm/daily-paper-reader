## 摘要
长期运行的 LLM 智能体是有状态的：除对话记录外，它们还会不断累积压缩摘要、明文记忆、待执行的工具计划，并且在每个服务 API 下都还有一个 KV 缓存。然而，如今的“遗忘”操作只删除一条明文记忆记录就停止，使所有源自被撤销信息的产物都保持原样。我们将执行状态遗忘形式化：在收到遗忘请求后，智能体必须表现得仿佛从未观察到目标一样。将运行时建模为确定性转移系统，我们证明：目标之前的轨迹前缀可免费与该反事实世界共享；没有 token 级归因时，目标之后的后缀不可避免地受到污染；而精确遗忘至少需要 $T-τ+1$ 次重算转移，其中 $τ$ 是目标的注入步。Provenance-Guided Selective Replay（来源引导的选择性重放）作为一项跨越提示、压缩记忆和缓存的跨层契约达到了这一下界：来源图定位注入点，检查点恢复可简化为裁剪 KV 缓存，净化重放则重新生成反事实后缀。在三个智能体套件、九个基线和三个模型家族上，通过诱导、随机和无字符串行为测试进行审计后发现：记忆删除使泄漏保持不变，基于指令的遗忘在诱导下崩溃（Leak@probes = 1.00），源遮蔽在 80% 的片段中仍会对已撤销的偏好起作用，而选择性重放与完全重置无法区分，且重算 token 最多减少 9 倍。

## Abstract
Long-running LLM agents are stateful: beyond the transcript they accrete compressed summaries, plaintext memory, pending tool plans, and, under every serving API, a KV cache. Yet today's "forget" operations delete a plaintext memory record and stop, leaving every artifact derived from the revoked information intact. We formalize execution-state unlearning: after a forget request, the agent must behave as if it had never observed the target. Modeling the runtime as a deterministic transition system, we prove that the pre-target trajectory prefix is shared with this counterfactual world for free, that the post-target suffix is irreducibly tainted without token-level attribution, and that exact unlearning requires at least $T-τ+1$ recomputed transitions, where $τ$ is the target's injection step. Provenance-Guided Selective Replay attains this bound as a cross-layer contract spanning prompt, compressed memory, and cache: a provenance graph locates the injection point, checkpoint restoration reduces to cropping the KV cache, and sanitized replay regenerates the counterfactual suffix. Audited with elicitation, stochastic, and string-free behavioral tests across three agent suites, nine baselines, and three model families, memory deletion leaves leakage unchanged, instruction-based forgetting collapses under elicitation (Leak@probes = 1.00), and source redaction still acts on a revoked preference in 80% of episodes, while selective replay is indistinguishable from a full reset at up to 9x fewer recomputed tokens.

# 论文总结：Forgetting Without Restarting: Execution-State Unlearning for Stateful LLM Agents

## 1. 核心问题与整体含义

- **研究动机**：长时运行的 LLM Agent 是有状态的，其运行时状态不仅包括对话记录，还包括压缩摘要、明文长期记忆、待执行工具计划、工具轨迹，以及底层 KV 缓存。
- **核心问题**：现有“遗忘”操作通常只删除一条明文记忆记录或从检索中移除消息，但由该信息派生出的摘要、计划、缓存张量等仍然保留，导致被撤销的信息继续影响 Agent 行为。
- **整体含义**：论文将“遗忘”重新定义为**执行状态遗忘**：收到遗忘请求后，Agent 必须表现得像一个从未观察过目标信息的“反事实孪生 Agent”。
- **关键背景**：间接提示注入、用户中途撤销同意、误粘贴秘密等场景中，信息一旦进入上下文就会被压缩、蒸馏、持久化并缓存；检测或撤销往往发生在事后，因此需要一种可证明的运行时补救原语。

## 2. 方法论：核心思想与关键技术

- **核心思想**：将 Agent 运行时建模为确定性转移系统：
  \[
  R_t = F(R_{t-1}, o_t;\theta)
  \]
  其中 \(R_t\) 是可重构运行时状态，\(o_t\) 是外部观测流。目标 \(z\) 在步骤 \(\tau\) 首次进入。反事实轨迹 \(R^{-z}_t\) 表示从未见过 \(z\) 的世界。
- **精确遗忘定义**：遗忘算子 \(U\) 精确当且仅当 \(U(R_T,z)=R^{-z}_T\)；随机解码下松弛为未来行为分布 \(\varepsilon\)-一致。
- **两个关键引理**：
  - **前缀共享引理**：对 \(t \le \tau-1\)，真实轨迹与反事实轨迹完全相同，因此干净前缀可免费复用，恢复它等价于裁剪 KV 缓存。
  - **污染单调性与可证明边界**：一旦目标进入，其影响沿数据流可达闭包传播到摘要、计划和工具调用；没有 token 级归因时，\(\tau\) 及之后的原始状态不可安全复用，只能重放。
- **拼接定理**：若存在 \(\tau-1\) 或更早的干净检查点，且满足确定性解码、净化观测与反事实观测一致、无已提交外部副作用，则从检查点重放可精确重建 \(R^{-z}_T\)。
- **最优性下界**：精确遗忘至少需要 \(T-\tau+1\) 次重算转移；重放成本由反事实分歧后缀长度决定，而非整个会话长度。
- **系统实现：Provenance-Guided Selective Replay**：
  - **来源图**：记录 artifact 级数据流，定位注入点 \(\tau\) 和污染闭包 \(I(z)\)。
  - **稀疏检查点**：仅在元数据层面保存 token 偏移、缓存句柄、环境快照 ID 等；恢复即裁剪 KV 缓存。
  - **净化重放**：丢弃目标 \(z\)，保留其余观测；只读/确定性工具重放或从快照恢复，有后果工具影子执行并去重，避免真实副作用二次触发。
  - **算法流程**：定位来源 → 找首次进入边界 → 计算污染闭包 → 选最近干净检查点 → 裁剪恢复 → 对后缀逐步净化重放 → 返回反事实等价状态。

## 6. 主要结论与发现

- **删除不等于遗忘**：B1 Memory-Delete 与 B0 No-Forget 在所有单元格几乎相同，泄漏不变（any-leak 0.86–1.00），目标仍存活于答案、摘要、计划和缓存。
- **指令遗忘只是抑制**：B2 在单任务探针上看似有效，但 Leak@probes = 1.00，在六种诱导探针下目标仍可被提取。
- **源遮蔽仍会行为泄漏**：B3 在 80% 的偏好 episode 中仍按被撤销偏好行动，即使字符串泄漏为零。
- **IFC 不能清理已污染状态**：B8 仅阻止未来标识符流，仍以 B0 速率通过自由文本泄漏；B9 组合重放后降为零。
- **选择性重放达到精确等价**：B7 与 B5 Full-Reset 在所有审计中不可区分，any-leak = 0、CAD = 0，行为分布无显著差异。
- **效率优势显著**：B7 重算 token 比 Full-Reset 少最多 9.3 倍（133 vs. 1235），比 prefix-cache 控制 B5′ 少 1.5 倍。
- **成本遵循 \(T-\tau+1\) 规律**：重算成本随目标注入步 \(\tau\) 线性下降，\(R^2=1.000\)，而非随会话长度增长。
- **失效边界实验支持理论**：只切除目标 span 仍泄漏，CAD 甚至比不遗忘更差；需后代闭包加净化重放才能同时保证安全与等价。
