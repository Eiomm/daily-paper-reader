## 摘要
由大型语言模型（LLMs）驱动的自主智能体通过交互不断积累经验，这为通过自演化改进未来行为创造了机会。一个根本性挑战在于，如何将大量任务特定的交互经验转化为可复用的模型能力，同时不牺牲对新观测证据快速适应的能力。显式文本状态（如技能和智能体运行框架）能够提供快速、人类可读且可编辑的适应，但会持续依赖外部上下文；参数化策略提供紧凑且可复用的能力，但更新速度要慢得多。我们提出“经验漏斗”（Experience Funnel），一个自演化框架，它在交替循环中将快速的状态适应与缓慢的策略巩固耦合起来。交互轨迹首先被蒸馏为显式文本状态，新获得的经验可以在其中被快速纳入并验证。该框架随后有选择地识别那些在状态修订之间仍具用处的由状态使能的行为，并通过转移感知蒸馏将其巩固到策略中。更新后的状态—策略对随后生成新的 rollout，为下一轮状态适应与策略巩固提供新证据。在不同智能体基准上的实验表明，与仅状态演化和策略内化方法相比，“经验漏斗”持续提升智能体能力，同时逐步将有用的显式经验转化为自主策略能力。

## Abstract
Autonomous agents powered by large language models (LLMs) continuously accumulate experience through interaction, creating an opportunity to improve future behavior through self-evolution. A fundamental challenge is how to transform abundant, task-specific interaction experience into reusable model competence without sacrificing the ability to adapt rapidly to newly observed evidence. Explicit textual states, such as skills and agent harnesses, provide fast, human-readable and editable adaptation, but incur persistent dependence on external context; parametric policies provide compact and reusable competence, but are substantially slower to update. We present \textit{Experience Funnel}, a self-evolving framework that couples fast state adaptation with slow policy consolidation in an alternating loop. Interaction trajectories are first distilled into an explicit textual state, where newly acquired experience can be rapidly incorporated and validated. The framework then selectively identifies state-enabled behavior that remains useful across state revisions and consolidates it into the policy through transition-aware distillation. The updated state--policy pair subsequently generates new rollouts, providing fresh evidence for the next round of state adaptation and policy consolidation. Experiments across diverse agent benchmarks show that \textit{Experience Funnel} consistently improves agent capability over state-only evolution and policy-internalization approaches, while progressively converting useful explicit experience into autonomous policy competence.

- **两种互补但各有缺陷的经验表征**：
  - **显式文本状态**（记忆、技能、流程指令、agent harness）：适应快、人类可读、可编辑，但持续依赖外部上下文，无限累积会导致检索与上下文开销上升、产生冗余/冲突指导、需要复杂的记忆管理。

## 2. 论文提出的方法论

### 2.1 核心思想：状态—策略交替循环（State–Policy Alternating Loop）

- 在**快速状态适应**与**缓慢策略固化**之间建立交替循环，演化序列为：
  `(S_k, π_k) → S_{k+1} → π_{k+1} → S_{k+2} → π_{k+2} → …`
- 新经验先在任务特定文本状态中组织（可快速纳入与验证），可复用的经验再逐步固化进长期策略，两种表征联合演化。

### 2.2 阶段一：状态演化（State Evolution）

- **轨迹收集**：当前状态—策略对在部署中累积交互轨迹，冻结为 reflection batch。
- **跨轨迹反思**：跨交互联合识别**反复出现的行为模式**（而非从单个样本推导修正），总结为高层文本经验，包括可复用流程、常见失败模式、纠正策略，表示为对当前状态的候选编辑。
- **验证门控**：候选更新在独立 held-out 验证集上、以当前策略评估环境级结果，**只有提升才被接受**。跨轨迹反思提取可复用经验，held-out 验证过滤样本特定或不可靠更新。

### 2.3 阶段二：转移感知技能蒸馏（Transition-Aware Skill Distillation）

**（a）转移感知的 rollout 选择**

- 对每个交互实例 `x_i`，分别评估当前策略 `π_k` 在三种条件下的表现：无状态 `r_i^0`、前一状态 `r_i^-`、验证后的更新状态 `r_i^+`。
- 相对无状态执行的行为效用：`b_i^- = I[r_i^- > r_i^0]`，`b_i^+ = I[r_i^+ > r_i^0]`。
- 用转移对 `(b_i^-, b_i^+)` 区分四类行为：
  - `(0,1)` **新有用**（仅状态更新后才有效）
  - `(1,1)` **持续有用**（跨状态版本始终有效）
  - `(1,0)` **退化**
  - `(0,0)` **无效**
- 保留前两类用于固化，权重 `a_i`：`(0,1)` 取 1，`(1,1)` 取 `α`（控制持续有用行为的相对贡献），其余为 0。

**（b）状态响应 token 归因**

- 在相同前缀下，对比冻结策略 `π_k` 在**有/无已接受状态**条件下的 token 分布：`p_{i,t}^+` 与 `p_{i,t}^0`。
- 两分支共享同一模型参数、仅文本状态条件不同，其预测差异可隔离出对已接受状态的局部行为响应。
- 用 Jensen–Shannon 散度量化响应：`d_{i,t} = D_JS(p_{i,t}^+ ∥ p_{i,t}^0)`，并在每条轨迹内归一化为 `w_{i,t}`。
- 作用：`a_i` 决定**哪些 rollout** 参与固化，`w_{i,t}` 强调**哪些决策**最响应已接受状态。

**（c）策略固化**

- 设 `π_θ` 为从 `π_k` 初始化的可训练策略；状态条件分支 `p_{i,t}^+` 提供特权监督，而 `π_θ` 只接收无状态上下文。
- 蒸馏损失 `L_distill` 为按 `a_i·w_{i,t}` 加权的、学生与状态条件教师之间的 KL 散度（归一化形式）。
- 与无状态奖励优化结合：`L_consolidate = L_state-free RL + λ_distill · L_distill`。
  - 奖励目标从环境反馈改进自主行为；蒸馏内化由验证状态使能的行为。
- 候选策略 `π̃_{k+1}` 仅在无状态性能满足验证标准时才被提交，随后回到部署，开启下一轮演化。

## 6. 论文的主要结论与发现

1. **整体性能最优**：在三个环境均取得最佳表现——SearchQA 62.4%、ALFWorld 67.9%、WebShop 42.4%，平均 57.6%。相比最强显式状态方法 SkillOpt（53.9%）提升 3.7 分，相比最强策略内化方法 OPID（55.4%）提升 2.2 分，相比最接近的状态—策略协同演化基线 SkillRL（56.2%）提升 1.4 分且三环境全面领先。
2. **经验逐步转化为自主能力**：在被接受的固化轮次中，state-free 策略准确率从 58.1% 升至 61.3%，说明交互经验被逐步内化为自主策略能力；再叠加演化后的状态可进一步提升至 62.4%。
3. **显式经验的价值日益依赖其共演化的策略**：同一演化状态与初始策略配对仅得 60.2%，与共演化策略配对得 62.4%；中间阶段差距为 0.8 分，最终阶段扩大至 2.2 分，直接支持"状态与策略应联合演化"的设计选择。
4. **选择性固化显著优于不加过滤的固化**：组合新有用（0→1）与持续有用（1→1）经验达到 63.0% ACC，远超未过滤训练（58.9%）、仅 0→1（55.2%）、仅 1→1（59.9%），提升幅度分别为 4.1 和 3.1 分。
5. **增益源于状态条件而非教师规模**：27B 教师在不做状态条件时仅得 56.29%（低于基线），条件化于演化状态时达到 61.21%；增益来自"教师作为演化状态执行者"的交互效应，而非通用知识蒸馏。
6. **固化后残余状态仍然有用**：固化将 state-free 性能从 58.1% 提升至 61.3%，重新引入完整演化状态进一步升至 62.4%；而残余化配置在不需要完整状态的情况下维持 61.3%，说明可复用经验被吸收、显式状态仅保留仍具互补性的信息。

## 7. 优点

- **问题定位精准**：抓住了"显式文本状态适应快但依赖上下文、参数化策略可复用但更新慢"这一本质矛盾，并提出用**交替循环**而非单向内化来解决，视角新颖。
- **转移感知选择机制设计精巧**：用 `(b^-, b^+)` 四象限区分"新有用 / 持续有用 / 退化 / 无效"行为，避免了"把所有状态条件轨迹都拿来训练"的冗余监督问题。
- **Token 级归因有效**：通过共享参数、仅状态条件不同的双分支 JSD 对比，精确定位"状态响应型"决策，使蒸馏信号更聚焦。
- **验证门控贯穿始终**：状态修订与策略 checkpoint 均经 held-out 验证，降低固化噪声风险。
- **数据协议严谨**：训练/验证/测试角色严格分离，测试集不参与任何更新。
- **对照实验设计有说服力**：教师容量与状态条件的交叉对照有效排除了"大模型通用知识"这一替代解释。
- **残余状态分析**完整展示了"什么该留在外部、什么该内化"的预期行为，与框架动机自洽。

## 8. 不足与局限

- **适用域受限**：框架面向部署后反复遇到相关任务、且能获得充分信息性环境反馈的场景，适用于可交互、可验证的领域（网页导航、工具使用、重复工作流），对**一次性任务**或**反馈高度主观/稀疏**的领域直接适用性有限。
- **计算开销与延迟**：多条件 rollout 评估、状态修订、策略固化均带来额外演化期计算，构成"计算—适应"权衡；虽然作者指出更新可异步/周期性进行（在线收集、低负载期固化），但这会引入经验获取到模型更新之间的**延迟**。
- **统计可靠性不足**：多数配置仅单次运行，最终对比才报告重复运行不确定性；教师—学生交互效应需重复实验才能确认统计显著性。
- **跨环境比较非受控**：不同环境使用不同 OPD 预算，跨环境平均值仅为描述性总结。
