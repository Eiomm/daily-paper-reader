## 摘要
无奖励的潜在世界模型能够从离线视频中学习，并通过在预测的潜在未来中优化动作来解决新的图像目标任务。这种设定对规划状态提出了两项要求：其坐标必须能够与目标图像进行比较。此外，其动力学必须保留速度、运动趋势、接触以及其他依赖历史的信息，而这些信息超出了上述目标坐标。离线训练还造成第二个不匹配：每条记录的轨迹只揭示一个事实未来，而基于采样的规划器会比较许多并非从同一状态采取的动作。我们提出 FIRM-WM（事实-干预循环世界模型），一种围绕这两个缺口设计的紧凑像素世界模型。其循环状态将一个类型化的、可与目标比较的配置与一个 128 维动态纤维分离；后者用于预测，但不纳入终端目标代价。广泛的事实轨迹提供状态覆盖，而共同重置的干预分支为替代动作序列提供观测结果。在执行每个分支之前，我们重置环境，并恢复环境的状态设置接口所暴露的相同记录值。在匹配的 CEM 规划与三个独立全流程随机种子下，FIRM-WM 在 TwoRoom 上达到 99.0±1.0%，在 Reacher 上达到 92.7±2.1%，在 OGBench-Cube 上达到 88.0±3.0%，而 LeWM 分别为 89.0%、88.0% 和 70.0%。部署模型使用 2.98–3.42M 参数，并在这些任务上实现 2.13–11.60× 的规划时间降低。

## Abstract
Reward-free latent world models can learn from offline videos and solve new image--goal tasks by optimizing actions through predicted latent futures. This setting places two demands on the planning state: its coordinates must be comparable with a goal image. Moreover, its dynamics must retain velocity, motion trend, contact, and other history--dependent information beyond those goal coordinates. Offline training creates a second mismatch: each recorded trajectory reveals one factual future, whereas a sampling--based planner compares many actions that were not taken from the same state. We introduce FIRM-WM (Factual--Interventional Recurrent World Model), a compact pixel world model designed around these two gaps. Its recurrent state separates a typed, goal--comparable configuration from a 128-dimensional dynamic fiber used for prediction but excluded from the terminal goal cost. Broad factual trajectories provide state coverage, while common--reset intervention branches provide observed outcomes for alternative action sequences. Before executing each branch, we reset the environment and restore the same recorded values exposed by the environment's state--setting interface. Under matched CEM planning and three independent full-pipeline seeds, FIRM-WM reaches 99.0$\pm$1.0% on TwoRoom, 92.7$\pm$2.1% on Reacher, and 88.0$\pm$3.0% on OGBench-Cube, compared with 89.0%, 88.0%, and 70.0% for LeWM. The deployed model uses 2.98--3.42M parameters and records 2.13--11.60$\times$ lower planning time on these tasks.

# FIRM-WM 论文结构化总结

## 一、核心问题与整体含义（研究动机与背景）

- **研究背景**：无奖励潜在世界模型（latent world model）可从离线视频中学习与任务无关的动力学，部署时给定当前观测与目标图像，用 CEM（Cross-Entropy Method）在学到的预测器中滚动候选动作序列、优化潜在终端代价，从而解决新的图像目标任务。代表性工作包括 PlaNet、DINO-WM、PLDM、LeWM、Fast-LeWM 等。
- **核心问题一：规划状态的"表征张力"（representation tension）**。规划器既需要一个紧凑、可与静态目标图像直接比较的坐标系统（如位置、关节角等**类型化配置**），又需要一个**动力学充分**的状态——两个历史可以有相同的配置，却在速度、运动方向、接触模式、未来可控性上不同。若用无约束的视觉潜在同时承担预测与目标比较，会把动力学差异与不影响终端代价的外观变化混在一起。
- **核心问题二：离线学习造成的"事实–干预缺口"（factual–interventional gap）**。每条离线轨迹只记录了**实际执行动作**所产生的那一个事实未来（factual continuation）；而 CEM 会从同一历史出发评估成百上千条**未被执行过的替代动作序列**（counterfactual planner queries）。事实训练只约束了已执行动作处的转移，替代动作的结果处于**欠定**状态。作者强调这与长时程误差累积不同，本质上是固定状态下动作激励不足导致受控动力学不可辨识（引 Zhang et al., 2026b）。
- **整体含义**：论文主张，面向无奖励像素规划的世界模型必须同时满足三点：(1) 终端状态含可直接与目标图像比较的坐标；(2) 循环状态保留预测该坐标演化所需的历史依赖信息；(3) 训练信号必须约束事实延续之外的其他动作结果。FIRM-WM 即针对这三点给出一个紧凑的像素世界模型方案。

## 二、方法论

### 2.1 核心思想：状态因子化

- 规划状态被显式分解为两部分：  
  **s_t = (c_t, m_t)，c_t ∈ C，m_t ∈ R^128**
  - **c_t（类型化配置）**：可从图像推断、与目标图像可比的物理坐标（位置、关节角的正余弦对、物体位姿分量等），**只它参与终端目标代价**。
  - **m_t（动态纤维）**：128 维学习到的动态上下文，保留速度、方向、接触等历史依赖信息，**用于预测但被排除在终端目标代价之外**。
- 转移递归更新两者，但终端代价只比较 c_t，使候选排序在任务坐标中可解释。

### 2.2 感知前端与因果历史信念

- 空间视觉 token：**p_t = E_φE(o_t, Δo_t)，Δo_t = o_t − o_{t−1}**（含帧差通道以编码运动线索）。
- 因果历史注意力融合近期 token 与执行动作：**b_t = B_φB(p_{t−L+1:t}, a_{t−L+1:t−1})**，弥补单帧图像无法提供的运动信息。

### 2.3 配置读出与动态纤维初始化

- 配置由共享的 grounder 从"去掉帧差通道"的图像编码读出：**c_t = G_ψ(E_φE(o_t, 0)) ∈ C**；目标图像走同一路径得到 c_g。
- 纤维初始化使用因果信念与近期配置变化：  
  **δc_t = [c_{t−1} − c_{t−2}, c_t − c_{t−1}]，m_t = R_ω([b_t, δc_t]) ∈ R^128**。
- 周期性角度以 (sin θ, cos θ) 存储，差值在正余弦对上取，避免 ±π 处跳变。

### 2.4 单一循环转移

- **(ĉ_{k+1}, m̂_{k+1}) = T_θ(ĉ_k, m̂_k, u_k)，k = 0, …, H−1**，u_k 为第 k 个宏动作。
- 所有任务共享**一个循环算子**（一个配置头 + 一个纤维头）；TwoRoom/Reacher/Cube 用紧凑残差 MLP 隐更新；Push-T 在同一隐更新内加入动作条件空间残差以保留接触几何。
- 增量作用于欧氏位置、正余弦角度与纤维，因此配置与动态上下文在整个 rollout 中同步演化。
- 训练期辅助解码器 **χ̂_k = D_ρ(m̂_k)** 将纤维映射到环境类型化动态目标（速度、位移、接触、剩余机器人状态等），**训练后丢弃，永不进入目标代价**。
- 计算效率：CEM 每次求解评估 15,000–45,000 个"候选–步"对，规划内循环中不重复做 token 级注意力。

### 2.5 事实 + 共同重置干预的双源监督

- **事实数据 D_F**：从离线轨迹抽取的 rollout 记录 ξF = (h_i, U^F_i, c_{i,0:H}, χ_{i,0:H})，提供广泛状态覆盖。
- **共同重置干预数据 D_I**：选定锚点 i，保存观测–动作历史 h_i 与环境状态设置接口暴露的记录值 x^sim_i；对每个替代宏动作序列 U_ij，先重置环境并恢复 x^sim_i，再执行动作并记录结果，得到 K_i 条分支 ℐ_i = {ξI_ij}。
- 作者特别澄清："共同重置"仅指**接口暴露变量在各分支间相同**，并不等于完整模拟器状态或内部求解器记忆完全相同（附录 D 说明 Cube 的 14 维 solver warm-start 被重新初始化）。
- **损失函数**（每个源 σ ∈ {F, I}）：  
  **ℓ_σ = ℓ_{σ,cfg}（未来配置）+ ℓ_{σ,disp}（配置位移）+ ℓ_{σ,dyn}（纤维动态）**
  - 配置项：位置用平方欧氏误差，角度用正余弦对之间的平方距离；
  - 位移项：用拓扑感知映射 Λ_κ（κ = emb 直接相减 / κ = rel 先合成角度再编码）匹配配置变化，避免静态场景内容主导损失；
  - 动态项：用 D_ρ 的输出监督训练期目标 χ_k。
  - 尾部分量用 TopMean_{0.25}（取误差最大的 25% 平均）。
- **最终联合目标**：**L_FIRM = E_{B_F∼D_F}[ℓ_F] + E_{B_I∼D_I}[ℓ_I]**，即把状态覆盖与动作覆盖在共同重置条件下结合。
- 训练是分阶段的（Algorithm 1），不同环境激活不同数据源：TwoRoom 为 F → (F+I)；Reacher 为 I → I → (F+I)；Push-T 为 (F+I)×6 → 结构化精修；Cube 为 F+I。模块按阶段冻结/微调，转移参数逐阶段继承。

### 2.6 无奖励潜在 MPC

- 目标图像经同一编码器与 grounder 得到 **c_g = G_ψ(E_φE(o_g, 0))**。
- 对每个候选序列预测终端配置 ĉ_H(U)，用**任务类型化距离**打分：  
  **J(U; h_t, o_g) = d_C(ĉ_H(U), c_g)**，其中 d_C 对欧氏分量用平方误差、对周期分量用单位圆弦距离（等价于 4sin²(δ/2)），Push-T 用任务归一化的方向/位置误差取 max 再平方。
- CEM 最小化 J，执行第一个宏动作，观测新图像，滚动重规划。纤维影响预测但不参与目标比较，使候选排序可解释为具名量（位置误差、关节角误差等）。

## 四、主要结果（结论层面）

- **主结果**：FIRM-WM 在四个连续控制任务上一致优于 LeWM 等无奖励潜在世界模型基线，尤其在 **Push-T（接触密集）** 与 **OGBench-Cube（高维操作）** 上提升显著；与任务专用方法的差距缩小，说明"紧凑像素世界模型 + 干预监督"可在无奖励设定下逼近专门设计。
- **验证两个核心假说**：
  - **表征张力**：仅配置状态在需要历史依赖（速度、接触）的任务上失败；仅纤维状态因终端代价不可比而排序混乱；两者因子化后同时具备可比终端坐标与充分动力学，成功率最高。
  - **事实–干预缺口**：仅用事实数据训练时，CEM 的替代动作查询出现系统性偏差（欠定转移被任意外推）；加入共同重置干预数据后，替代动作结果被显式约束，规划鲁棒性显著提升，且提升幅度在动作空间更大、接触更复杂的任务上更明显。
- **可解释性**：由于终端代价只在类型化配置上计算，CEM 的候选排序可被解读为具名量（如"目标位置差 0.03、朝向差 12°"），相较纯视觉潜在代价更易诊断；纤维仅影响预测，不引入不可解释的目标比较。
- **效率**：规划内循环避免重复 token 级注意力，单次 CEM 求解需评估 15,000–45,000 个"候选–步"对仍可实时运行；辅助解码器训练后丢弃，不增加部署开销。

## 五、贡献与创新点

1. **状态因子化（c_t, m_t）**：把"可与目标图像比较的类型化配置"与"承载历史依赖的动态纤维"显式分离，直接针对规划的表征张力，使终端代价既可解释又与动力学充分解耦。
2. **共同重置干预监督**：提出在接口暴露变量一致的条件下生成替代动作分支，显式约束事实延续之外的动作结果，针对离线学习的事实–干预缺口，且对"共同重置 ≠ 完整状态相同"做了诚实澄清。
3. **拓扑感知的配置损失与角度处理**：以 (sin θ, cos θ) 表示周期量、用 Λ_κ 映射匹配配置变化，避免 ±π 跳变与静态内容主导损失。
4. **无奖励潜在 MPC 的具名代价**：终端代价按任务类型化距离（欧氏平方误差 + 单位圆弦距离）计算，候选排序可解释。
5. **分阶段训练与数据源调度**：不同环境按阶段激活 F/I 数据与冻结/微调策略，转移参数逐阶段继承，兼顾覆盖与稳定性。

## 六、局限性与批判性评述

- **对"共同重置"接口的依赖**：干预数据的质量取决于环境能否暴露并恢复锚点变量；对无法重置或重置不完整的真实系统（如仅有人类演示、无可复位仿真器），该方法难以直接应用。论文虽承认求解器内部记忆（如 Cube 的 14 维 warm-start）未完全复现，但这意味着干预分支仍残留未观测的初始状态差异，可能给动力学监督引入噪声。
- **配置接口的人工设计**：c_t 的维度与语义（位置、关节角正余弦、物块位姿）需按任务给定，grounder 从图像读出；这削弱了"无奖励、通用"的宣称——任务类型的先验仍以配置空间形式注入，跨任务的配置设计并不自动。
- **动态纤维的容量与可迁移性**：m_t 固定为 128 维，其对长时程、多接触模式的可扩展性未充分讨论；纤维目标的辅助解码器 χ_k 也需按环境定义，属于额外的监督工程。
- **评测规模**：固定 100 组配对试验虽利于配对比较，但统计功效有限，置信区间与方法间显著性检验在文中不够突出；部分基线取自他人已发表数字，训练/评测协议可能存在不完全对齐。
- **理论刻画较薄**：对"事实–干预缺口"主要给出直觉与引证，缺少形式化的可辨识性条件（在何种动作激励、何种覆盖下受控动力学可被识别）与样本复杂度分析。
- **计算成本未系统报告**：训练阶段干预数据的生成（重置 + 多分支 rollout）与分阶段训练的总开销、以及相比纯事实训练的成本倍率，缺少量化对比。

## 七、一句话总结

FIRM-WM 通过把规划状态显式因子化为"可与目标图像比较的类型化配置 c_t"与"承载历史依赖的动态纤维 m_t"，并用"事实 + 共同重置干预"双源监督补齐离线数据在替代动作上的欠定，从而在无奖励像素规划中同时获得可解释的终端代价与更可靠的候选排序，在四个连续控制任务上优于 LeWM 等潜在世界模型基线。
