## 摘要
近年来，大语言模型（LLM）的进展使智能体能够在多样环境中处理长时程任务。为了进一步提升智能体性能，现有语言世界模型通常预测环境观测，然而在可获得真实反馈时，重建高熵、依赖执行的工具响应价值有限。与此同时，智能体受到任务状态污染的影响，其中缺乏支撑的假设和过时的计划持续留在历史中，并扭曲后续决策。我们提出 Agent-Editing 世界模型（AEWM），它建模推理与动作如何塑造未来任务进展，而非模拟工具响应。AEWM 结合 Action Judge 来区分 Critical、Exploratory 和 Noisy 决策，并利用 State Revision 从同一观测历史中编辑有噪声的推理—动作延续。EditAct 将这些能力与真实执行集成，直接改变后续决策所基于的状态，而不仅仅是提供批评。我们通过中期训练和监督微调，在 Search、Terminal 和 Software Engineering 上训练 AEWM。AEWM 在我们的 Action Judge 基准上达到 70.5% macro-F1，超过最强前沿基线 10.6 个点。在六个基准和三个智能体骨干上，EditAct 将平均分数较最强基线提升 3.2–6.7 个点。此外，在已验证的 EditAct 轨迹上进行拒绝采样微调，称为 AEWM-RFT，在没有在线 AEWM 指导的情况下，在三个领域上比 Self-RFT 提升 2.2–2.6 个点。

## Abstract
Recent advances in large language models (LLMs) have enabled agents to tackle long-horizon tasks across diverse environments. To further improve agent performance, existing language world models typically predict environment observations, yet reconstructing high-entropy, execution-dependent tool responses offers limited value when real feedback is available. Meanwhile, agents suffer from \emph{task-state contamination}, where unsupported assumptions and outdated plans persist in history and distort subsequent decisions. We propose the \textbf{Agent-Editing World Model (AEWM)}, which models how reasoning and actions shape future task progress rather than simulating tool responses. AEWM combines \textbf{Action Judge} to distinguish \textsc{Critical}, \textsc{Exploratory}, and \textsc{Noisy} decisions with \textbf{State Revision} to edit noisy reasoning--action continuations from the same observed history. \textbf{EditAct} integrates these capabilities with real execution, directly changing the state underlying subsequent decisions rather than merely providing critiques. We train AEWM across Search, Terminal, and Software Engineering through mid-training and supervised fine-tuning. AEWM achieves 70.5\% macro-F1 on our Action Judge benchmark, exceeding the strongest frontier baseline by 10.6 points. Across six benchmarks and three agent backbones, EditAct improves average scores by 3.2--6.7 points over the strongest baseline. Furthermore, rejection sampling fine-tuning on verified EditAct trajectories, termed \textbf{AEWM-RFT}, improves over Self-RFT by 2.2--2.6 points across three domains without online AEWM guidance.

# Agent-Editing World Model (AEWM) 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：LLM 智能体已能处理跨环境的长时间跨度任务。现有"语言世界模型"（language world model）大多沿用具身智能/视频生成领域的**以环境为中心的范式**，即预测动作条件下的下一观测或工具响应（如搜索结果、终端输出、代码执行反馈）。
- **核心质疑**：在智能体任务中，**真实工具反馈始终可获得**，而工具响应往往是**高熵、依赖具体执行状态**的（网页内容、文件系统、运行时状态），预测它们既困难，又在有真实反馈时价值有限，甚至可能引入"捏造证据"。
- **关键失败机制——任务状态污染（task-state contamination）**：智能体在部分观测下需维护假设、计划与判断，但常把**无支撑的假设当作事实**、**保留与反馈矛盾的计划**、**把部分进展误判为完成**。这些错误留在历史中并不断放大，仅靠真实观测并不足以修正。
- **核心问题**：语言世界模型究竟应该预测什么，才能支撑可靠的长时程智能体？论文主张：应建模**智能体的推理与动作如何塑造未来任务进展**，而非重建观测。

## 2. 方法论

### 核心思想
- 将世界模型从"观测预测"（$M_{obs}(o_t|s_t)$）转向**智能体状态编辑**（$M_{SR}$）：在动作执行前，直接改写有问题的推理—动作延续，改变后续决策所依赖的状态。
- 定义**执行前状态** $s_t = h_t \oplus (\hat r_t, \hat a_t)$，其中 $h_t$ 为任务与交互历史，$(\hat r_t, \hat a_t)$ 为智能体提出的推理—动作对。

### 两个核心能力（统一为单一模型 M）
- **Action Judge（动作裁判，$M_{AJ}$）**：在执行前将决策分为三类：
  - **Critical**：直接解路径上的必要步骤（获取关键证据、必要状态变更）。
  - **Exploratory**：有意义地降低不确定性或测试合理分支。
  - **Noisy**：几乎无进展，或重复、无关、违反约束、方向错误。
- **State Revision（状态修订，$M_{SR}$）**：对被判为 Noisy 的提案，从**同一历史**生成修订后的 $(\tilde r_t, \tilde a_t)$，保留 $h_t$，修正错误假设/过时计划，并通过真实环境交互补足缺失证据。

### EditAct：编辑与执行的集成
- 推理阶段流程：智能体提出 $(\hat r_t, \hat a_t)$ → Action Judge 打标签 → 若为 Critical/Exploratory 则保留，若为 Noisy 则调用 State Revision 替换 → 选定动作在真实环境执行 → 观测进入历史。
- 关键区别：不是仅提供"批评"（critique），而是**直接替换当前推理—动作延续**。

### 训练流程
- **数据合成**：
  - Action Judge 数据：将成功轨迹拆分为单轮，由强标注智能体标注每轮动作类型，生成**仅前向可见**的推理（cot）与标签，并过滤未来信息泄漏。
  - State Revision 数据：提案智能体尝试任务 → AJ 检查点判为 Noisy → 修订智能体生成替换 → **真实执行**替换动作，仅保留带来实质进展的样本。
- **两阶段训练**：
  - **Mid-training**：约 52.16B tokens（AJ 20.56B + SR 25.01B + 原始轨迹 6.59B），覆盖 Search/Terminal/SWE 三域，学习交互知识。
  - **SFT**：120K 高质量样本（AJ 60K + SR 60K，各域 40K），激活并校准两种能力。
- **AEWM-RFT**：在经真实反馈验证的 EditAct 轨迹上做拒绝采样微调（RFT），将 AEWM 引导的决策模式内化回智能体，推理时**无需在线 AEWM 指导**。

## 6. 主要结论与发现

- **Action Judge 能力**：AEWM 达 **70.5% macro-F1**，超最强基线 DeepSeek-V4-Pro（59.9%）**10.6 个点**；三域分别提升 10.3/10.5/13.4 点，SWE 增益最大，Search 最难。
- **EditAct 提升任务性能**：在全部 6 个 benchmark、3 个骨干上均优于 ReAct 与两种 Best@3，平均提升 **3.2–6.7 点**；相较 ReAct 提升 13.3/9.6/6.6 点；Qwen3.5-9B+EditAct 可超过 Qwen3.5-35B-A3B+ReAct。
- **可迁移性**：AEWM-RFT 在无在线 AEWM 指导时，较 Self-RFT 提升 **2.2–2.6 点**，并在 BrowseComp/Terminal 上分别减少 30.0%/16.7% 平均轮数，说明编辑轨迹提供了可迁移的监督信号。
- **消融结论**：学习到的干预选择优于随机门控；直接编辑优于重采样/提示引导；联合修订推理与动作优于单组件修订；专门训练的 AEWM 优于 Self-WM 与通用强模型。
- **行为分析**：Search 域 Noisy 占比最高（60.0%），Terminal 域 Exploratory 最高（43.2%）；AEWM 修复任务状态污染体现在：Search 中重新打开过早结论、Terminal 中纠正执行状态误判、SWE 中恢复被遗忘的兼容性/不变量约束。

## 7. 优点

- **问题重构有洞见**：将世界模型的目标从"重建环境观测"转为"建模决策效果并编辑智能体状态"，直面长时程智能体的核心痛点（任务状态污染），而非泛泛提升模拟精度。
- **方法闭环完整**：Action Judge（判断）+ State Revision（修订）+ EditAct（执行集成）+ AEWM-RFT（能力内化），从训练数据合成到推理干预再到知识蒸馏形成完整链条。
- **跨域统一**：单一模型覆盖 Search/Terminal/SWE 三种工具与交互模式差异极大的领域，且证明跨域决策判断的鲁棒性。
- **数据与评测严谨**：三重标注一致性 + 模型审核 + 多样性采样；SFT 采用 0–4 分严格 rubric（各维度 ≥3 才保留）；对未来信息泄漏做专门过滤。
- **可迁移性强**：AEWM-RFT 在推理时不需要在线世界模型，具备实际部署价值；且能缩小不同规模智能体之间的性能差距。
- **案例研究细致**：9 个跨域案例清晰展示"污染假设 → 编辑 → 真实反馈 → 后续修复"的因果链条。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号/数量、训练时长、总能耗，复现成本与可行性不透明。
- **数据依赖强**：训练与评测数据高度依赖 DeepSeek-V4-Pro、GLM-5、GPT-5.6-Sol 等特定强模型进行标注/审核/验证，存在**标注模型偏差**与**成本/可复现性**风险；自建 Action Judge 基准的"金标签"本质来自模型共识，而非人类标注。
- **能力上限受骨干约束**：论文自承 Qwen3.5-Plus 上 Terminal/SWE 增益有限，因 AEWM 与更强智能体之间存在**容量差**；世界模型弱于智能体时收益受限。
- **Search 域仍困难**：Noisy 占比高达 60%，AEWM 在 Search 上 macro-F1 仅 60.9%，为三域最低，说明该域决策判断仍具挑战。
- **部分结果增益较小**：如 NL2Repo 仅 +2.9、SWE-Bench Pro 仅 +3.2，Doc2Repo 的 AEWM-RFT 平均轮数反而上升（78.1→89.8），提示某些场景下收益与效率之间存在权衡。
- **评测覆盖**：部分 benchmark 为 OOD，但仅 6 个 benchmark、以英文/代码/终端为主，对多语言、多模态、真实开放网络动态等场景覆盖有限；RFT 的领域智能体是分域单独微调，未验证联合训练下的表现。
- **潜在偏差**：轨迹过滤只保留成功样本（SWE 分数 >0.6/>0.8），可能引入幸存者偏差；Action Judge 的"下游贡献"标注基于单条已实现轨迹，论文也承认不代表该动作在所有可能未来中的价值。
