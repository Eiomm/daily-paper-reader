## 摘要
潜在动作模型（LAMs）通过从视觉转移中推断潜在动作并重建未来状态，从无标注视频中学习动作表示。然而，我们发现了一个根本性的重建-动作失配：更低的重建误差未必带来更好的潜在动力学或下游性能。我们将这种失配归因于基于重建的潜在动力学建模中两个约束不足的方面：（i）逆动力学模型（IDM）未被明确鼓励区分与动作相关的转移和无关外观；（ii）前向动力学模型（FDM）可能利用来自当前状态的预测捷径，从而未能充分利用推断出的潜在动作。为解决这两个局限，我们提出 ACT-LAM，一个轻量级的以动作为中心的框架，同时增强动作提取和动作利用。具体而言，其动作查询 IDM（AQ-IDM）采用可学习的动作查询和门控聚合，以在没有强信息瓶颈的情况下选择性提取丰富的动作相关转移线索。其动作 Token FDM（AT-FDM）将潜在动作投影为动作 token，这些 token 与不断演变的状态表示逐步交互，从而实现连续的状态感知动作条件化。ACT-LAM 进一步简化特征处理，以将模型容量集中于潜在动力学建模。在多个机器人数据集和 VP$^2$ 基准上的大量实验表明，其具有更强的潜在动作一致性、前向动力学和下游视觉规划性能，同时可训练参数更少、计算开销更低。特别地，ACT-LAM 在聚合 VP$^2$ 成功率上超越此前的最优方法 7.6%。代码见 https://github.com/DingjieFu/ACT-LAM。

## Abstract
Latent action models (LAMs) learn action representations from unlabeled videos by inferring latent actions from visual transitions and reconstructing future states. However, we identify a fundamental $\textbf{reconstruction-action mismatch}$: lower reconstruction error does not necessarily yield better latent dynamics or downstream performance. We attribute this mismatch to two underconstrained aspects of reconstruction-based latent dynamics modeling: (i) the inverse dynamics model (IDM) is not explicitly encouraged to distinguish action-related transitions from nuisance appearance, and (ii) the forward dynamics model (FDM) can underutilize the inferred latent action by exploiting predictive shortcuts from the current state. To address both limitations, we propose $\textbf{ACT-LAM}$, a lightweight action-centric framework that strengthens both action extraction and action utilization. Specifically, its Action Query IDM (AQ-IDM) employs learnable action queries and gated aggregation to selectively extract rich action-related transition cues without strong information bottlenecks. And its Action Token FDM (AT-FDM) projects latent actions into action tokens that progressively interact with evolving state representations, enabling continuous state-aware action conditioning. ACT-LAM further streamlines feature processing to concentrate model capacity on latent dynamics modeling. Extensive experiments on several robotic datasets and the VP$^2$ benchmark demonstrate stronger latent action consistency, forward dynamics, and downstream visual planning performance with fewer trainable parameters and lower computational overhead. In particular, ACT-LAM surpasses the previous state of the art by $\textbf{7.6%}$ on the aggregated VP$^2$ success rate. Codes at $\href{https://github.com/DingjieFu/ACT-LAM}{url}$.

# 论文总结：Reconstructing Is Not Acting: Action-Centric Latent Dynamics Modeling（重建不等于动作：以动作为中心的潜在动力学建模）

## 1. 核心问题与研究动机

- **背景**：潜在动作模型（Latent Action Models, LAM）旨在从无动作标注的视频中学习动作表示，为视觉-语言-动作（VLA）模型预训练提供可扩展监督。典型 LAM 由逆动力学模型（IDM）与前向动力学模型（FDM）组成：IDM 由相邻帧推断潜在动作，FDM 以当前状态与潜在动作为条件重建/预测未来状态。由于缺少真实动作标签，**重建**自然成为主要训练目标。
- **核心发现（重建-动作失配）**：作者通过系统分析指出，**更低的重建误差并不必然带来更好的潜在动作、前向动力学或下游视觉规划性能**。论文图 1 显示 PlainLAM 重建损失最低，但 ACT-LAM 的 grid/action 损失更低、下游成功率最高。
- **失配的两个根源（约束不足的自由度）**：
  - **IDM 侧（动作提取）**：重建目标无法唯一确定 IDM 应提取什么，无法区分“动作相关转移线索”与“无关外观”，导致潜在动作混入外观信息。
  - **FDM 侧（动作利用）**：重建对 FDM 依赖潜在动作的程度没有显式约束，FDM 可利用来自当前状态的**预测捷径**绕过潜在动作，重建准确但动作未被充分利用。
- **现有工作的不足**：IDM 侧多以强信息瓶颈（向量量化、显式正则、压缩为紧凑结构嵌入）间接诱导动作相关性，可能丢弃与外观纠缠的动作线索；FDM 侧关注较少，动作条件多为固定形式（相加、拼接、交叉注意力、AdaLN-zero），在状态演化过程中缺乏状态感知交互。

## 2. 方法论：ACT-LAM

- **核心思想**：以动作为中心，同时强化**动作提取**（AQ-IDM）与**动作利用**（AT-FDM），并在潜在空间建模（冻结 DINOv2 编码器 + ViT-XL RAE 解码器），简化特征处理路径，把容量集中在动力学建模上。
- **问题形式化**：给定帧对 $(x_t, x_{t+1})$，编码得 $(f_t, f_{t+1})$，动力学适配器 $A$ 得状态 $s_t$。IDM 推断 $z_t = I_\phi(s_t, s_{t+1})$；FDM 预测残差 $\hat{s}_{t+1} = s_t + F_\theta(s_t, z_t)$，再映射回视觉特征做重建。
- **AQ-IDM（动作查询逆动力学模型）**：
  - 定义空间转移 $\Delta s_t = s_{t+1} - s_t$，轻量转移编码器映射为 patch token $E_t$，加入可学习位置嵌入。
  - 引入 $M$ 个可学习动作查询 $Q$，执行 **action-to-patch 注意力**（而非全局自注意力）：$A_t = \mathrm{Softmax}((QW_q)(E_tW_k)^\top/\sqrt{d_k})$，$H_t = A_t(E_tW_v)$。
  - 经 query mixer 与 temporal mixer 后，用**门控聚合**生成潜在动作：$\alpha_t=\mathrm{Softmax}(g(\tilde H_t))$，$C_t=f_{query}(\tilde H_t)$，$z_t=f_{action}(\alpha_t^\top C_t)$。
  - 不使用向量量化或显式容量正则；注意力图规模由 $(2N+1+M)^2$ 降为 $MN$，更省算力。
- **AT-FDM（动作 Token 前向动力学模型）**：
  - 初始化 $s_t^0=s_t$，$a_t^0=f_{proj}(z_t)$（动作 token）。
  - 堆叠 $L$ 个 Action Conditioning Block：先对 $[s_t^l, a_t^l]$ 做联合自注意力；再由动作 token 生成调制参数 $\gamma_t^l,\beta_t^l=h(\tilde a_t^l)$，按 FiLM 方式调制状态：$s_t^{l+1}=\tilde s_t^l+\sigma(g^l)[\gamma_t^l\odot \mathrm{LN}(\tilde s_t^l)+\beta_t^l]+\mathrm{FFN}_s(\tilde s_t^l)$，同时更新 $a_t^{l+1}=\tilde a_t^l+\mathrm{FFN}_a(\tilde a_t^l)$。
  - 最终投影得状态残差 $\Delta\hat s_t$，实现**动作 token 与状态表示的协同演化与持续状态感知条件化**。
- **轻量化设计**：移除 ST-Transformer，用 AQ-IDM 替换 DeepConv IDM，采用 AT-FDM；可训练参数约 55M（DiLA 为 123M）。
- **训练目标**（教师强制范式）：$L_{rec}$（特征重建）、$L_{grid}$（前向状态预测，SmoothL1）、$L_{act}$（真实转移与预测转移的潜在动作一致性）、$L_{sym}$（前向/反向对称）、$L_{var}$（潜在动作多样性）；总损失为加权和，系数 $\lambda_r=2.0,\lambda_g=0.05,\lambda_a=0.05,\lambda_v=0.01,\lambda_s=0.001$。

## 6. 主要结论与发现

- **重建质量不是潜在动力学或视觉规划性能的可靠指标**；“重建 ≠ 动作”在受控模型与多指标下得到验证。
- AQ-IDM 学到的潜在动作**与机器人动作线性对齐更好**（Block Pushing 0.031、Push-T 0.007 的最低探测 MSE）、**谱衰减更慢**（多样性/有效维度更高）、UMAP 中按真实方向形成清晰聚类、注意力集中于动作相关区域。
- AT-FDM 的动作利用度随 rollout 时域显著提升（如 SSv2 @15 达 41.7%，远高于 AdaLN-FDM 的 14.2%），4 数据集平均 @15 为 46.3%。
- **下游规划**：VP² 聚合成功率 49.04%，较前 SOTA 提升 **7.6%**；在 Push Blue Button（+11.5%）与 Push Green Button（+29.2%）上提升显著。
- **效率**：相比 DiLA 减少 2.49× GFLOPs、吞吐提升 4.36×、峰值显存降低 3.47×，可训练参数 55M（约为 DiLA 的一半）。

## 7. 优点

- **问题识别有洞察力**：明确指出并实证“重建-动作失配”，并给出两个可操作的失配来源（提取不足、利用不足），而非仅报告性能提升。
- **设计对称互补**：AQ-IDM 与 AT-FDM 分别对应“提取”和“利用”，消融显示两者提供互补增益。
- **用聚合替代瓶颈**：以可学习查询的选择性读出代替强信息压缩，避免丢弃与外观纠缠的动作线索。
- **状态感知的持续条件化**：AT-FDM 让动作 token 与状态共同演化，突破了固定动作条件的局限。
- **高效轻量**：在性能提升的同时显著降低参数、算力与显存，具有实际部署价值。
- **实验透明度较好**：诚实报告了在长时域重建、SSIM 等指标上不及 DiLA，且明确说明对比中的 checkpoint 差异。

## 8. 不足与局限

- **重建保真度受限**：像素级重建质量（尤其长时自回归 rollout）弱于 DiLA；长时域 rollout MSE 与 SSIM 上 DiLA 更优。
- **评估覆盖有限**：仅在当前数据集与 VP² 上验证，未覆盖需要高精度视觉预测或细粒度控制的场景；作者自述失配现象的普适性仍需更广泛验证。
- **消融统计强度不足**：VP² 消融仅单一随机种子；部分结果（如视频生成）指标间相互矛盾，结论需谨慎解读。
- **对比公平性的细微问题**：DiLA 使用 rollout 微调 checkpoint 而 ACT-LAM 未微调，虽对基线有利，但也意味着两者在长时域上的差距可能被低估或高估，缺乏同条件的长时域对比。
- **应用限制**：方法依赖冻结的强视觉编码器与 RAE 解码器，仍受限于其表征与重建能力；对更高精度控制任务的迁移能力未知。
