## 摘要
大语言模型（LLM）智能体日益依赖外部记忆来支持长时程推理与决策。现有记忆系统通常将历史轨迹或摘要作为独立的上下文片段进行检索，忽视了多步执行背后的过程依赖关系。随着记忆规模扩大，这种扁平化检索会引入上下文碎片化和跨任务干扰，导致推理轨迹在结构上不一致。我们提出 ActiveMem，一种分层记忆框架，它以递归方式将智能体经验组织为依赖感知的潜在执行树。ActiveMem 将轨迹抽象为可复用的子任务节点，同时显式保留执行转移，从而能够以当前执行状态为条件检索连贯的推理路径。为支持持续适应，ActiveMem 进一步通过强化学习学习动态的记忆扩展、检索与剪枝策略。在多种智能体基准上的实验表明，与现有基于记忆的智能体相比，ActiveMem 持续提升了任务完成度、推理稳定性和记忆效率。此外，ActiveMem 使紧凑的开源权重模型能够取得与规模大得多的专有系统相竞争的性能。

## Abstract
Large Language Model (LLM) agents increasingly rely on external memory to support long-horizon reasoning and decision making. Existing memory systems typically retrieve historical trajectories or summaries as independent context fragments, overlooking the procedural dependencies underlying multi-step execution. As memory scales, such flat retrieval introduces context fragmentation and cross-task interference, leading to structurally inconsistent reasoning trajectories. We propose ActiveMem, a hierarchical memory framework that recursively organizes agent experiences into dependency-aware latent execution trees. ActiveMem abstracts trajectories into reusable subtask nodes while explicitly preserving execution transitions, enabling coherent reasoning-path retrieval conditioned on the current execution state. To support continual adaptation, ActiveMem further learns dynamic memory expansion, retrieval, and pruning policies through reinforcement learning. Experiments across various agent benchmarks demonstrate that ActiveMem consistently improves task completion, reasoning stability, and memory efficiency over existing memory-based agents. Moreover, ActiveMem enables compact open-weight models to achieve competitive performance with substantially larger proprietary systems.

### 2. 方法论
#### 2.1 核心思想
- 提出 **ActiveMem**：将智能体经验递归组织为 **Hierarchical Latent Memory Tree（HLMT，分层潜在记忆树）**。
- 树节点表示可复用的子任务级潜在抽象，边表示执行依赖/时序转移。
- 检索时不是取孤立历史片段，而是取与当前执行状态一致的**依赖连贯推理路径**。
- 记忆不是被动追加，而是通过强化学习学习**扩展、检索、压缩、剪枝**策略。

#### 2.2 HLMT 结构与检索
- 节点定义为 \(n_i=(e_i, pa(i), ch(i))\)：\(e_i\) 为压缩潜在摘要，\(pa(i)\) 为父节点，\(ch(i)\) 为子节点集合。
- 初始仅有虚拟根节点，不编码任务语义，回合结束后重置。
- 以当前状态隐藏表示 \(h_t\) 为查询，从根开始递归贪心遍历：
  - 在当前子节点中选择与 \(h_t\) 余弦相似度最大的节点；
  - 当最大相似度低于阈值 \(\tau_{stop}\) 时停止；
  - 得到激活路径 \(P_t\)，表示当前执行阶段对应的历史分支。

#### 2.3 双头记忆控制器
- 对检索路径做均值池化，得到路径表示 \(\bar p_t\)。
- 共享表示 \(u_t = \mathrm{MLP}_{shared}([h_t;\bar p_t])\)，由轻量控制器 \(W_\phi\) 处理。
- **Latent Injection Head**：
  - 生成连续潜在前缀 \(m_t=W_{latent}u_t\)；
  - 将 \(m_t\) 作为动态 soft prompt，注入冻结 LLM 的输入嵌入或注意力 KV 缓存；
  - 不直接改文本上下文，而是通过隐藏状态调制推理。
- **Tree Action Head**：
  - 输出离散拓扑动作分布 \(\mathrm{Softmax}(W_{tree}u_t)\)；
  - 采样动作决定记忆树的插入、更新、合并、删除等操作。

#### 2.4 记忆更新与维护
- **即时执行**：
  - `insert`：新节点 \(e_{new}=W_{ins}u_t\) 挂到检索叶节点下；
  - `update`：用门控 \(\alpha=\sigma(W_{gate}u_t)\) 更新叶节点表示；
  - 新插入/更新嵌入做 L2 归一化，防止表示崩塌。
- **延迟维护**：
  - 回合结束后根据环境回报计算节点效用 \(S(n_i)=\sum_k \gamma^{k-t_i}r_k\)；
  - 用 EMA 平滑效用，低于 \(\tau_{del}\) 的节点剪枝，并将其子节点重连父节点；
  - 兄弟节点相似度高于 \(\tau_{merge}\) 时融合。
- **异步提交**：在线 rollout 时缓存拓扑操作，回合结束后异步提交，避免解码中并发修改导致检索不一致。

#### 2.5 训练目标
- 冻结 LLM 主干 \(\pi_\theta\)，仅优化控制器参数 \(\phi\)。
- 使用 **GRPO**，避免维护 critic 模型。
- 结合可验证过程监督与最终回报，构造层级优势：
  - 全局优势：节点效用相对同组 rollout 的归一化表现；
  - 局部优势：节点相对父节点的改进；
  - 深度折扣进一步稳定长时程优化。
- 联合优化：
  - 潜在注入头的 GRPO 目标；
  - 树动作头的 GRPO 目标；
  - 加入 KL 惩罚防止策略崩塌。
- 理论上给出：
  - 树检索复杂度约 \(O(DB)\)，近似 \(O(\log_B |T|)\)，优于扁平检索 \(O(|T|)\)；
  - 树规模在剪枝/合并下可保持有界；
  - 冻结 LLM、只在记忆树深度上优化可带来二次方差降低。
