## 摘要
近年来，大型语言模型（LLM）的进展使智能体能够在多样环境中处理长时程任务。为了进一步提升智能体性能，现有语言世界模型通常预测环境观测，但当真实反馈可用时，重建高熵且依赖执行的工具响应价值有限。与此同时，智能体受到任务状态污染的困扰：无依据的假设和过时的计划滞留在历史中，并扭曲后续决策。我们提出智能体编辑世界模型（Agent-Editing World Model, AEWM），其建模推理与动作如何塑造未来任务进展，而非模拟工具响应。AEWM 将 Action Judge 与 State Revision 相结合：前者区分 Critical、Exploratory 和 Noisy 决策，后者从同一观测历史中编辑含噪的推理—动作延续。EditAct 将这些能力与真实执行集成，直接改变后续决策所基于的状态，而不仅仅是提供批评。我们通过中期训练和监督微调，在 Search、Terminal 和 Software Engineering 领域训练 AEWM。AEWM 在我们的 Action Judge 基准上达到 70.5% macro-F1，超过最强前沿基线 10.6 个点。在六个基准和三个智能体骨干上，EditAct 将平均分数较最强基线提升 3.2--6.7 个点。此外，对已验证的 EditAct 轨迹进行拒绝采样微调（称为 AEWM-RFT），在没有在线 AEWM 指导的情况下，在三个领域上较 Self-RFT 提升 2.2--2.6 个点。

## Abstract
Recent advances in large language models (LLMs) have enabled agents to tackle long-horizon tasks across diverse environments. To further improve agent performance, existing language world models typically predict environment observations, yet reconstructing high-entropy, execution-dependent tool responses offers limited value when real feedback is available. Meanwhile, agents suffer from \emph{task-state contamination}, where unsupported assumptions and outdated plans persist in history and distort subsequent decisions. We propose the \textbf{Agent-Editing World Model (AEWM)}, which models how reasoning and actions shape future task progress rather than simulating tool responses. AEWM combines \textbf{Action Judge} to distinguish \textsc{Critical}, \textsc{Exploratory}, and \textsc{Noisy} decisions with \textbf{State Revision} to edit noisy reasoning--action continuations from the same observed history. \textbf{EditAct} integrates these capabilities with real execution, directly changing the state underlying subsequent decisions rather than merely providing critiques. We train AEWM across Search, Terminal, and Software Engineering through mid-training and supervised fine-tuning. AEWM achieves 70.5\% macro-F1 on our Action Judge benchmark, exceeding the strongest frontier baseline by 10.6 points. Across six benchmarks and three agent backbones, EditAct improves average scores by 3.2--6.7 points over the strongest baseline. Furthermore, rejection sampling fine-tuning on verified EditAct trajectories, termed \textbf{AEWM-RFT}, improves over Self-RFT by 2.2--2.6 points across three domains without online AEWM guidance.

# Agent-Editing World Model（AEWM）论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：LLM 智能体已能处理跨环境的长时间跨度任务，世界模型被普遍视为实现通用智能的基础，用于理解环境结构与动态。
- **现有范式的局限**：现有语言世界模型大多沿用"预测环境观测/工具响应"的目标（记作 \(M_{obs}\)），但在真实工具可提供反馈时，重建高熵、依赖执行的观测（如搜索结果、终端输出、测试结果）难度大且价值有限，甚至可能引入伪造证据。
- **核心问题**：面向长时程任务的语言世界模型究竟应该预测什么？
- **关键发现——任务状态污染（task-state contamination）**：智能体在部分可观测环境中探索时，会把无依据的假设当作事实、在矛盾反馈下保留过期计划、把部分进展误认为完成。这些错误滞留在历史中并通过"局部看似合理"的动作不断累积，扭曲后续决策。
- **核心主张**：真正值得建模的是"推理与动作如何塑造后续任务进展"，而非模拟工具响应；应当在动作执行前直接**编辑智能体状态**，从根源上阻断污染传播。

## 2. 方法论：核心思想与关键技术

### 2.1 核心思想
将语言世界模型从"观测预测"重构为"**智能体状态编辑**"。给定前执行状态 \(s_t = h_t \oplus (\hat{r}_t, \hat{a}_t)\)（任务、历史、候选推理—动作对），AEWM 不预测观测 \(\hat{o}_t\)，而是直接干预状态：

- 传统 WM：\(s_t \xrightarrow{M_{obs}} \hat{o}_t\)
- AEWM：\(s_t \xrightarrow{M_{SR}} \tilde{s}_t = h_t \oplus (\tilde{r}_t, \tilde{a}_t)\)

后续观测仍通过真实环境执行获得，从而避免模拟误差。

### 2.2 两大核心能力
- **Action Judge（\(M_{AJ}\)）**：在执行前预测候选决策的效应标签，分三类：
  - **Critical**：闭合关键缺口、获取必要证据、完成必需状态变更，属于紧凑解路径。
  - **Exploratory**：有意义地降低不确定性或检验合理分支（显式保留探索类，避免只奖励最短路径）。
  - **Noisy**：预期无进展，或导致重复、无关、违反约束、错误方向。
- **State Revision（\(M_{SR}\)）**：仅对 Noisy 提案生成编辑后的推理与动作 \((\tilde{r}_t, \tilde{a}_t)\)，可调和冲突信息、修正无依据假设、更新计划；编辑同时改变"下一步动作"和"带入未来历史的推理"。

### 2.3 EditAct：编辑与执行的集成
每步推理—动作对提交规则：

\[
(r_t, a_t) = \begin{cases} (\hat{r}_t, \hat{a}_t), & \hat{y}_t \in \{\text{critical}, \text{exploratory}\} \\ (\tilde{r}_t, \tilde{a}_t), & \hat{y}_t = \text{noisy} \end{cases}
\]

随后在真实环境 \(\mathcal{E}\) 中执行 \(a_t\)，更新历史 \(h_{t+1} = h_t \oplus (r_t, a_t, o_t)\)。关键区别在于：不是给智能体"批评/提示"让它重新生成，而是**直接替换状态**。

### 2.4 数据合成与两阶段训练
- **Action Judge 数据**：将成功轨迹分解为逐轮样本，由强标注智能体基于完整轨迹、对应观测及后续作用做**轮级标注**，输出仅含前缀可见信息的"前瞻式推理 + 标签"。过滤条件包括标签一致性、动作—观测对齐、动作有效性、无未来信息泄漏。
- **State Revision 数据**：提案智能体尝试任务 → AJ 检查点判定 Noisy → 修订智能体从同一历史生成新对 → **在真实环境执行** → 仅保留带来实质进展的样本。
- **两阶段训练**（骨干 Qwen3.5-35B-A3B，verl + Megatron）：
  - **Mid-training**：约 52B tokens（AJ 20.56B + SR 25.01B + 原始轨迹 6.59B），覆盖 Search / Terminal / SWE。
  - **SFT**：120K 高质量样本（60K AJ + 60K SR，三域各 40K）。Search 域 AJ 刻意采用 1:1:3 的 C/E/N 混合。

### 2.5 AEWM-RFT：能力内化
用 EditAct 产生的、经真实反馈验证的高质量轨迹做拒绝采样微调，把 AEWM 的纠错模式迁移进智能体本身。与 Self-RFT 的唯一差别是 rollout 来源，其余过滤策略与训练配置完全一致，保证受控对比。
