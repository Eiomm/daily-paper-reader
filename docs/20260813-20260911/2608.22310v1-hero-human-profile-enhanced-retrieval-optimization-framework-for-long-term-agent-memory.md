## 摘要
长期记忆对于个性化响应和长时程智能体交互至关重要。现有方法通常依赖大语言模型（LLMs）压缩或重写对话历史，并将转换后的记忆用作检索证据。尽管在组织碎片化上下文方面取得了进展，但仍存在两个主要缺陷：（1）压缩导致的信息损失，会丢弃细粒度但后续有用的细节；（2）重写导致的语义漂移，会侵蚀原始语气和情境化上下文。在这项工作中，我们提出了一种新颖的面向长期智能体记忆的用户画像增强检索优化框架（HERO）。具体而言，HERO 将对话历史转换为可追溯的异构记忆图，保留原始对话文本作为推理证据，从而缓解信息损失。在检索时，HERO 从当前查询中提取初始锚点，并通过迭代图遍历融入用户画像；这些锚点和画像提供引导信号，自适应地激活图中信息量最丰富的区域。在两个基准数据集上的实验表明，HERO 在事实推理和个性化推理上均优于强基线，同时能够更忠实地访问原始对话证据。

## Abstract
Long-term memory is crucial for personalized responses and long-horizon agent interactions. Existing methods often rely on LLMs to compress or rewrite dialogue histories and use the transformed memories as retrieval evidence. Despite the progress in organizing fragmented contexts, two major drawbacks persist: (1) information loss from compression, which discards fine-grained but later useful details, and (2) semantic drift from rewriting, which erodes the original tone and situated context. In this work, we propose a novel Human-profile Enhanced Retrieval Optimization framework for long-term agent memory (HERO). Specifically, HERO converts the dialogue history into a traceable heterogeneous memory graph that preserves raw dialogue text as evidence for reasoning, thereby mitigating information loss. For retrieval, HERO extracts initial anchors from the current query and incorporates human profiles via an iterative graph traversal; these anchors and profiles provide guidance signals that adaptively activate the most informative regions of the graph. Experiments on two benchmark datasets show that HERO outperforms strong baselines on both factual and personalized reasoning, while providing more faithful access to raw dialogue evidence.

## 1. 核心问题与研究动机

- **背景**：长期记忆是个性化响应与长时程智能体交互的核心能力。当前主流做法是基于 RAG 检索历史上下文或外部知识，但检索到的孤立文本片段缺乏结构化关联，冗余高、相关性弱，本质上是"外部知识库的静态访问"，而非类人的动态记忆系统。
- **两条既有技术路线及其缺陷**：
  - **摘要式方法**（MemoryBank、LightMem、EverMemOS、Mem0、CAM 等）：用 LLM 将对话精炼为分层摘要、结构化事实或用户画像。
  - **图式方法**（RAPTOR、HippoRAG、GraphRAG、A-Mem、Zep 等）：抽取实体/关键词或文本块摘要，用关系边表达时序、因果或语义关联。
- **两个核心痛点**（论文的核心批判）：
  1. **压缩导致信息损失**：写入时看似不重要的细节（时间指代、因果条件、数值事实、细微偏好变化）被丢弃，后续却可能关键。
  2. **重写导致语义漂移**：即使主要事实保留，用户原始措辞、情感、说话人归属与情境上下文也会被削弱。
- **深层原因**：两类方法都高度依赖 LLM 的叙事与摘要能力；关系抽取不准会引入图拓扑噪声，错误的 LLM 摘要会在层级聚类中把幻觉从底层表征传播到高层抽象。
- **研究目标**：构建一种受人类认知启发的长期记忆机制——既能快速定位相关概念（属性、偏好等），又能激活相关情景记忆片段，同时保证事实忠实的推理与个性化生成。

## 2. 方法论：HERO 框架

### 2.1 核心思想

- **认知启发原则**：**原始对话痕迹作为情景证据被完整保留**，高层画像信息**仅用于引导记忆激活**，而非替代记忆本身。
- **形式化目标**：给定会话历史 H={s₁,…,s_T}、潜在用户画像 P、当前查询 q，目标是检索最优记忆子集 M*⊂H 以最大化生成目标响应 r 的概率：
  - `M* = argmax_{M⊂H} P(r | q, M, P; Φ_LLM)`
- 框架由**记忆构建**与**记忆检索**两大部分组成。

### 2.2 记忆构建：以情景为中心的异构记忆图 G=(V,E)

- **情景层（Episodic Layer）**——忠实记录原始对话，含三类节点：
  - **情景痕迹（Episodic Traces, Vₜ）**：语义连贯的会话或时间窗，保留完整原文、时间戳与顺序索引。
  - **情景单元（Episodic Units, Vᵤ）**：进一步切分的原子句级单元，是证据的基本载体，保留细粒度上下文约束。
  - **情景线索（Episodic Cues, V_c_epi）**：由 LLM 从单元中抽取的实体与关键词，作为联想桥梁；跨单元实体归一化合并为全局共享线索节点。
- **画像层（Profile Layer）**——高层语义抽象，含两类节点：
  - **画像洞察（Profile Insights, V_p）**：针对每条情景痕迹，由 LLM 蒸馏出 Facts（事实）、Insights（情境状态/情绪）、Traits（稳定特质与偏好）。
  - **画像线索（Profile Cues, V_c_pro）**：从画像洞察中抽取的细粒度实体，把抽象用户画像链接回全局语义空间。
  - 全局线索集 `V_c = V_c_epi ∪ V_c_pro`，节点全集 `V = Vₜ ∪ Vᵤ ∪ V_p ∪ V_c`。
- **三类边**：
  - **结构包含**：`(vᵤ,vₜ)`、`(v_p,vₜ)` 指向来源痕迹；`(v_c,vₜ)`、`(v_c,v_p)` 连接线索到其来源。
  - **语义索引**：`(v_c,vₜ)`、`(v_c,v_p)` 的加权边，权重 w 基于共现频率。
  - **时序链**：相邻情景痕迹 `(v_{t_i}, v_{t_{i+1}})` 保持时间顺序。
- **三点收益**：情景层支持原始证据的忠实检索与跨会话多跳、可变分辨率检索；画像层提供隐式链接以召回无关键词重叠的画像一致证据；支持**增量更新**（新对话只新建局部节点与边，无需全图重建）。

### 2.3 记忆检索：画像增强的三阶段流程

- **两类查询对应两种激活路径**：事实型问题激活查询相关线索以定位完整原始证据；个性化推理问题激活画像相关线索（目标属性可能并不以显式实体出现于对话中）。
- **Phase 1 初始锚点识别**：从查询 q 抽取显式实体集 E_q，与线索节点 V_c 做嵌入余弦相似度匹配，超过阈值 τ_init 者构成初始激活集 S₀。
- **Phase 2 迭代上下文扩展**（模拟人类"顺藤摸瓜"式回忆，共 K 轮）：
  - 先在 S_{k-1} 内扩展同义线索节点得 S′_{k-1}（阈值 τ_alias 约束语义漂移）；
  - 收集与当前线索相连的上下文节点 `N_k = ∪ Adj(v) ∩ (Vᵤ ∪ V_p)`；
  - 用查询相关性过滤得 `N*_k`（阈值 τ_iter）；
  - 由 N*_k 激活新线索生成 S_k（排除历史已激活节点）；
  - 新线索的激活权重按 `W(c)_k = W(c′)_{k-1} × sim(Φ(n), Φ(q))` 从上一轮线索经中间上下文传递。
- **Phase 3 全局相关性传播与证据排序**：
  - 情景痕迹的激活强度 = 稠密检索相关性 + 线索匹配加成：`W(vₜ) = α·sim(Φ(vₜ),Φ(q)) + log(1 + Σ_{c∈S_all} W(c)·ln(1+f(c,vₜ))/L_c)`，其中 f 为线索在痕迹中的出现频次，L_c 为线索层级深度。
  - 由 `{W(v) | v ∈ V_c ∪ Vₜ}` 构造重启概率向量 r，**画像洞察节点 v_p 在传播中被掩蔽**（排除在 r 之外）。
  - 在图上执行 **Personalized PageRank**：`a = (1−d)·r + d·a·P_mask`，P_mask 为掩蔽画像节点及其关联边后的行归一化转移矩阵，保证能量只在承载证据的节点间流动。
  - 按 PPR 得分对情景痕迹排序，经重排序模型返回 top-k 作为 LLM 的推理证据。

## 6. 主要结论与发现

- **RQ1（事实检索的准确性与忠实度）**：HERO 在 LoCoMo 上取得最佳整体表现——**87.99% ACC、56.06% F1、48.38% BLEU-1**，全面领先所有基线；检索质量 Overall R@10 = **0.938**、R@5 = 0.910，说明图检索器多数情况下能定位到相关原始证据。开放域问题召回较低（R@10 = 0.667）属预期，因其需要对话历史之外的常识。
- **RQ2（跨会话推理）**：多跳任务准确率达 **85.11%**；案例显示 HERO 能通过实体线索把时间上相距甚远的两段会话（2023-02-25 的"同事 Rob 邀请上瑜伽课"与 2023-04-07 的"和同事开始周末瑜伽课"）桥接起来，实现长程依赖恢复。
- **RQ3（动态画像与偏好演化）**：PERSONAMEM 整体准确率 **70.63%**，优于所有基线；在偏好对齐推荐（80.00%）、偏好更新原因回溯（87.88%）、完整偏好演化追踪（72.66%）上优势明显。消融显示移除画像层使 PERSONAMEM 准确率从 65.70% 降至 63.67%，证明画像提供查询匹配之外的互补信号。
- **RQ4（效率）**：HERO 在取得最高 F1 的同时平均仅消耗 **248 tokens**、延迟**低于 1 秒**。原因在于重量级语义链接与结构构建被前移到记忆构建与画像维护阶段，检索时只做轻量线索抽取与图遍历，避免在线长链 LLM 推理。
- **稳定性**：τ_alias、τ_init/τ_iter、top-k 在合理范围内变动时，LoCoMo 准确率稳定在 0.801–0.829、F1 在 0.546–0.560，说明方法不依赖精细阈值
