## 摘要
长期语言模型智能体在交互中不断积累记忆，但它们的检索器通常不会积累检索经验。语义检索高效，但嵌入相似度并不总能反映某条记忆是否包含与当前查询相关的证据。大型语言模型（LLM）重排序器能提供更强的查询条件化相关性分数，然而无状态重排序会反复对大规模候选池打分，并在每次查询后丢弃这些分数。我们提出 EARM，一种经验摊销式重排序框架，将先前获得的 LLM 相关性分数视为可复用的检索经验。EARM 将稀疏的查询–记忆相关性分数存储在在线矩阵中，通过因果矩阵补全学习其共享结构，并将少量新观测分数与估计分数相结合，以对其余候选进行重排序。随着经验积累，打分预算逐渐减少，使 LLM 重排序从每次查询重复产生的开销转变为智能体生命周期内习得的检索能力。在长期对话记忆上的实验表明，混合观测分数与估计分数的重排序相较语义检索最多可将答案准确率提升 6.62%，并且在仅 17.5% 的候选获得直接 LLM 相关性分数时仍保持有效，从而大幅降低 LLM 重排序的推理开销。这些结果促使我们以更广阔的视角看待智能体记忆：一个长期存续的智能体不仅应记住过去的内容，还应记住这些内容如何被证明对检索有用。

## Abstract
Long-term language-model agents accumulate memories across interactions, but their retrievers typically do not accumulate retrieval experience. Semantic retrieval is efficient, but embedding similarity does not always reflect whether a memory contains evidence relevant to the current query. Large language model (LLM) rerankers provide stronger query-conditioned relevance scores, yet stateless reranking repeatedly scores a large candidate pool and discards these scores after each query. We introduce EARM, an experience-amortized reranking framework that treats previously acquired LLM relevance scores as reusable retrieval experience. EARM stores sparse query--memory relevance scores in an online matrix, learns their shared structure through causal matrix completion, and combines a small set of newly observed scores with estimated scores to rerank the remaining candidates. The scoring budget decreases as experience accumulates, changing LLM reranking from a repeated per-query expense into a retrieval capability learned over an agent's lifetime. Experiments on long-term conversational memory show that mixed observed-and-estimated reranking improves answer accuracy over semantic retrieval by up to 6.62% and remains effective when only 17.5% of candidates receive direct LLM relevance scores, thereby substantially reducing the inference overhead of LLM reranking. These results motivate a broader view of agent memory: a long-lived agent should remember not only past content, but also how that content has proved useful for retrieval.

## 1. 核心问题与整体含义

- **背景**：长期语言模型智能体需要外部记忆跨交互保存事件、偏好、任务轨迹等信息；但记忆库增长后，系统必须反复从大量记忆中检索当前查询所需证据。
- **核心矛盾**：记忆库会随交互积累，但检索器通常不积累经验。每次查询都从相同初始状态开始：语义检索召回候选，LLM 重排序器逐条打分，使用后丢弃分数；下次相关查询或相同记忆再出现时，检索器仍需重新打分。
- **问题本质**：语义嵌入相似度不等于查询条件化相关性。高相似记忆可能无证据价值，低相似记忆可能提供关键时间、因果或实体关系。LLM 重排序虽更强，但无状态、逐查询独立，成本随查询数和候选池规模增长，且重复浪费。
- **整体含义**：论文提出智能体记忆应包含第二类持久状态——**检索记忆（retrieval memory）**：不仅记住“过去发生了什么”，还记住“哪些记忆对哪些信息需求有用”。由此，LLM 重排序分数从一次性推理痕迹变为可复用的检索经验。

## 2. 方法论：EARM 框架

- **核心思想**：将历史 LLM 相关性分数视为可复用经验，存入在线查询–记忆矩阵；通过因果矩阵补全学习共享的低秩“记忆可访问性地图”；新查询只需少量锚点分数，即可估计其余候选的相关性并完成重排序。
- **整体流程**：
  1. **语义候选生成**：对每个查询用嵌入相似度返回 Top-N 候选，保持记忆身份稳定。
  2. **检索经验矩阵**：构造稀疏矩阵 \(R^{(t)}\)，行是稳定记忆身份，列是查询；已观测单元为 LLM 分数，未观测单元为待补全分数。
  3. **阶段式经验采集**：将查询流分为经验阶段，预算 \(B_t=\lfloor \rho_{\ell(t)}N \rfloor\)，且 \(\rho_1\ge\rho_2\ge\cdots>0\)，即随经验积累逐步降低直接打分比例。
  4. **锚点采样**：每个查询的候选池分为高相似层 \(H_t\) 和其余候选；预算一半从高相似层采样以利用，一半从其余候选采样以探索。
  5. **因果低秩补全**：用带偏置的低秩模型估计未观测分数：
     \[
     \hat R_{i\tau}=\mu+\alpha_i+\beta_\tau+p_i^\top z_\tau
     \]
     其中 \(\mu\) 为全局偏置，\(\alpha_i\) 为记忆偏置，\(\beta_\tau\) 为查询偏置，\(p_i^\top z_\tau\) 捕捉记忆–查询潜在交互。
  6. **优化方式**：在已观测集合 \(\Omega_t\) 上最小化掩码重建误差与 L2 正则，使用交替最小二乘（ALS），并从上一轮解热启动。因果掩码确保排序查询 \(q_t\) 时不能使用未来查询分数。
  7. **混合重排序**：若候选被直接打分则用 LLM 分数；否则用补全分数。按混合分数排序后取 Top-K 进入答案上下文，再将选中记忆恢复为时间顺序。
- **可选扩展**：补全模型还可对历史上有行参数、但当前语义候选集未召回的记忆打分，即 \(D_t=C_t\cup E_t\)，使语义检索从硬边界变为软边界。但实验主要在 \(D_t=C_t\) 内验证。
