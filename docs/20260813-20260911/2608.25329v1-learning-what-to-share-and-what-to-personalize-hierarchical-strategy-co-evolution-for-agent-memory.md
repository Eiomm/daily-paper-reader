## 摘要
记忆增强型智能体在长时对话中维护紧凑的用户画像，从而无需处理完整对话历史即可实现个性化且一致的响应。这些用户画像的质量依赖于底层的记忆管理策略：在每一步，智能体都必须决定保留、压缩或丢弃哪些内容。然而，现有方法通常采用在训练前设定的静态、一刀切策略。在实践中，最优记忆决策本质上因用户而异，并会随策略优化动态演化。为解决这一问题，我们提出 HiPS（Hierarchical Personalized Strategy，分层个性化策略），一个将记忆管理解耦为全局共享基础与用户特定自适应层的框架。具体而言，HiPS 采用 Universal Strategy 从跨人设轨迹中提取共享原则，并利用 Persona Delta Distillation 为行为偏离一般模式的用户生成定制规则。Cross-Level Rule Flow 通过提升被广泛验证的个人规则并降级与之矛盾的全局规则，动态校准二者边界。该架构建立了一个协同演化循环，其中一种机制保证所有策略改进都锚定于任务结果。大量实验表明，其相比记忆增强基线取得了持续提升。

## Abstract
Memory-augmented agents maintain compact user profiles throughout extended conversations, enabling personalized and consistent responses without the need to process the entire dialogue history. The quality of these user profiles relies on the underlying memory management strategy: at each step, the agent must determine what to retain, compress, or discard. However, existing methods typically employ a static, one-size-fits-all strategy established before training. In practice, the optimal memory decision is inherently user-specific and dynamically evolves alongside policy optimization. To address this, we propose \textbf{HiPS} (\textbf{Hi}erarchical \textbf{P}ersonalized \textbf{S}trategy), a framework that decouples memory management into a globally shared foundation and a user-specific adaptive tier. Specifically, HiPS employs \textbf{Universal Strategy} to extract shared principles from cross-persona trajectories, alongside \textbf{Persona Delta Distillation} to generate tailored rules for users whose behaviors diverge from general patterns. \textbf{Cross-Level Rule Flow} dynamically calibrates their boundary by promoting broadly validated personal rules and demoting contradicted global ones. The architecture establishes a co-evolution loop where a mechanism guarantees that all strategy refinements are anchored to task outcomes. Extensive experiments demonstrate consistent improvements over memory-augmented baselines.

- **整体含义**：论文将"策略个性化"形式化为一个可学习问题，提出 HiPS（Hierarchical Personalized Strategy），把记忆管理策略解耦为**全局共享层 Su** 与**用户自适应层 Δp**，并让二者的边界随训练证据迁移调整，与策略 πθ 形成持续协同演化闭环。

## 2. 方法论

### 2.1 核心形式化
- 策略分解：**Sp = Su ∪ Δp**，其中 Su 为全群体受益的通用规则，Δp 为用户 p 的个性化增量规则。
- 记忆更新：**mt = πθ(ct, mt−1; Sp)**，即规则以系统提示形式注入，调节每步的记忆动作；处理完 K 个对话块后基于终态 mK 回答查询 q。

### 2.2 通用策略蒸馏（USD）
- **对比式结构化差分**：每隔 K1 步，采样"人格均衡"的 top-k / bottom-k 轨迹（防止主导用户偏斜信号），由 LLM 元优化器比较后输出**离散操作集合**而非自由文本总结：**δUSD = {V:[·], H:[·], R:[·]}**，分别对应"验证已有规则 / 假设新规则 / 修订或退役规则"。
- 新假设必须遵守 **"[Label]: When [condition], [action]"** 格式，且必须规定明确的管理动作。
- **证据追踪**：每条规则带证据等级 **tentative → supported → established**；一致验证则升级，被修订/反驳则降级；连续 Tstale 个周期无验证的 tentative 规则被剪枝。同时用数据驱动的**预测增益 PG** 做兜底：PG > θval 自动提升，PG < θrev 自动降级。
- 与既有规则的词重叠 > 0.7 时，新假设被视为"验证"而非新规则，防止规则爆炸。

### 2.3 人格增量蒸馏（PDD）
- **预测增益定义**：**PG(r) = P(Y=1 | r+) − P(Y=1 | r−)**，即遵守与不遵守规则 r 的轨迹成功率之差，作为规则重要性的**相对排序代理**（不作绝对质量度量）。
- **发散门控**：用户发散度定义为 **Dp = Σ_{r∈Su} |PG(r|p) − PG(r)|**；仅当 **Dp ≥ θdiv** 才触发 PDD。低发散用户默认沿用 Su，从而缓解冷启动与算力浪费、避免对已被通用规则覆盖良好的用户引入噪声。
- **行为条件化蒸馏**：以 Su 为锚定上下文，要求生成与 Su **严格不同**的规则；约束为**管理导向（prescribe actions，而非陈述事实）**且**行为条件化（条件须引用可观测行为模式，而非用户身份或领域名）**，以保证对未见用户的泛化。

### 2.4 跨层规则流（Cross-Level Rule Flow）
- **泛化（Δp → Su）**：当某条 Δp 规则达到 supported 及以上、且出现在 ≥ θflow 比例（默认 0.6）的拥有 Δp 的用户中时，提升入 Su 并从各用户增量中剪除；规则匹配用语义相似度聚合，容忍句法差异。
- **特化（Su → Δp）**：当 USD 修订或降级某条 Su 规则时，此前受益于该规则的用户可能失去关键指导，因此由 PDD 生成人格特异的替代规则，把该管理行为"本地化恢复"，避免一刀切修订损害少数派。
- 二者构成循环：局部发现若广泛有效则被吸收为通用原则，通用规则若被子群体反驳则由定制规则替代。

### 2.5 策略注入与协同演化
- **子模选择（预算受限注入）**：在 token 预算 B 下贪心最大化覆盖目标 **max Σ_{r∈S} PG(r)·(1 − max_{s≠r} σ(r,s))**，其中 σ 为语义相似度（冗余惩罚）；预算按 Su 与 Δp 的聚合 PG 比例分配，每层设最小保底（0.2B）。
- **准则对齐奖励**：**Rfollow(τ,p) = Σ_{r∈Sp} PG(r)·h(τ,r) / Σ_{r∈Sp} PG(r)**，h∈[0,1] 为合规检查；最终 **R(τ,p) = Rans(τ) + λ·Rfollow(τ,p)**（λ=0.3），送入 GRPO。同一轨迹在不同用户的 Δp 下会得到不同合规分。
- **反自循环设计**：蒸馏缓冲区的排序**只用 Rans**，Rfollow **只用于 GRPO 优势计算**。这样切断了"合规 → 被选为策略更新证据 → 规则自我确认"的直接回路；Rfollow 通过影响策略再影响未来 Rans 的间接路径，在"合规确实提升任务成功率"时是良性的，否则不会得到奖励强化。
- **训练循环（Algorithm 1）**：每步构造 Sp → 注入 rollout → 计算 Rans/Rfollow → 仅用任务奖励更新缓冲区 → GRPO 更新 πθ → 每 K2 步做 PDD（含 PG 重算与自动升降级）→ 每 K1 步做 USD 与跨层迁移。
