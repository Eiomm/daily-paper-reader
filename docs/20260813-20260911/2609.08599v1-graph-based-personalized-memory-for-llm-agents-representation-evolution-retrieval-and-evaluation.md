## 摘要
大语言模型（LLM）智能体正从单会话工具演变为长期个人助理，必须跨任务、上下文和交互适应个体用户。这一转变使记忆成为个性化的核心需求，因为用户的偏好、目标、约束、关系以及过往经历会逐渐积累，并往往随时间变化。基于图的个性化记忆提供了一种结构化方式，通过显式关系、时间上下文和证据链接来建模此类用户信息。此类表示不仅能够建模智能体关于用户记住了什么，还能建模记忆之间如何连接、修订和检索，以支持个性化决策。然而，现有工作分散在个性化智能体与通用图记忆框架中，使得难以从整体上理解该设计空间。本综述提出了一种面向LLM智能体的基于图的个性化记忆的生命周期视角。我们围绕记忆表示、记忆演化、记忆检索和记忆评估来组织现有研究。我们进一步比较关键设计选择，讨论当前的评估实践，以及在构建可靠的长期个性化智能体方面的开放挑战。本综述旨在阐明基于图的记忆如何支持自适应、可控且以用户为中心的LLM智能体。

## Abstract
Large Language Model (LLM) agents are evolving from single-session tools toward long-term personal assistants that must adapt to individual users across tasks, contexts, and interactions. This shift makes memory a core requirement for personalization, since user preferences, goals, constraints, relationships, and past experiences are accumulated gradually and often change over time. Graph-based personalized memory provides a structured way to model such user information through explicit relations, temporal context, and evidence links. Such representations can model not only what an agent remembers about a user but also how memories are connected, revised, and retrieved to support personalized decisions. However, existing work remains fragmented across personalized agents and generic graph memory frameworks, making it difficult to understand the design space as a whole. This survey develops a lifecycle-oriented view of graph-based personalized memory for LLM agents. We organize existing studies around memory representation, memory evolution, memory retrieval, and memory evaluation. We further compare key design choices, discuss current evaluation practices, and open challenges in building reliable long-term personalized agents. This survey aims to clarify how graph-based memory can support adaptive, controllable, and user-centric LLM agents.

- **背景转变**：LLM 智能体正从"单会话工具"演变为"长期个人助理"（如 OpenClaw、Hermes），需要跨任务、跨上下文、跨交互地适应同一用户。
- **记忆成为个性化刚需**：用户偏好、目标、约束、关系与过往经历是逐步累积且持续变化的；即便上下文窗口不断增大，把全部交互历史塞进每次 prompt 仍不可行，因此需要**外部持久化记忆**。
- **早期方案的局限**：对话日志、段落级/压缩式自然语言摘要、向量库等方案虽能记录与召回单个事实，但把每条记忆视为自包含条目，难以刻画事实之间的关联、随时间的演化、以及事件间的因果/派生关系。

### 2.1 前置定义与边界

- **图基个性化记忆的定义**：包含用户特有状态（事实、偏好、目标、约束、关系、经验），跨会话持久、存储于模型参数之外、以显式图结构组织。
  - "记忆"属性 → 区别于瞬时的 prompt 上下文；
  - "个性化"属性 → 区别于跨用户共享的通用知识。
  - **排除标准**：单纯的通用图增强生成（GraphRAG）与通用智能体记忆，除非其支持用户建模。
- **个人记忆的五个维度**（表 I，非互斥，一条记忆可同时具备多种属性）：
  - 语义（Semantic）：稳定事实、偏好、目标、约束；
  - 时间（Temporal）：记忆何时成立、如何变化；
  - 关系（Relational）：与人、地点、任务、物品的链接；
  - 经验（Experiential）：过往事件、结果、习惯、例行程序；
  - 情感（Affective）：情绪效价与强度。

### 2.2 记忆表示（Representation）

- **元素层（Element Level）**：
  - **四类功能节点角色**（可在同一图中重叠）：证据节点（原始交互记录：轮次、情节、句子）、事实节点（抽取出的原子断言）、抽象节点（对重复观察的综合：画像、场景、反思）、领域特定节点（如兴趣、职业、医疗与患者作息）。
  - **四类关系功能**：时间关系（事件顺序/推进）、溯源关系（断言/抽象 → 源证据）、联想关系（语境或语义相关）、领域特定关系。
  - **生命周期元数据**：时间戳、有效期区间、失效标记，用于区分"当前有效用户状态"与"历史证据"。
  - **权衡**：证据丰富型保留源语境但存储开销大；事实/抽象中心型紧凑但会放大抽取错误；领域特定模式提升任务对齐但牺牲通用性。
- **结构层（Structure Level）——五种表示模式**（图 2，非互斥，可组合）：
  - **扁平图（Flat）**：以带类型的节点与边存用户事实/偏好/关系，无显式抽象层。注意：**异质节点/边类型本身不构成层级**。代表：UMGR（用户-物品-属性-观点的领域异质图，用于推荐）、KGT（可编辑的个性化事实三元组）、Mem0g（从对话增量构建开放域实体关系图）。扁平图仍可携带溯源与有效性元数据。
  - **层级图（Hierarchical）**：多层组织用户证据，使不同粒度可访问；层级不等于单调抽象，跨层链接可让证据从高层表示反向可达。两类功能：
    - 证据→抽象组织：GAAMA（轮次→情节节点、中间层事实与概念、高层反思）、Bi-Mem（事实→主题场景→全局画像，跨层链接支持用局部证据校准）；
    - 粒度保持组织：GAM（活跃事件图 / 主题节点 / 归档事件分层）、SGMem（会话→轮次→句子分解，细粒度与粗粒度摘要、抽取事实并存）。
    - 风险：高层抽象可能传播抽取错误或把瞬时证据过度泛化；跨层一致性要求随深度增长。
  - **超图（Hypergraph）**：保留"意义依赖多个相连元素"的联合上下文。HingeMem（边界触发的对话片段成超边，按参与者/地点/时间索引，强调查询-事件匹配）、HyperMem（主题/情节/事实三层，情节超边归组同主题情节、事实超边归组同一情节内事实，支持粗到细的自顶向下检索）。
  - **混合图（Hybrid）**：图拓扑 + 非图基底（树、摘要库、段落库、证据缓冲）。H-Mem（时间-语义树 + 实体图，实体链接到提及它的记忆片段）；LiCoMemory（图存实体关系对，会话摘要与对话块承载内容）；MemWeaver（关系图 + 经验库 + 段落库）。代价：跨组件一致性要求。
  - **多重不相交图（Multiple Disjoint Graphs）**：按功能/时间尺度拆分为多个图实例。目前证据仅限 DEMENTIA-PLAN（日常作息图 + 人生记忆图）。论文明确指出：该工作未证明这些图实例形式上不相交，该模式的普适性仍需更多证据；但其优势在于"知道记忆存在哪里"从而高效存取。
- **小结**：表示决定了系统保留哪些用户证据、以及后续生命周期操作可用的依赖关系；它是演化与检索的**基底**，而非个性化质量的保证。

### 2.3 记忆演化（Evolution）——五类操作（图 3）

- **① 记忆准入（Admission）**：判断新证据是否转为持久记忆、以何种功能类型/粒度写入。KGT（用户反馈触发三元组增删改）；MemORAI（选择性过滤与压缩，保留与用户画像相关的情节、事实与偏好）；MemGuard（写入时赋予功能角色——事实/程序性指令/约束，并保持功能边界）。风险：过度准入会把瞬时陈述固化为持久状态；准入不足会丢失后续所需证据。
- **② 记忆整合（Integration）**：局部写入尺度上挂接到已有结构。追加并链接（LiCoMemory，保留到原始轮次/会话/块的溯源）；Mem0g（复用语义匹配节点、使过时边失效）；HingeMem（合并近重复的边界超边）；GAM（缓冲式挂接，新话语先写入活跃事件图，之后才整合进全局图，从而只整合语义完整单元、降低语义漂移）。
- **③ 冲突消解（Conflict Resolution）**：区分三类冲突，**不应塌缩为"最新优先"单一规则**——
  - 时间替代（新状态取代旧状态）；
  - 用户纠正（已存事实或推断被判定为错）；
  - 语境共存（表面矛盾的状态在不同语境下同时有效）。
  - 处理方式：AriadneMem（合并静态重复、把状态迁移保留为时间边）；GRAVITY（覆盖旧值但标记失活并保留证据）；ZEP（保留为可查询的版本序列）。
- **④ 巩固（Consolidation）**：多次写入后重组累积记忆，承担抽象、去重、重构、归档功能。GAM（把完成的事件缓冲提升为主题级结构并归档详细事件图）；All-Mem（带门控的 SPLIT/MERGE/UPDATE 拓扑编辑，同时保留不可变证据）。
- **⑤ 记忆移除（Removal）**：区分**遗忘与删除**——
  - 遗忘：降低曝光度、分辨率、权重或检索概率，但表示仍有留存。ScrapMem 的"光学遗忘"逐步降低旧剪贴页分辨率以抑制低价值细节并降低存储成本。
  - 删除：改变存储/激活/可恢复的内容。Kumiho 采用版本化信念修正——不可变修订保留、可变标签指示当前活跃状态、废弃记忆在正常检索中被排除（除非显式请求），保留完整演进历史以供审计。
  - 关键开放问题：**依赖传播**——移除源证据时，由它派生的派生事实、摘要、画像是否同步修订，否则活跃用户模型会内部不一致（交互证据已删、画像主张仍在）。
- **小结**：各系统在不同时间尺度上串联演化操作，但**不存在普适最优的生命周期设计**。

### 2.4 记忆检索（Retrieval）

- 目标：把当前请求映射到用户持久记忆图上的**有界子集**，既取回所需用户证据，又不暴露无关个人历史。三类机制可组合：
  - **① 相似度检索**：词法/关键词/稠密向量匹配，常用于生成初始候选或把查询锚定到图节点。EMG-RAG（可编辑智能手机记忆图上的个性化检索）。局限：扁平 top-k 易返回相关或近重复的交互碎片；纯语义邻近会漏掉经时间、因果、实体或抽象关系相连的证据。
  - **② 结构检索**：借助图组织扩展或精化初始候选。GAM（先检索主题节点，需要细节时再访问归档事件图）；MAGMA（同一记忆项在语义/时间/因果/实体四种图中表示，按查询意图选视图）；AssoMem（话语锚定到自动抽取的线索构成的联想记忆图，结合相关性、重要性、时间对齐排序）；xMemory（先选互补组与记忆组件，再按需扩展到源片段或消息）。风险：无控制的扩展会引入无关节点、无支撑路径与上下文成本。
  - **③ 自适应与智能体式检索**：按请求意图与中间证据改变查询解释、图探索、停止、路由或压缩。MRAgent（Cue-Tag-Content 图，迭代探索并剪枝检索路径）；PRISM（意图敏感路径选择 + 证据压缩，在上下文预算下保留高价值片段）；HingeMem（控制激活哪些元素索引路由以及检索深度）；APEX-MEM（多工具检索智能体在检索时解决冲突或演化信息）。
- **小结（重要限定）**：三者可组成流水线——相似度锚定入口、结构扩展取回分布式证据、自适应控制选择/压缩。但**图结构并不自动改善检索**：受控比较显示结果可能取决于图结构之外的基础系统设置（ref [51]）。图检索仅在"表示暴露了有意义的用户关系 + 演化维护了其有效性 + 检索返回了相关证据"三者同时成立时才有用。

### 2.5 评估框架（Evaluation）

- 评估仍以**下游任务为主**：测试记忆系统能否答对、能否检索到支撑证据、能否验证更新后的用户状态、能否降低长历史下的上下文成本。
- 基准按目标分为几类（表 II，标注维度：Ans. 答案质量 / Ret. 证据检索 / User 用户状态建模 / Evol. 随时间演化 / MemOrg. 记忆组织 / Cost 效率 / MM 多模态证据；✓ 显式、△ 部分或间接）：
  - **长程回忆与检索**：LoCoMo（真实图文对话，图记忆论文常用基准，覆盖生产级记忆的图变体、拓扑感知图推理、学习式遍历、多尺度用户记忆、图原生版本化记忆）、LongMemEval（更长历史、知识更新、单会话偏好问题、时间推理、弃答）。
  - **个性化与用户状态建模**：PersonaMem（动态用户画像与偏好追踪）、PersonaMem-v2（隐式画像、更长上下文、更大偏好覆盖、智能体式记忆）、RealMem（项目导向、目标/日程/依赖跨会话演化）、PerLTQA（把个人长期记忆分为语义记忆——画像与社交关系——
