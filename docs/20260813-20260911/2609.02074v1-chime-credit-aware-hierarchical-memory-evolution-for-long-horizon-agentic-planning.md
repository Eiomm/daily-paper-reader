## 摘要
规划是一种核心能力，使智能体能够将复杂的长时程任务分解为可管理的步骤。测试时搜索和基于训练的方法改进了规划，但会带来高昂的推理成本或需要昂贵的训练数据。自演化记忆则将从智能体交互结果中积累的可复用经验存入外部记忆库，从而使规划能力在推理时无需更新参数即可持续提升。然而，现有自演化记忆方法普遍存在固有的信用分配问题：它们依赖最终任务结果作为反馈，但这类结果将规划质量与执行错误和环境因素混为一谈，因此积累的规划经验往往有偏且充满噪声。为解决这一问题，我们提出信用感知分层记忆演化（CHIME），一种自演化记忆框架，它分别维护规划库和执行库，并遵循先归因后记忆原则：CHIME 首先将每个任务结果归因于规划、执行、二者兼有或二者皆无，然后仅更新相应的记忆库。在四个长时程智能体基准上的大量实验表明，CHIME 始终优于最先进的基于训练的方法和自演化记忆基线。进一步分析揭示了若干有趣发现。例如，CHIME 以少得多的记忆条目积累出有效记忆。此外，学习到的记忆价值忠实反映下游效用：高质量的规划记忆比执行记忆更有价值。最后，积累的记忆能有效地跨主干模型迁移。代码将发布于 https://github.com/ATH-MaaS/Marco-DeepResearch。

## Abstract
Planning is a central capability that enables agents to decompose complex long-horizon tasks into manageable steps. Test-time search and training-based methods improve planning but incur high inference costs or require expensive training data. Self-evolving memory instead accumulates reusable experience from agent interaction outcomes into an external memory bank, so planning capability keeps improving at inference time without parameter updates. However, existing self-evolving memory methods share an inherent credit assignment problem: they rely on final task outcomes as feedback, but such outcomes conflate plan quality with execution errors and environmental factors, so the accumulated planning experience is often biased and noisy. To address this problem, we propose Credit-Aware Hierarchical Memory Evolution (CHIME), a self-evolving memory framework that maintains a separate planning bank and execution bank and follows an attribute-before-memorize principle: CHIME first attributes each task outcome to the plan, the execution, both, or neither, and then updates only the corresponding memory bank. Extensive experiments on four long-horizon agent benchmarks show that CHIME consistently outperforms state-of-the-art training-based and self-evolving memory baselines. Further analyses reveal several interesting findings. For example, CHIME accumulates effective memory with far fewer items. In addition, the learned memory values faithfully reflect downstream utility: high-quality planning memories are more valuable than execution memories. Finally, the accumulated memory effectively transfers across backbone models. Code will be released at https://github.com/ATH-MaaS/Marco-DeepResearch.

## 一、核心问题与研究背景

- **研究领域**：长时程（long-horizon）智能体规划。长时程任务要求智能体在多个相互依赖的步骤间协调决策，并持续满足任务约束，因此规划能力是核心。
- **现有三条技术路线及其代价**：
  - **测试时搜索**（Tree of Thoughts、WebAnchor、MiroThinker-H1 等）：靠采样多个候选计划/轨迹来提升单任务表现，但推理成本高，且不保留可复用经验。
  - **规划器模型训练**（Plan-and-Act、TodoEvolve 等）：把规划能力内化到参数中，但需要昂贵的轨迹采集与后训练，持续更新困难。
  - **自演化记忆**（ReasoningBank、UMEM、A-MapReduce 等）：冻结模型参数，只更新外部记忆库，训练免费且可持续，是本文选择的范式。
- **核心问题——信用分配失败**：现有自演化记忆方法普遍把**最终任务结果**直接等同于**计划质量**。但同一结果可能有不同成因：
  - 成功可能来自好计划，也可能来自执行器对坏计划的补救；
  - 失败可能源于计划缺陷、执行错误或环境因素。
  - 后果有两层：①有偏经验一旦写入记忆库会被反复检索复用，局部误判累积为系统性规划错误；②执行级/环境级经验被误当作规划记忆，检索出的低层细节反而误导高层规划决策。
- **整体含义**：论文主张自演化规划记忆的关键不在于"记住多少"，而在于**把经验归因到正确的决策阶段**，据此提出"先归因后记忆"（attribute-before-memorize）原则。

## 二、方法论（CHIME）

### 2.1 核心思想

- 将单一共享记忆库拆分为**规划库**（子任务分解、依赖建模、约束纳入等战略经验）与**执行库**（工具选择与调用等操作经验）。
- 每个 episode 先由**信用归因门**判断结果应归因于规划、执行、两者或皆非，再**只更新被归因的记忆库**，从而抑制有偏反馈与跨阶段污染。
- 模型参数全程冻结，只在推理期演化外部记忆。

### 2.2 关键技术细节

**(1) 分层记忆库**

- 记忆库 $M_t=(M_{plan,t}, M_{exec,t})$，阶段标记 $\ell\in\{plan, exec\}$。
- 每个记忆项 $m_i=(c_i, e_i, v_i, n_i)$：$c_i$ 为适用任务描述（检索与合并的 key）；$e_i$ 为可复用经验；$v_i\in[-1,1]$ 为复用反馈估计的价值分；$n_i$ 为复用次数。

**(2) 分层记忆检索（两阶段独立进行）**

- 先用阶段查询 $q_{\ell,t}$ 按语义相似度取 Top-N 候选集 $C_{\ell,t}$（$N=20$）。
- 用复用次数对价值做收缩：$\tilde v_i = v_i \cdot \frac{n_i}{n_i+\lambda}$，$\lambda=3.0$，使低频记忆退回纯相似度排序。
- 再按相似度与价值联合重排取 Top-K（$K=3$）：
  $\text{score} = \text{sim}(q_{\ell,t},c_i)\,[1+\text{clip}(\alpha \tilde v_i, -\beta, \beta)]$，$\alpha=1.0,\ \beta=0.2$，保证相似度仍为主导、同时偏好被验证有用的记忆、抑制误导记忆。

**(3) 信用归因门（Credit Attribution Gate）**

- 实现为冻结策略的**结构化自反思**：审阅任务、计划、轨迹、结果与检索到的记忆，评估计划充分性、执行正确性与外部因素影响。
- 输出诊断 $g_t=\big(a_t, \{(c^{new}_{\ell,t}, e^{new}_{\ell,t})\}_\ell, \gamma_t, M^{mis}_t\big)$：
  - $a_t\in\{planning, execution, both, none\}$（成功时则标记应归功的阶段）；
  - 各阶段新生成的场景与经验；
  - 归因置信度 $\gamma_t\in[0,1]$；
  - 被识别为**误导**的已检索记忆集合。

**(4) 信用感知记忆演化（仅作用于被归因阶段）**

- 阶段集合映射：$L(a_t)$ 在 planning/execution/both/none 时分别为 $\{plan\}$、$\{exec\}$、$\{plan,exec\}$、$\varnothing$。
- 价值反馈：被标为误导则 $\delta_{i,t}=-\gamma_t$；任务成功且该记忆所属阶段被归因则 $+\gamma_t$；否则为 0。
- 在线平均更新价值与复用次数：$v_i \leftarrow \text{clip}\big(\frac{n_i v_i+\delta_{i,t}}{n_i+1},-1,1\big)$，$n_i\leftarrow n_i+1$。
- 剪枝：当 $n_i\ge n_{min}=3$ 且 $v_i<\theta_{prune}=-0.1$ 时删除该记忆。
- 内容演化三选一：与最相似记忆（$\text{sim}>\theta_{merge}=0.88$）**合并**；接受但不相似则**插入**（初始 $v=0,n=0$，价值由未来复用决定）；否则**丢弃**。接受需满足 $\gamma_t\ge\theta_{conf}=0.5$ 且任务场景具体、经验可操作。

### 2.3 单 episode 流程

$M_t \to M^{ret}_{plan,t} \to p_t \to M^{ret}_{exec,t} \to \tau_t \to s_t \to g_t \to M_{t+1}$：检索规划记忆 → 生成计划 → 检索执行记忆 → 执行得轨迹 → 环境给二值结果 → 归因门诊断 → 演化记忆。
