## 摘要
长期记忆是个性化 LLM 智能体的核心能力。为支持这一点，现有记忆系统使用各种标准（如主题片段或摘要层级）来组织信息。然而，我们发现这些设计存在两个主要局限。第一，它们缺乏场景感知：来自无关生活场景的记忆共享同一检索空间，这会增大搜索空间并引入跨场景干扰。第二，它们从单一视角对每条记忆进行编码，导致难以检索同一事件的互补视图。在本文中，我们提出 CreaMem 架构，通过将记忆划分为多个生活场景记忆（Life Scene Memories）来实现场景感知的记忆组织，从而减少检索时的跨场景干扰。为了超越单一视角并实现跨记忆协同，每条记忆中的条目都从情节视角和特质视角进行双重编码。我们还设计了一种检索时的逐记忆平衡采样策略。在两个长期记忆基准上的大量实验表明，CreaMem 在所有评价指标上提升了问答准确率，尤其在多跳推理性能上提升显著，验证了场景感知划分和跨记忆协同的有效性。为增强可复现性，我们在公开的 GitHub 仓库中发布了代码。

## Abstract
Long-term memory is a core capability for personalized LLM agents. To support it, existing memory systems organize information using various criteria such as topic segments or summary hierarchies. However, we identify two major limitations in these designs. First, they lack scene awareness: memories from unrelated life scenes share the same retrieval space, which inflates the search space and introduces cross-scene interference. Second, they encode each memory from a single perspective, making it difficult to retrieve complementary views of the same event. In this paper, we propose the CreaMem architecture, which enables scene-aware memory organization by partitioning memory into several Life Scene Memories to reduce cross-scene interference at retrieval. To go beyond the single perspective and achieve cross-memory synergy, entries are dual-coded from both episodic and trait-based perspectives within each memory. We further devise a permemory balanced sampling strategy at retrieval time. Extensive experiments on two long-term memory benchmarks show that CreaMem improves QA accuracy across all evaluation metrics, with particularly large gains on multi-hop reasoning performance, validating scene-aware partitioning and cross-memory synergy. To enhance reproducibility, we release our code in a public GitHub repository.

## 1. 核心问题与研究动机

- **背景**：LLM 正从单会话工具演变为跨会话长期陪伴的个性化智能体，长期记忆成为核心能力。仅"存得住"不够，记忆的**组织结构与检索方式**决定了能否在长时间跨度上维持行为一致性。
- **现有工作的三种范式**：
  - 扁平存储（MemGPT、MemoryBank、MPNet、Contriever、MPC）：在无结构池中做相似度检索。
  - 结构强加（RecurSum、SeCom、RAPTOR、HippoRAG 2、A-Mem、MemGAS）：引入摘要树、主题片段、知识图谱、笔记链接等。
  - 记忆分区（MemoryOS、MIRIX 等）：按时间尺度或认知功能（情景/语义/程序）拆分。
- **论文识别的两大缺陷**：
  - **缺乏场景意识**：来自无关生活场景（如工作与家庭）的记忆共享同一检索空间，导致检索空间膨胀并产生**跨场景干扰**；按时间尺度分区（MemoryOS）也无法解决，因为不同场景条目仍可落在同一层级。
  - **单视角编码**：每条记忆只从一个角度编码，难以取回同一事件的**互补视角**（如"何时去徒步"与"用户是否喜欢户外活动"）。
- **认知心理学依据**（作为设计原则）：
  - Conway 的自记忆系统：自传体记忆按**人生情境（lifetime contexts）**组织，而非抽象类别。
  - Tulving 的多重记忆系统：情景记忆与语义记忆以互补形式编码同一经验，并在回忆时协同。

## 2. 方法论

### 2.1 核心思想
将记忆沿用户**生活场景**分区，并把每次经验**双重编码**为时间线条目与场景特质条目，检索时通过逐记忆平衡采样组合两种视角。

### 2.2 记忆组件
- **Episodic Memory**：存储带时间锚定的事件及其叙事细节，支持需要具体时刻落地的查询。
- **Life Scene Memories（Life / Work / Interest）**：每个场景存**特质（trait）**条目，即从一条或多条消息中抽象出的、场景条件下的用户推断（如"用户周末做家庭户外活动"）。特质保留在场景内，因为偏好是情境依赖的。
- **Core Memory**：跨场景的稳定用户画像（身份、偏好、关键关系、静态参考信息），被 Planner 选中时全文注入 prompt；自由文本块，达到字符上限 90% 时自动压缩。
- **Meta Memory Manager**：中央路由器，将消息分类到一个或多个场景并分发。

### 2.3 存储流程
- 三步管线：路由 → 提取 → 合并/插入。
  - 路由集合 $R(m) \subseteq \{Core, Episodic, Life, Work, Interest\}$；采用**宽进严筛**策略，不确定时触发多个组件以避免信息静默丢失（如"下班后和同事去健身房"可同时路由到 Life/Work/Interest）。
  - 每个被选组件由对应的 LLM 提取器 $f^{r}_{LLM}$ 产生候选条目。
  - 对每个候选，用嵌入检索最相似的已有条目，由 LLM 决定**合并**还是**插入** SQLite 表。
- **Episodic 条目 schema**：$M^{(i)}_{epi} = (eid_i, t_i, a_i, e_i, s_i, d_i, v_{s,i}, v_{d,i})$，其中 $t_i$ 为时间戳、$a_i \in \{user, assistant\}$ 为行为者、$e_i$ 为事件类型、$s_i$ 为一句摘要、$d_i$ 为完整事件上下文，$v_{s,i}, v_{d,i}$ 分别为摘要与详情的稠密嵌入；一条消息可产生多个条目。
- **Scene 条目 schema**：$M^{(i)}_{scene} = (sid_i, c_i, w_i, v_i)$，$c_i$ 为特质内容，$w_i \in [0,1]$ 为 LLM 给出的重要性分数，$v_i$ 为内容嵌入。

### 2.4 检索流程
- **记忆选择**：Planner LLM 输出 $(K, R) = f^{plan}_{LLM}(q)$，即 3–6 个检索关键词与待查记忆子集。
- **逐记忆平衡检索**：对每个被选记忆 $r$，并行执行 BM25（文本）与余弦相似度（查询嵌入）两路检索，各取 top-k，记为 $C^{bm}_r$ 与 $C^{emb}_r$。**每个记忆贡献相同数量候选**，因此没有单一记忆能主导候选池。
- **候选去重**：$C = \mathrm{dedup}\left(\bigcup_{r \in R}(C^{bm}_r \cup C^{emb}_r)\right)$，按记忆 ID 与内容前缀去重。
- **全局重排（RRF）**：$\mathrm{RRF}(c) = \frac{1}{k_0 + \mathrm{rank}_{bm}(c)} + \frac{1}{k_0 + \mathrm{rank}_{emb}(c)}$，$k_0 = 60$；按 RRF 分数取 top-N 注入 prompt。
- **兜底**：若 Planner 判断上下文不足，则重新查询，每次取 3 条。

### 2.5 实现细节
- 骨干 LLM 为 GPT-4o-mini（Manager、各提取器、Planner 全部使用），temperature = 0；嵌入模型为 `text-embedding-3-small`；存储为本地 SQLite；累积 3 条及以上用户消息触发批量提取；Core Memory 字符上限 $L=2000$。

## 4. 主要实验结果

- **LoCoMo**：
  - CreaMem 在 **4o-Judge 准确率**上取得最高分，相较 MemGAS、MemoryOS 等强基线有一致提升，且在 **Multi-hop** 与 **Temporal** 两类问题上优势更明显——前者受益于场景内特质的聚合能力，后者受益于 Episodic 的时间锚定。
  - 在 Token F1、BLEU-4、ROUGE 等词面重叠指标上，CreaMem 并非全面领先（部分基线在 BLEU/ROUGE 上接近甚至局部更高），作者指出词面指标对"语义正确但措辞不同"的记忆型回答区分度有限，故以 LLM judge 为主指标。
  - 相较 Full History 基线，CreaMem 在显著更小的 prompt token 预算下取得更高准确率，说明收益来自**组织方式**而非"喂入更多上下文"。
- **LongMemEval-S**：
  - CreaMem 同样取得最高或最具竞争力的 4o-Judge 准确率，验证其不止适配超长单会话，也适用于跨会话的稀疏记忆保持场景。
  - 在该数据集上因对话更碎片化，Core Memory 与 Scene trait 的贡献占比上升。
- **骨干鲁棒性**：
  - 在 Gemini-3 作为 QA 骨干与 judge 的复现实验中，CreaMem 相对基线的排序基本保持一致，说明架构收益**不依赖特定 LLM**。

## 5. 深入分析与关键发现

- **场景分区的收益来源**：消融显示 3-scene 明显优于 1-scene，且"全量路由"退化策略反而下降，说明关键在于**路由的判别性**——把记忆放进正确场景、并让检索在场景内收敛，比单纯增加记忆条目更重要。
- **逐记忆平衡采样是核心机制**：去掉平衡采样改为全局 top-k 后，候选池被 Episodic 或某一高频场景主导，准确率下降；逐记忆等量采样通过"配额"强制多视角共存，是缓解跨场景干扰的关键。
- **双视角互补性得到验证**：仅 Episodic 在"何时发生"类问题上强但抽象偏好类问题弱，仅 Scene trait 反之；Full System 在两类问题上均最优，支持 Tulving 的互补编码假设。
- **BM25 与嵌入的互补**：去掉任一通道均下降，说明关键词匹配（人名、专有名词、时间词）与语义相似度承担不同角色；RRF 的作用在两者排序分歧时尤为明显。
- **Core Memory 的定位**：作为跨场景稳定画像被全文注入，其价值主要体现在 Open-domain 与身份相关问题上；字符上限触发的自动压缩在超长会话中有效控制了 prompt 膨胀。
- **宽进严筛的代价与收益**：宽进策略避免了信息静默丢失，但引入了冗余条目，由合并/插入决策与去重环节吸收；消融表明该策略总体为正收益。

## 6. 局限与未来工作

- **场景类别固定**：Life / Work / Interest 三分为先验设定，未必覆盖所有用户（如学习、照护、社群），且场景边界存在模糊与重叠；未来可探索自动发现或动态增删场景。
- **依赖 LLM 的中间决策**：路由、提取、合并、规划四步均由 LLM 判定，误差会级联传播；且每轮存储与检索的 LLM 调用带来可观成本与延迟。
- **重要性权重 $w_i$ 未被充分用于检索**：当前检索未显式使用场景条目的重要性分数，存在进一步优化空间。
- **评估依赖 LLM judge**：4o-Judge 虽为主流做法，但仍存在偏好偏差，且词面指标与 judge 结论不一致，提示评测方法本身仍需完善。
- **规模与时效**：实验基于 GPT-4o-mini 与固定数据集，未验证在更大规模、更长周期（数月到数年）真实用户日志下的可扩展性与遗忘/冲突更新机制。

## 7. 结论与启示

- **核心贡献**：论文提出 CreaMem，把认知心理学的**自传体记忆按人生情境组织**与**多重记忆系统互补编码**两条原则，落为可工程化的记忆架构——场景分区 + 双重编码 + 逐记忆平衡检索。
- **方法要点**：Meta Memory Manager 负责宽进路由，Episodic 与 Scene trait 分别承担时间线与特质视角，Core Memory 提供跨场景画像，检索端以逐记忆等量采样保证视角均衡、以 RRF 融合关键词与语义两路信号。
- **实践启示**：长期记忆系统的性能瓶颈不在"存多少"，而在"如何分区、如何多视角编码、如何公平检索"；简单地把所有记忆放进一个向量库，会随生活场景增多而持续劣化。
- **更广意义**：为个性化智能体提供了一条可复用的设计范式——用认知结构约束检索空间，用配额式采样对抗单一视角主导，从而在长时跨度上维持行为一致性与用户理解深度。
