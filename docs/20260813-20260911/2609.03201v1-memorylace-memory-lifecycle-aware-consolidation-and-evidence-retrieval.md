## 摘要
长期LLM智能体必须在跨交互过程中保留信息，同时区分重复证据、历史状态、更新以及未解决的矛盾。现有的文本记忆系统能够高效检索语义相关的记忆，但往往将这些关系隐式处理，而更丰富的结构化方法则通过全局图、层次化抽象或反思以更高的复杂度对其建模。我们提出MemoryLACE（MemLACE），一种轻量级记忆框架，通过稀疏的合并、取代和矛盾关系显式建模文本证据的生命周期，同时保留原子化自然语言记忆及其来源。MemLACE并非独立检索记忆，而是重建关系感知的证据单元，为下游推理暴露当前、历史、支持和冲突证据。在BEAM和StructMemEval上，使用开放权重和专有LLM骨干模型，MemLACE在相同骨干比较中取得最高整体性能，同时相对于报告的最强反思式记忆基线Hindsight，将BEAM上的端到端运行时间减少66.6%。消融研究表明，生命周期扩展和时间感知是这些增益的主要贡献因素。总体而言，结果表明，显式建模文本证据的局部生命周期足以显著改善长期记忆推理，而无需全面的知识图谱或全局反思。

## Abstract
Long-term LLM agents must preserve information across interactions while distinguishing repeated evidence, historical states, updates, and unresolved contradictions. Existing textual memory systems retrieve semantically relevant memories efficiently but often leave these relationships implicit, whereas richer structured approaches model them through global graphs, hierarchical abstractions, or reflection at greater complexity. We introduce MemoryLACE (MemLACE), a lightweight memory framework that explicitly models the lifecycle of textual evidence through sparse merge, supersession, and contradiction relations while preserving atomic natural-language memories and their provenance. Rather than retrieving memories independently, MemLACE reconstructs relation-aware evidence units that expose current, historical, supporting, and conflicting evidence for downstream reasoning. Across BEAM and StructMemEval, using open-weight and proprietary LLM backbones, MemLACE achieves the highest overall performance in same-backbone comparisons while reducing end-to-end runtime on BEAM by 66.6% relative to Hindsight, the strongest reported reflective-memory baseline. Ablation studies identify lifecycle expansion and temporal awareness as the principal contributors to these gains. Together, the results demonstrate that explicitly modeling the local lifecycle of textual evidence is sufficient to substantially improve long-term memory reasoning without requiring comprehensive knowledge graphs or global reflection.

## 1. 核心问题与整体含义

- **研究背景**：长期 LLM 智能体需要跨会话、跨任务保存偏好、计划、约束、纠正、事实与任务进度等信息。仅靠上下文窗口不足，需要外部长期记忆。
- **核心问题**：现有文本记忆系统虽能高效检索语义相关记忆，但通常把“重复、取代、历史状态、未解决矛盾”等关系隐式处理；结构化/图/层次/反思方法虽显式建模关系，却需要全局知识图谱、层次抽象或反思模块，复杂度高、运行成本大。
- **整体含义**：论文试图回答：能否仅通过建模文本证据的**局部生命周期关系**，在不构建完整全局结构的前提下，显著提升长期记忆推理能力。
- **核心主张**：MemLACE 在“扁平文本记忆”和“重型结构化记忆”之间取得轻量折中，保留原子自然语言记忆及其来源，同时用稀疏关系连接重复、取代和矛盾证据。

## 2. 方法论

### 2.1 核心思想

- 将长期记忆视为**不断演化的证据**，而非静态摘要集合。
- 每个记忆保持原子化、自然语言化、可追溯来源，并显式记录其生命周期状态。
- 写入时通过有界候选比较和局部批量演化建立关系；检索时通过生命周期扩展重建“关系感知证据单元”，让答案模型同时看到当前、历史、支持和冲突证据。

### 2.2 记忆表示

- 单条记忆表示为：  
  \(m_i = (x_i, \tau_i, z_i, p_i, a_i, R_i)\)
  - \(x_i\)：原子自然语言事实/偏好/计划/纠正等；
  - \(\tau_i\)：证据支撑的时间元数据；
  - \(z_i\)：实体、关键词、主题、地点等轻量元数据；
  - \(p_i\)：来源对话轮次，保留顺序与出处；
  - \(a_i\)：是否活跃；
  - \(R_i\)：合并、取代、矛盾等生命周期关系引用。
- 完整记忆库形成稀疏关系图 \(G=(M,E)\)，其中 \(E\) 包含有向取代边和对称合并/矛盾边。
- 与通用知识图谱不同，MemLACE 只存解释证据演化所需的关系。

### 2.3 Stage I：记忆构建与整合

- 沿用滑动窗口构造：20 轮窗口、2 轮重叠，将对话转为独立原子记忆。
- 重叠窗口导致的重复提取会合并来源；不同轮次的重复可保留为可合并链接。
- **候选与关系选择**：按时间顺序整合；对每个新记忆，先按语义相似度和同实体匹配检索相关记忆，再扩展其一跳生命周期邻居，形成候选集；交叉编码器重排候选，但重排只决定比较对象，不决定关系。
- 整合决策函数 \(g(m_{new}, C(m_{new})) \rightarrow (r, c^\star)\)，其中 \(r \in \{\text{merge}, \text{update}, \text{contradict}, \text{no action}\}\)，每次只选择一个关系和至多一个目标。
- **生命周期状态更新**：
  - update：旧记忆失活，新记忆成为活跃链头，并建立双向取代关系；
  - contradict：矛盾记忆保持活跃并对称链接，因为证据未解决冲突；
  - merge：默认“linked-merge”，保留原文和来源并加双向合并引用；对比策略“compact-merge”则合成单条活跃记忆，但丢弃原始条目；
  - no action：独立可检索。
- **局部批量演化**：对新加入记忆组及其整合候选做有界联合审查，修复单次决策遗漏的额外 update/contradict/merge 关系，只改关系与活跃状态，不改写文本或增加事实。

### 2.4 Stage II：证据检索与上下文构建

- **混合活跃记忆检索**：使用语义相似度、关键词、结构化模板、主题相关性等多个通道，对活跃记忆生成排名，再用 Reciprocal Rank Fusion 融合：  
  \(s_{RRF}(m)=\sum_{c\in C} \frac{1}{k+rank_c(m)}\)，文中 \(k=60\)。
- **生命周期扩展**：先得到活跃锚点 \(A_q\)，再扩展为  
  \(E_q = A_q \cup L(A_q)\)，其中 \(L\) 沿取代链恢复历史状态，并扩展一跳矛盾关系。扩展有界，不遍历全图。
- **证据单元**：将检索池中由取代、矛盾、合并链接连接的记忆组成证据单元；取代边按旧到新排列，矛盾证据保留在一起而非过早裁决。
- **链感知重排与打包**：重排器对完整证据单元打分，按上下文预算选择高分单元；更新链保持旧到新顺序，预算不足时保留高优先级部分。
- **证据 grounded 生成**：打包上下文按生命周期顺序呈现当前、被取代、冲突记忆，使模型可优先当前证据、恢复历史状态、保留未解矛盾。
