## 摘要
检索增强生成（RAG）提升了大语言模型（LLMs）的事实性，但现有 RAG 系统往往难以应对复杂、多步推理，这类推理需要自适应检索和对中间上下文的持续修正。近期基于强化学习（RL）的智能体 RAG 方法部分缓解了该问题，但通常依赖粗粒度动作空间和轨迹级奖励，导致奖励分配较弱，并偏向短视界、刻板化的推理模板。为解决这一问题，我们提出 AgenticRag-R1，一个通过记忆栈和细粒度动作空间深度集成推理、检索与记忆的 RL 框架，并辅以分层动作感知奖励和信息感知轨迹拒绝策略，以实现有效的长视界学习。在涵盖多种骨干模型规模的多样化多跳、开放域和智能体推理基准上的实验表明，AgenticRag-R1 持续优于强基线。此外，AgenticRag-R1 学到了更稳健、可解释且具有记忆感知的推理行为，凸显了细粒度动作建模和信息感知优化对长视界推理的作用。我们的代码可在 https://github.com/jiangxinke/Harness-RL/tree/AgenticRAG-R1-Whitebox 匿名获取。

## Abstract
Retrieval-Augmented Generation (RAG) improves the factuality of large language models (LLMs), yet existing RAG systems often struggle with complex, multi-step reasoning that requires adaptive retrieval and continuous revision of intermediate contexts. Recent reinforcement learning (RL)-based agentic RAG methods partially alleviate this issue, but typically rely on coarse-grained action spaces and trajectory-level rewards, resulting in weak reward assignment and a bias toward short-horizon, stereotyped reasoning template. To address, we propose AgenticRag-R1, a RL framework that deeply integrates reasoning, retrieval, and memory via a memory stack and fine-grained action space, supported by hierarchical action-aware rewards and an information-aware trajectory rejection strategy to enable effective long-horizon learning. Experiments across a diverse set of multi-hop, open-domain, and agentic reasoning benchmarks, spanning multiple backbone model sizes, demonstrate that AgenticRag-R1 consistently outperforms strong baselines. Moreover, AgenticRag-R1 learns more robust, interpretable, and memory-aware reasoning behaviors, highlighting the effect of fine-grained action modeling and information-aware optimization for long-horizon reasoning. Our code is anonymous available at https://github.com/jiangxinke/Harness-RL/tree/AgenticRAG-R1-Whitebox.

## 2. 方法论

### 2.1 核心思想

用 **LIFO 记忆栈**作为智能体的内部状态载体，每个栈元素是一个语义完整的推理单元；通过 push/pop 支持**可逆、可检查、可修正**的记忆操作；再以**token 级分层奖励**监督异质认知动作，并以**信息感知的全局轨迹拒绝**保证训练分布的高信息量。

### 2.2 记忆感知的多动作建模

- `<Plan>`（push）：生成并存储子目标 / 任务分解 / 高层策略。
- `<Think>`（push）：记录内部推理（逻辑推演、决策）。
- `<Search>`（push）：构造带结构化参数的查询并调用检索模块，检索观测以 `<Observation>` 形式入栈。
- `<Backtrack>`（pop，再 push）：检测到不一致或错误时弹出若干栈顶元素，恢复到先前有效状态以探索替代路径。
- `<Summary>`（pop，再 push）：把近期记忆压缩为简洁表示后重新入栈，兼顾上下文管理与关键信息保留。
- `<Conclusion>`（push）：标记候选最终答案，终止推理序列。

### 2.3 分层奖励建模（token 级）

每个 token 的奖励定义为：

```
r_i^(k) = (1 − I_mask,i^(k)) · r_out^(k) + I_act,i^(k) · r_proc,i^(k)
```

- `I_mask`：屏蔽检索观测等非模型生成 token，避免虚假梯度更新。
- `I_act`：标识该 token 是否属于某个动作调用。

**结果奖励 r_out**：从 `<Conclusion>` 抽取答案与 gold 比较，离散答案用 Exact Match、分级答案用 F1，取值 ∈ [0,1]，并均匀分摊到有效生成 token 上。

**过程奖励 r_proc = r_fmt + r_rag + r_mem**：

- **格式奖励 r_fmt**：动作标签格式合法则给 `α_type`，`<Conclusion>` 为 1.0、其他有效动作为 0.5，否则 0。
- **检索奖励 r_rag**：由大参数通用奖励模型 GRM 对「查询—检索观测—原始问题」的一致性打分 ∈ [0,1]。
- **记忆奖励 r_mem**：由 GRM 对「记忆动作—当前记忆栈—问题」判断该 Backtrack / Summary 是否合理且有益，∈ [0,1]。

**奖励预算与比例归一化**：设 `R_proc = Σ r_proc,i`，当 `R_proc > B_proc` 时按 `B_proc / R_proc` 等比缩放全部过程奖励，以抑制通过滥发动作进行 reward hacking。

### 2.4 信息感知轨迹拒绝（Information-Aware Trajectory Rejection）

- **批量级 rollout 集合**：每个 mini-batch 含 B 个输入，每个输入采样 K 条随机 rollout，合并为 `Y_B`（|Y_B| = B×K）。
- **输入级统计量**：对每个输入计算 rollout 奖励的均值 `μ(b)` 与方差 `(σ(b))²`，方差刻画该输入的**信息量 / 可解路径多样性**。
- **UCB 式打分**：`r̃(b,i) = (σ(b))² · r(b,i) + μ(b)`。乘法项在"存在有意义多样性"时放大高质量 rollout、抑制退化轨迹；加法均值项作为稳定基线防止过度拒绝。
- **全局拒绝**：在整个 batch × rollout 空间内按 `r̃` 排序，仅保留 top-p 比例的 rollout 参与策略优化，未入选者被丢弃。

### 2.5 Pop-based 注意力掩码

标准因果掩码不足以表达"早出现但已被弹出"的 token 应不可见。论文引入 `M_pop`（若 token j 在第 i 步前被弹出则置 −∞），最终掩码为 `M = M_causal + M_pop`。这样被 Summary 压缩并弹出的动作，其信息只能通过摘要 token 被后续步骤访问。

### 2.6 训练流程（Algorithm 1 概览）

循环执行：采样 token 直到动作分隔符 → 解析动作 → 若属 Plan/Think/Search/Conclusion 则入栈；若为 Search 则调用检索器、把观测追加到轨迹并入栈、同时修改检索损失掩码；若为 Backtrack / Summary 则先 pop 再 push 修正内容，并修改 Pop-based 注意力掩码；若为 Conclusion 则返回轨迹。整体采用 **GRPO** 优化（含 KL 正则、裁剪目标）。
