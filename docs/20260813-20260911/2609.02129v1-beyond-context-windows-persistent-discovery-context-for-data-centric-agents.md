## 摘要
以数据为中心的智能体在规划或执行之前会反复执行一个发现步骤：识别与任务相关的数据对象。然而，成功的发现结果通常被丢弃，而不是被重用。我们引入持久化发现上下文，一种轻量级记忆层，用于存储先前的意图到对象映射，并复用它们来增强未来的检索。在三个结构化数据环境中，持久化发现上下文在检索质量上始终优于仅基于元数据的搜索，在自动生成的记忆下仍然有效，并揭示了一种可复现的干扰失效模式。在词汇稀疏的领域中，仅依赖记忆的检索甚至可以优于基于元数据的检索。这些发现表明，发现结果构成了一种对以数据为中心的智能体有用的可复用上下文形式。

## Abstract
Data-centric agents repeatedly perform a discovery step before planning or execution: identifying the data objects relevant to a task. Yet successful discovery outcomes are typically discarded rather than reused. We introduce persistent discovery context, a lightweight memory layer that stores prior intent-to-object mappings and reuses them to augment future retrieval. Across three structured data environments, persistent discovery context consistently improves retrieval quality over metadata-only search, remains effective with automatically generated memories, and exposes a reproducible interference failure mode. In lexically sparse domains, memory-only retrieval can even outperform metadata-based retrieval. These findings suggest that discovery outcomes constitute a useful form of reusable context for data-centric agents.

## 1. 核心问题与研究动机

- **背景**：以数据为中心的智能体（data-centric agents）在规划或执行任务前，必须反复执行一个"发现（discovery）"步骤——识别与当前任务相关的数据对象（表、属性）。
- **核心痛点**：现有的智能体记忆系统主要存储对话历史（MemGPT）、观察与反思（Generative Agents）、可执行技能（Voyager）或可复用工作流（Agent Workflow Memory），但**成功的发现结果通常被一次性使用后丢弃**，无法跨任务复用。
- **研究问题**：*成功的发现结果是否应当跨任务持久化？*
- **整体含义**：论文主张将"发现结果"本身视为一种可复用的上下文/记忆artifact，提出**持久化发现上下文（Persistent Discovery Context）**，作为对话、经验、工作流记忆之外的第四类智能体记忆，用于缓解上下文窗口之外的知识复用问题。

## 2. 方法论

- **核心思想**：用一个轻量级记忆层存储历史"意图→数据对象"映射，并在未来检索时用相似任务的记忆来增强对象排序。
- **关键概念**：
  - **发现记忆（Discovery Memory）**：`m = ⟨intent, objects⟩`，记录自然语言任务描述与其相关的数据对象集合；在 registry 级别持久化并跨任务累积。
  - **记忆增强检索（Memory-Augmented Retrieval）**：给定查询 `q`，先由 registry 检索得到基础相关度 `r(q, oi)`，再检索最相似的 top-K 条发现记忆进行加权增强。
- **核心公式（文字说明）**：
  ```
  score(q, oi) = r(q, oi) + α · Σ_{m∈top-K_m} sim(q, m.intent) · 1[oi ∈ m.objects]
  ```
  - `α` 控制记忆信号的影响权重；
  - `1[·]` 为指示函数，表示对象 `oi` 是否出现在某条被检索到的记忆中；
  - **特例**：`α=0` 退化为标准 registry 检索（S1）；令 `r(q, oi)=0` 则得到仅依赖记忆的排序器（S2）。
- **算法流程**：任务查询 → registry 检索候选对象 → 检索 top-K 相似记忆 → 按公式融合两路分数 → 重排对象。

## 6. 主要结论与发现

- **持久发现上下文持续提升检索质量**：S3 相对 S1 在三个领域均提升 F1@5（TF-IDF 下 Finance +0.103、NYC +0.183、Northwind +0.082；神经检索下 +0.167 / +0.051 / +0.119）。
- **记忆在词汇稀疏领域尤为重要**：NYC Collisions 中仅记忆检索（S2=0.412）超过 registry（S1=0.299），说明属性名晦涩时记忆信号强于元数据描述。
- **LLM 生成的记忆依然有效**：自动记忆与人工记忆的对象级 F1 为 0.698 / 0.762 / 0.735；在 Finance 和 NYC 仍优于 S1，三个领域均优于 S0，说明对不完美记忆有一定鲁棒性。
- **存在可复现的跨族干扰失败模式**：语义相近但错误的记忆会把检索质量压到低于无记忆基线（如 Northwind 中 S3-wrong F1=0.000）。
- **记忆增益不均匀**：对象词汇独特、意图-对象关系稳定的任务族获益最大；对象跨任务复用的任务族出现近零或负增益。
- **α 需适中**：三种领域、两种检索器均在 `α=0.25` 达到峰值，`α=1.0` 时性能全面下降；基础检索器越强，记忆可贡献空间越小。
- **融合优于直接注入**：S3（分数融合）在 MRR 与 F1@5 上全面优于 S4（Naive Injection）。

## 7. 优点

- **方法轻量且通用**：仅需存储 `⟨intent, objects⟩` 映射，可插拔地叠加在任意 registry 检索器之上（TF-IDF、BM25、neural 均有效）。
- **问题视角新颖**：将"发现结果"本身抽象为第四类可复用记忆，区别于对话/技能/工作流记忆，定位清晰。
- **实验设计较严谨**：多领域、多检索器、多条件交叉验证，并包含 LOO seed 稳健性、α 消融、LLM 记忆鲁棒性、S4 消融。
- **诚实地报告负面结果**：专门分析干扰失败模式，并给出后续研究方向（干扰感知选择、记忆老化、置信度估计）。
